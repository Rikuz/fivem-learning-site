# TRACK_OUTLINE.md — プロジェクトトラック設計

このドキュメントは、`docs/CONTENT_OUTLINE.md`(レッスン)・`docs/EXERCISE_OUTLINE.md`(演習)と同格の、**プロジェクトトラックの唯一の正**となる設計書です。トラック1・2(lb-phoneアプリ/犯罪script)は2026-08-11時点で実装完了。トラック3〜7(配送ジョブ/住居/カスタムHUD/管理者パネル/車両ディーラー拡張)は同日、需要の高さを基準に追加設計されたトラックです。着手時は、このファイルの内容に従い、外部スクリプトに依存するステップは実装前に必ず公式ドキュメントで構文を確認すること(`CONTENT_OUTLINE.md`の「コンテンツの正確性について」と同じ方針)。

## プロジェクトトラックとは

これまでのサイトには「Tier別ロードマップ(難易度順)」「カテゴリ別逆引き検索(概念別)」という2つの入口があったが、「lb-phoneアプリを1本作りきる」「犯罪(ゲーム内)scriptを1本作りきる」のような**目的ベースの通し道**がなかった。プロジェクトトラックは、既存レッスン・新規レッスン・演習を1つの完成物に向けて順序付けした、3つ目の入口となる。

- トラック自体は新しいレッスンの寄せ集めではなく、**既存コンテンツへの導線を中心に、本当に足りない部分だけ新規レッスン/演習を追加する**という考え方で設計する。
- レッスン本体の執筆ルール(結論→説明→コード例→注意点→補足、コード省略禁止、外部スクリプトは公式ドキュメントで裏取り)は`CLAUDE.md`の既存ルールをそのまま適用する。トラックページ自体は「順路の索引」に徹し、独自の内容は持たない。

## データ構造(実装時の指針)

`assets/js/tracks-data.js`に`TRACKS`配列を持たせる想定。

```js
const TRACKS = [
  {
    id: "track-lb-phone-app",
    title: "lb-phoneアプリ開発トラック",
    summary: "...",
    steps: [
      { type: "lesson", id: "t3-01-nui-basics", note: "前提: NUIの基礎" },
      { type: "lesson", id: "t4-lbphone-starter-template", note: "新規: スターターテンプレート" },
      { type: "exercise", id: "ex-lbphone-messaging-app", note: "新規演習: 簡易メッセージアプリ" },
      // ...
    ],
  },
  // track-crime-script
];
window.TRACKS = TRACKS;
```

`tracks.html`は`practice.html`と同様の一覧ページ、`tracks/*.html`は各トラックの詳細(ステップを順番に並べたチェックリスト。演習ページと同じ完了トグルの仕組みを再利用する)を想定する。

## 選定基準(トラック3〜7)

ユーザーからの依頼:「同じように1〜100までこのサイトだけで完結し、勉強できる内容を5個ほど考えて、できるだけ需要がある内容にしてほしい」。FiveM RPサーバーで実際に需要が高く、かつ既存レッスンとの重複が少ないテーマを基準に、以下の5つを選定した。

1. **配送/運送ジョブ開発トラック** — RPサーバーで最も定番の「仕事」コンテンツ(トラッカー/デリバリー系)。`t4-02-framework-jobs`はJob機能の使い方止まりなので、「仕事のループ設計」という需要の核心部分が未カバーだった。
2. **不動産(住居)システム開発トラック** — 「家を買う」はRPサーバーの定番機能だが、サイト内に住居関連レッスンが1つも存在しなかった(完全な空白領域)。
3. **カスタムHUD開発トラック** — どのRPサーバーもデフォルトHUDではなく自作HUDを使うのが実質標準。NUI基礎(Tier3)はあるが「常駐HUD」という具体的な作り方は未カバー。
4. **管理者パネル(Admin Panel)開発トラック** — 既存レッスン(`t3-20`管理者メニュー基礎、`t4-07`BAN/キック、`t4-11`スクリーンショット等)を統合するだけでも実用的なトラックになり、新規コンテンツが少なく済む効率の良いテーマ。
5. **車両販売店(ディーラー)拡張トラック** — `t4-12-used-car-dealership`という既存の核はあるが、実際のディーラー体験に欠かせない試乗・分割払いが未カバーだった。既存レッスンを土台に発展させられる。

新カテゴリは`housing`🏠(住居・不動産)の1種のみ追加する。他のトラックは既存カテゴリ(`gameplay`, `vehicle`, `nui`, `admin-tools`等)で表現できるため、カテゴリ増殖を避ける。
