NUI × StateBags: 複数プレイヤーで共有されるUI状態を同期する

やりたいこと

街の掲示板(prop)のようなオブジェクトの内容を誰かが更新したら、それを見ている全プレイヤーのNUI表示にも反映する。

組み合わせるレッスン

  • NUIの基礎(画面UIを表示する)Tier3-01
  • StateBagsによる同期Tier5-03

コード例

server.lua: 掲示板の内容を更新する

RegisterNetEvent('recipe:updateSignMessage')
AddEventHandler('recipe:updateSignMessage', function(signNetId, message)
    local signEntity = NetworkGetEntityFromNetworkId(signNetId)
    if signEntity == 0 then return end

    -- 第3引数をtrueにすると全clientに同期される(replicated、Tier5-03参照)
    Entity(signEntity).state:set('message', message, true)
end)

client.lua: StateBagsの変化を検知してNUIに反映する

-- 掲示板のStateBagsが変化したら、開いているNUIに反映する(Tier5-03参照)
AddStateBagChangeHandler('message', '', function(bagName, key, value)
    SendNUIMessage({ action = 'updateSignMessage', message = value })
end)

注意点

  • AddStateBagChangeHandlerは、そのプレイヤーがNUIを開いていなくても発火します。SendNUIMessageを送るだけなら害はありませんが、演出(音を鳴らす等)を伴う場合はNUIが開いているかどうかのフラグを併用してください。
  • StateBagsは「多くのclientが継続的に参照する比較的静的なデータ」向きです。頻繁に更新される値には向きません(Tier5-03参照)。
