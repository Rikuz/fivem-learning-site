ox_inventory × okokBanking: 所持アイテムで銀行手数料を割り引く

やりたいこと

「VIPカード」のようなアイテムを所持していると、okokBankingV2の出金手数料が安くなる特典を実装する。

組み合わせるレッスン

  • ox_inventoryにアイテムを追加するTier3-30
  • okokBankingV2と連携するTier4-06

コード例

server.lua: 所持アイテムに応じて手数料率を変える

local function getWithdrawFee(playerId, amount)
    -- Tier3-30のGetItemCountで所持数を確認する
    local hasVipCard = exports.ox_inventory:GetItemCount(playerId, 'vip_card') > 0
    local feeRate = hasVipCard and 0.01 or 0.05 -- VIPカード所持で手数料5%→1%に割引

    return math.floor(amount * feeRate)
end

RegisterNetEvent('recipe:withdraw')
AddEventHandler('recipe:withdraw', function(society, amount)
    local playerId = source
    local fee = getWithdrawFee(playerId, amount)
    local total = amount + fee

    -- Tier4-06のRemoveMoney/AddTransactionと組み合わせる
    exports['okokBanking']:RemoveMoney(society, total)
    exports['okokBanking']:AddTransaction(society, { value = total, type = 'withdraw', reason = ('出金(手数料$%s込み)'):format(fee) })

    TriggerClientEvent('okokNotify:Alert', playerId, 'ATM', ('$%sを出金しました(手数料$%s)'):format(amount, fee), 5000, 'success', true)
end)

注意点

  • 手数料率のような重要な数値は必ずserver側の定数として管理し、clientから送らせないでください(Tier3-05参照)。
  • 出金前に口座残高がtotal(手数料込みの金額)以上あるかの確認も忘れずに追加してください。
