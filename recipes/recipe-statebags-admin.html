StateBags × 管理者ツール: プレイヤー一覧に拘束状態を表示する

やりたいこと

Tier4-29で作った拘束状態(StateBags)を、管理者向けのオンラインプレイヤー一覧に反映し、「誰が今拘束中か」を一目で確認できるようにする。

組み合わせるレッスン

  • StateBagsによる同期Tier5-03
  • オンラインプレイヤー一覧とスペクテイト/ノークリップTier3-43

コード例

server.lua: プレイヤー一覧に拘束状態を含める

RegisterCommand('adminplayerstatus', function(source)
    local playerId = source
    if not IsPlayerAceAllowed(playerId, 'group.moderator') then return end

    for _, targetId in ipairs(GetPlayers()) do
        local targetIdNum = tonumber(targetId)

        -- Tier4-29で設定したisHandcuffedのStateBagsを読み取る(Tier5-03参照)
        local isHandcuffed = Player(targetIdNum).state.isHandcuffed or false

        TriggerClientEvent('chat:addMessage', playerId, {
            args = { '[管理者]', ('%s — 拘束中: %s'):format(GetPlayerName(targetIdNum), isHandcuffed and 'はい' or 'いいえ') }
        })
    end
end, false)

注意点

  • StateBagsは元々「拘束システム自身」のために設定した値です。管理者ツール側は読み取るだけにし、直接書き換えないようにしてください(状態管理の責任が分散すると事故のもとになります)。
  • この例はチャットメッセージで一覧表示する簡易版です。Tier3-43のNUIプレイヤー一覧と組み合わせれば、リスト内に拘束アイコンを表示するような、より見やすいUIにできます。
