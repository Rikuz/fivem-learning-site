ox_target × lb-phone: インタラクションをスマホ通知に連携する

やりたいこと

ox_targetのインタラクション(例: 宅配ボックスを確認する)をきっかけに、lb-phoneアプリのアイコンに新着通知バッジを表示する。

組み合わせるレッスン

  • ox_targetでインタラクションを作るTier3-07
  • アプリの新着通知バッジTier4-23

コード例

client.lua: 宅配ボックスにインタラクションを追加する

exports.ox_target:addBoxZone({
    coords = vec3(100.0, 200.0, 30.0),
    size = vec3(1.5, 1.5, 2.0),
    options = {
        {
            name = 'check_delivery_box',
            icon = 'fa-solid fa-box',
            label = '宅配ボックスを確認する',
            onSelect = function()
                TriggerServerEvent('recipe:checkDeliveryBox')
            end,
        },
    }
})

RegisterNetEvent('recipe:notifyPhone')
AddEventHandler('recipe:notifyPhone', function(count)
    exports['lb-phone']:SendCustomAppMessage('delivery_app', { action = 'updateBadge', count = count })
end)

server.lua: 未受け取り件数を確認して通知する

RegisterNetEvent('recipe:checkDeliveryBox')
AddEventHandler('recipe:checkDeliveryBox', function()
    local playerId = source
    local pendingCount = 3 -- 実際にはDBから取得する想定(Tier3-03参照)

    TriggerClientEvent('recipe:notifyPhone', playerId, pendingCount)
end)

注意点

  • SendCustomAppMessageの第1引数(アプリID)は、Config.CustomAppsに登録したキーと完全に一致させてください(Tier4-04参照)。
  • 未受け取り件数はTier3-03のDB連携で実際の値を取得するようにしてください。上記コード例は概念を示す簡略版です。
