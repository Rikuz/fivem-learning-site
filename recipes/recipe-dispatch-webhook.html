cd_dispatch × Discord Webhook: 通報を警察とDiscordの両方に送る

やりたいこと

事件が発生したら、ゲーム内の警察役プレイヤーへの通知(cd_dispatch)と、管理者向けDiscordチャンネルへのログ送信を1つの関数から同時に行う。

組み合わせるレッスン

  • cd_dispatchで警察無線通知を送るTier4-16
  • 重要操作をDiscord Webhookでログ収集するTier3-22

コード例

server.lua: 通報処理を1つの関数にまとめる

local WEBHOOK_URL = 'https://discord.com/api/webhooks/xxxxx/yyyyy' -- 実際のWebhook URLに置き換える

local function reportIncident(coords, title, message)
    -- 警察役のプレイヤーに通知する(Tier4-16参照)
    TriggerEvent('cd_dispatch:AddNotification', {
        job_table = { 'police' },
        coords = coords,
        title = title,
        message = message,
        flash = 0,
        unique_id = tostring(math.random(0, 100000)),
    })

    -- 同時にDiscordへもログを送る(Tier3-22参照)
    local payload = json.encode({
        embeds = { { title = title, description = message, color = 15158332 } }
    })

    PerformHttpRequest(WEBHOOK_URL, function() end, 'POST', payload, {
        ['Content-Type'] = 'application/json'
    })
end

-- 使用例: 強盗のドアが破られたら通報する
RegisterNetEvent('heist:doorBreached')
AddEventHandler('heist:doorBreached', function(coords)
    reportIncident(coords, '10-90 - 強盗事件', '金庫室のドアが破られました')
end)

注意点

  • PerformHttpRequestは非同期です(Tier3-03のDB処理と同じ考え方)。送信結果を厳密に確認したい場合はコールバック内で処理してください。
  • Discordへのログ送信を全ての通報で行うとレート制限に引っかかることがあります。本当に重要な事件(強盗・銃撃戦等)だけに絞ることをおすすめします(Tier3-22参照)。
