ox_libコンテキストメニュー × oxmysql: DBの内容から動的にメニューを作る

やりたいこと

固定の選択肢を書くのではなく、DBに保存された商品一覧を取得してから、その内容でox_libのコンテキストメニューを組み立てる。

組み合わせるレッスン

  • ox_libの組み込みコンテキストメニューTier3-35
  • oxmysqlのモダンな書き方Tier3-32

コード例

client.lua: サーバーから受け取った一覧でメニューを組み立てる

RegisterCommand('dynamicshop', function()
    TriggerServerEvent('recipe:requestItemList')
end, false)

RegisterNetEvent('recipe:receiveItemList')
AddEventHandler('recipe:receiveItemList', function(items)
    local options = {}

    for _, item in ipairs(items) do
        table.insert(options, {
            title = item.label,
            description = ('価格: $%s'):format(item.price),
            onSelect = function()
                TriggerServerEvent('recipe:purchaseItem', item.id)
            end,
        })
    end

    -- Tier3-35のregisterContext/showContextでメニューを表示する
    lib.registerContext({ id = 'dynamic_item_menu', title = '商品一覧', options = options })
    lib.showContext('dynamic_item_menu')
end)

server.lua: DBから商品一覧を取得して渡す

RegisterNetEvent('recipe:requestItemList')
AddEventHandler('recipe:requestItemList', function()
    local playerId = source

    -- Tier3-32のモダンAPIでDBから一覧を取得する
    local items = MySQL.query.await('SELECT id, label, price FROM shop_items ORDER BY price ASC', {})

    TriggerClientEvent('recipe:receiveItemList', playerId, items or {})
end)

注意点

  • メニューの選択肢を毎回DBから取得すると、商品数が多い・呼び出し頻度が高い場合はTier3-16のキャッシュ戦略も検討してください。
  • onSelect内で商品IDを送るだけにし、価格の再計算・在庫確認は必ずserver側で行ってください(Tier3-05参照)。
