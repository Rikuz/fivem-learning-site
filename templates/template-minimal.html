最小構成テンプレート

概要

fxmanifest.lua・client.lua・server.luaだけの、あらゆるresourceの出発点となる最小構成です。ここに必要な機能を足していくのが基本の進め方です。

ディレクトリ構造

tpl-minimal/
├── fxmanifest.lua
├── client.lua
└── server.lua

コード

fxmanifest.lua

fx_version 'cerulean'
game 'gta5'

author '自分の名前'
description 'resourceの説明をここに書く'
version '1.0.0'

client_script 'client.lua'
server_script 'server.lua'

client.lua

-- ここにclient側の処理を書く。以下は動作確認用のサンプルコマンド。

RegisterCommand('hello', function()
    print('Hello from client!')
end, false)

server.lua

-- ここにserver側の処理を書く。以下は起動確認用のログ出力。

AddEventHandler('onResourceStart', function(resourceName)
    if GetCurrentResourceName() ~= resourceName then return end
    print(('^2[%s] リソースが起動しました^0'):format(resourceName))
end)

使い方

実際のファイルはtemplates/tpl-minimal/に置いてあります。フォルダごとコピーして名前を変え、descriptionを書き換えてから機能を追加していってください。DB連携やNUIが必要な場合は、他のテンプレートも組み合わせて使えます。
