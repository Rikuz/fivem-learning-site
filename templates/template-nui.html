NUI付きリソーステンプレート

概要

開く/閉じる操作とJS↔Lua間の双方向通信を備えた、NUI画面付きresourceの土台です。Tier3-01・Tier3-02の内容をひとまとめにしたものです。

ディレクトリ構造

tpl-nui/
├── fxmanifest.lua
├── client.lua
└── ui/
    ├── index.html
    ├── style.css
    └── script.js

コード

fxmanifest.lua

fx_version 'cerulean'
game 'gta5'

author '自分の名前'
description 'NUI付きresourceテンプレート'
version '1.0.0'

ui_page 'ui/index.html'

files {
    'ui/index.html',
    'ui/style.css',
    'ui/script.js'
}

client_script 'client.lua'

client.lua

local isOpen = false

RegisterCommand('opennui', function()
    if isOpen then return end
    isOpen = true

    SetNuiFocus(true, true)
    SendNUIMessage({ action = 'open' })
end, false)

RegisterNUICallback('close', function(data, cb)
    isOpen = false
    SetNuiFocus(false, false)
    cb('ok')
end)

-- JS側からLuaへデータを送る例(Tier3-02参照)
RegisterNUICallback('submitData', function(data, cb)
    print('NUIから受け取ったデータ:', json.encode(data))
    cb('ok')
end)

ui/script.js

function post(name, body) {
  return fetch(`https://${GetParentResourceName()}/${name}`, {
    method: 'POST',
    headers: { 'Content-Type': 'application/json; charset=UTF-8' },
    body: JSON.stringify(body || {}),
  });
}

window.addEventListener('message', (event) => {
  const data = event.data;
  if (data.action === 'open') {
    document.getElementById('app').classList.remove('hidden');
  }
});

document.getElementById('submit-btn').addEventListener('click', () => {
  const text = document.getElementById('text-input').value;
  post('submitData', { text });
});

document.getElementById('close-btn').addEventListener('click', () => {
  document.getElementById('app').classList.add('hidden');
  post('close');
});

使い方

実際のファイルはtemplates/tpl-nui/に置いてあります。/opennuiで開き、入力して送信するとLua側のprintにデータが出力されます。画面のレイアウトはui/index.html・ui/style.cssを書き換えて作り込んでください。
