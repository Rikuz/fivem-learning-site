StateBags同期リソーステンプレート

概要

プレイヤーの状態を全clientに同期し、変化を監視して反映する、マルチプレイヤー同期resourceの土台です。Tier5-03の内容を土台にしています。

ディレクトリ構造

tpl-statebags/
├── fxmanifest.lua
├── client.lua
└── server.lua

コード

fxmanifest.lua

fx_version 'cerulean'
game 'gta5'

author '自分の名前'
description 'StateBags同期resourceテンプレート'
version '1.0.0'

client_script 'client.lua'
server_script 'server.lua'

server.lua

-- プレイヤーの状態をStateBagsで管理し、全clientに同期する(Tier5-03参照)
RegisterCommand('setstatus', function(source, args)
    local playerId = source
    local status = args[1] or 'idle'

    -- 第3引数をtrueにすると全clientに同期される(replicated)
    Player(playerId).state:set('myStatus', status, true)
end, false)

client.lua

-- 他プレイヤーのStateBagsの変化を監視する(Tier5-03参照)
AddStateBagChangeHandler('myStatus', '', function(bagName, key, value, reserved, replicated)
    print(('%sのmyStatusが%sに変わりました'):format(bagName, tostring(value)))
end)

-- 自分自身の状態を確認する
RegisterCommand('mystatus', function()
    local status = LocalPlayer.state.myStatus
    print('自分の状態:', status or '未設定')
end, false)

-- 特定エンティティの状態を確認する例
local function getEntityStatus(entity)
    return Entity(entity).state.myStatus
end

使い方

実際のファイルはtemplates/tpl-statebags/に置いてあります。myStatusというキー名・値の中身を自分の用途(拘束状態、勤務状態、所属チーム等)に合わせて書き換えてください。1フレームごとに変わるような値には向かない点に注意してください(Tier5-03参照)。
