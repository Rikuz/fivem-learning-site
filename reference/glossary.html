用語集・FAQ

サイト内で繰り返し登場する用語をカテゴリ別にまとめています。各レッスンの初出時にも簡単な補足を入れていますが、まとめて引きたいときはこのページを使ってください。

基礎用語

resource(リソース)
FiveMにおけるスクリプトの単位。1つのフォルダが1つのresourceに対応し、必ずfxmanifest.luaを持つ。→ Tier1-03
fxmanifest.lua
resourceの設定ファイル。fx_version・使用するLuaファイル・依存関係(dependency)などを宣言する。→ Tier1-04
native関数
FiveMがゲームエンジン(RAGE)を直接操作するために提供する組み込み関数。CreatePed・GetEntityCoords等。→ Tier1-10
convar
サーバー起動時にserver.cfgで設定できる変数。GetConvar()で読み取る。→ Tier1-12
識別子(identifier)
プレイヤーを一意に特定する文字列。license・steam・discord等の種類がある。→ Tier2-20
client側 / server側
FiveMのLuaコードは実行される場所によって、各プレイヤーのPCで動く「client側」とサーバー機で動く「server側」に分かれる。同じイベント名でも登録場所によって挙動が異なる。
ensure / restart / refresh
サーバーコンソールで使うresource操作コマンド。ensureは起動、restartは再起動、refreshはresourceリストの再読み込み。

イベント・通信関連

event(イベント)
RegisterNetEvent/TriggerEvent等で発火・購読する、resource間・client-server間の非同期メッセージング機構。→ Tier2-01
export
他のresourceから関数を呼び出せるように公開する仕組み。exports('名前', 関数)で公開し、exports['resource名']:名前()で呼び出す。→ Tier3-06
RegisterCommand
チャット欄やコンソールから/コマンド名で実行できる処理を登録する。→ Tier2-04
TriggerEvent / TriggerServerEvent / TriggerClientEvent
それぞれ「同じ側で発火」「serverへ送る」「特定または全clientへ送る」の3種類のイベント発火方法。

NUI(画面UI)関連

NUI
FiveMが内蔵するChromiumベースのブラウザで描画するUI画面。HTML/CSS/JSで作る。→ Tier3-01
SetNuiFocus
NUIにマウス/キーボード操作を渡す、または戻すnative。SetNuiFocus(true, true)で渡し、SetNuiFocus(false, false)で戻す。→ Tier3-01
RegisterNUICallback
JS側のfetch()から送られたデータをLua側で受け取る仕組み。→ Tier3-02
ui_page
fxmanifest.luaでNUIのエントリポイント(HTMLファイル)を指定するディレクティブ。

DB連携関連

oxmysql
FiveMで広く使われるMySQL連携リソース。→ Tier3-03
MySQL.query / MySQL.insert / MySQL.update / MySQL.scalar
oxmysqlのモダンAPI関数群。用途に応じて戻り値の形が異なる(全行/挿入ID/影響行数/単一値)。→ Tier3-32
プレースホルダー(?)
SQL文中の値を安全に埋め込むための書き方。文字列連結ではなくこれを使うことで、SQLインジェクションを防げる。

マルチプレイヤー同期関連

StateBags
プレイヤーやエンティティに紐づく、多くのclientで共有される状態データ。Entity(ent).state:set(...)やPlayer(id).state:set(...)で操作する。→ Tier5-03
replicated
StateBagsの:set()の第3引数。trueにすると全clientに同期され、falseだとserver内でしか見えない。
routing bucket(ルーティングバケット)
プレイヤー・エンティティの見える範囲(インスタンス)を分離する仕組み。強盗ミッション等で他プレイヤーと干渉しない専用空間を作るのに使う。→ Tier5-08

外部スクリプト・フレームワーク関連

ox_lib
Overextended製の汎用ユーティリティライブラリ。通知・プログレスバー・コンテキストメニュー・入力ダイアログ等を提供する。→ Tier3-08
ox_target / qb-target
マウスカーソルでのインタラクションメニュー(「ドアを開ける」等の選択肢表示)を提供するリソース。→ Tier3-07
ox_inventory
アイテム・インベントリ管理リソース。AddItem/RemoveItem/RegisterStash/RegisterShop等を提供する。→ Tier3-30
ox_doorlock
ドアの施錠・解錠を管理するリソース。ドアの登録自体はゲーム内コマンドで行う。→ Tier4-14
lb-phone
スマートフォンUIを提供するリソース。Config.CustomAppsにアプリを登録することでカスタムアプリを追加できる。→ Tier4-04
okokシリーズ
okokNotify・okokTextUI・okokBankingV2等、コミュニティで広く使われる通知・銀行システム等のスクリプト群。→ Tier4-03
ESX / QBCore / Qbox / ox_core
FiveMの代表的なロールプレイフレームワーク。プレイヤーデータ・Job・所持金等を統一的に管理する。テーブル構造は互いに異なる。→ Tier4-01

管理者・運用関連

txAdmin
FXServerに標準同梱されるWeb管理パネル。権限管理・バックアップ・リソース監視等を行える。→ Tier1-14
ACE権限
FiveMのアクセス制御の仕組み。add_ace/add_principalで権限をプレイヤーやグループに付与する。→ Tier2-04
Discord Webhook
Discordのチャンネルに外部からメッセージを送信できる、あらかじめ発行されたURL。PerformHttpRequestで送信する。→ Tier3-22
