通報・チケットシステムの基礎

結論

このレッスンを終えると、プレイヤーからの通報(不具合報告・迷惑行為の報告)をDBに記録し、管理者が一覧表示・対応済みにできる簡易チケットシステムを作れるようになります。

こんな時に使う: 「チートを見た」「バグを見つけた」という報告を、Discordだけでなくゲーム内から手軽に送れるようにしたいとき。

説明

通報システムは、プレイヤーが送った内容をDBに保存し、管理者側がその一覧を確認できるようにする、という単純な仕組みです。Tier3-20の管理者メニューと組み合わせて実装するのが自然です。

コード例

テーブル設計

# reports テーブル
# id | reporter_id | message              | status  | created_at
# 1  | 42          | チートを見ました    | open    | 2026-08-10 10:00:00

server.lua: 通報を受け取ってDBに保存する

RegisterNetEvent('report:submit')
AddEventHandler('report:submit', function(message)
    local source = source

    if not message or #message < 5 then
        TriggerClientEvent('myscript:notify', source, '通報内容が短すぎます')
        return
    end

    MySQL.Async.execute('INSERT INTO reports (reporter_id, message, status) VALUES (@id, @msg, "open")', {
        ['@id'] = source,
        ['@msg'] = message
    }, function()
        TriggerClientEvent('myscript:notify', source, '通報を送信しました')
    end)
end)

server.lua: 管理者が一覧を取得・対応済みにする

RegisterNetEvent('report:requestList')
AddEventHandler('report:requestList', function()
    local source = source
    if not IsPlayerAceAllowed(source, 'command.adminmenu') then return end

    MySQL.Async.fetchAll('SELECT * FROM reports WHERE status = "open" ORDER BY created_at DESC', {}, function(reports)
        TriggerClientEvent('report:showList', source, reports)
    end)
end)

RegisterNetEvent('report:resolve')
AddEventHandler('report:resolve', function(reportId)
    local source = source
    if not IsPlayerAceAllowed(source, 'command.adminmenu') then return end

    MySQL.Async.execute('UPDATE reports SET status = "resolved" WHERE id = @id', { ['@id'] = reportId })
end)

注意点・よくあるミス

  • 通報メッセージを何のチェックもなく受け付けると、スパム(同じ内容を連投する)やHTMLインジェクション的な文字列を混入されるリスクがあります。文字数制限や、Tier5-04で学んだレート制限の考え方を組み合わせてください。
  • statusのようなフィールドで「未対応/対応済み」を管理しないと、管理者が同じ通報を何度も確認することになります。
  • 通報者(reporter_id)がどのプレイヤーか分かるようにしておくと、詳しい状況を聞きたいときに追跡できます。ただし、通報内容自体を他プレイヤーに公開しないよう、閲覧権限は管理者に限定してください。

補足

より即応性を高めたい場合は、通報が届いた瞬間にTier3-22「重要操作をDiscord Webhookでログ収集する」と組み合わせて、管理者のDiscordにリアルタイム通知することもできます。
