ox_libの組み込みコンテキストメニュー

結論

このレッスンを終えると、ox_libのlib.registerContext/lib.showContextで、選択肢一覧のメニュー(コンテキストメニュー)とサブメニューを数行で作ることができるようになります。Tier3-13で自作したコンテキストメニューと同じ役割のものを、NUIファイルを1行も書かずに実現できます。

説明

lib.registerContextにメニューの構造(id・タイトル・選択肢のリスト)を渡して登録し、lib.showContext(id)で表示します。選択肢はevent(clientイベント)、serverEvent(serverイベント)、onSelect(直接呼ばれる関数)のいずれかで動作を指定でき、menuを指定すると別のメニューへ遷移する「サブメニュー」も作れます。

コード例

基本のメニュー登録・表示

lib.registerContext({
    id = 'garage_menu',
    title = 'Personal Garage',
    options = {
        {
            title = 'Retrieve Vehicle',
            description = 'Spawn your last saved car.',
            event = 'garage:retrieveVehicle',
        },
        {
            title = 'Store Vehicle',
            description = 'Save the vehicle you are currently in.',
            event = 'garage:storeVehicle',
        },
    },
})

RegisterCommand('garage', function()
    lib.showContext('garage_menu')
end, false)

onSelectで直接処理する例

lib.registerContext({
    id = 'shop_menu',
    title = 'ショップ',
    options = {
        {
            title = '水を買う ($20)',
            icon = 'bottle-water',
            onSelect = function()
                TriggerServerEvent('shop:buyItem', 'water')
            end,
        },
    },
})

サブメニューを作る

lib.registerContext({
    id = 'main_menu',
    title = 'メインメニュー',
    options = {
        { title = 'ショップを開く', menu = 'shop_menu' }, -- 別メニューのidを指定するとサブメニューになる
    },
})

RegisterCommand('menu', function()
    lib.showContext('main_menu')
end, false)

注意点・よくあるミス

  • optionsは連番キー(配列)で書いてください。{ ['a'] = {...}, ['b'] = {...} }のように文字列キーにすると、ox_libがアルファベット順に並び替えてしまい、意図した表示順になりません。
  • event/serverEvent/onSelectは複数同時に指定しても1つしか有効に機能しません。用途に応じてどれか1つを選んでください。
  • お金の増減などサーバー権威が必要な処理をonSelect(client側で直接実行される関数)に書くと、Tier3-05のバリデーションが抜けてしまいます。serverEventを使うか、onSelect内からTriggerServerEventを呼ぶ形にしてください。

補足

本レッスンの構文は公式ドキュメント(overextended.dev/docs/ox_lib/Interface/Client/context)で確認済みです。Tier3-13の自作コンテキストメニューと比べて、アイコン表示・サブメニュー・並び替えといった機能が最初から揃っているのが利点です。シンプルな用途なら自作、機能が欲しいならox_libの利用を検討してください。
