ox_inventoryにアイテムを追加する

結論

このレッスンを終えると、ox_inventoryにまだ存在しない新しいアイテムを、自分で定義して使えるようにすることができるようになります。Tier3-04では既に存在する'water'や'bread'のようなアイテムを増減させる方法を学びましたが、そのアイテム自体が「どこでどう定義されているか」を扱うのがこのレッスンです。

説明

ox_inventoryのアイテムは、ox_inventory本体のdata/items.luaというファイルに、アイテム名をキーとした連想配列(テーブル)として定義されています。ここに新しいキーを追加するだけで、AddItem/RemoveItem(Tier3-04)から使える新しいアイテムになります。

コード例

data/items.lua: 新しいアイテムを追加する

['burger'] = {
    label = 'Burger',
    description = 'Just what is the secret formula?',
    weight = 220,
    stack = true,
    close = true,
    client = {
        status = { hunger = 200000 },
        anim = { dict = 'mp_player_inteat@burger', clip = 'mp_player_int_eat_burger_fp' },
        prop = {
            model = 'prop_cs_burger_01',
            pos = { x = 0.02, y = 0.02, z = -0.02 },
            rot = { x = 0.0, y = 0.0, z = 0.0 }
        },
        usetime = 2500,
    }
}

シンプルな道具アイテムの例(食べ物以外)

['lockpick'] = {
    label = 'ロックピック',
    description = '鍵をこじ開けるための道具',
    weight = 100,
    stack = true,
    close = false, -- 使用してもインベントリを閉じない
    consume = 1,   -- 使用のたびに1個消費する
}

追加したアイテムをTier3-04の方法で操作する

-- 新しく定義した'burger'をそのままAddItem/RemoveItemで使える
exports.ox_inventory:AddItem(source, 'burger', 1)

注意点・よくあるミス

  • 主なフィールド: label(表示名), description(説明文), weight(重量。インベントリの重量制限計算に使われる), stack(同じアイテムをまとめて持てるか), close(使用時にインベントリ画面を自動で閉じるか), consume(使用のたびに消費する個数。小数を指定すると耐久値として扱われる)。用途に合わせて過不足なく設定してください。
  • アイテム画像は既定ではweb/images/アイテム名.pngというファイル名で自動的に読み込まれます。burgerならweb/images/burger.pngを用意してください。画像がないとインベントリ上でアイコンが表示されません。
  • アイテム名(キー)に日本語や記号、スペースを使うとエラーの原因になります。英数字とアンダースコアのみを使ってください(表示名はlabelで日本語にできます)。
  • data/items.luaはox_inventory本体側のファイルです。直接編集するとox_inventoryのアップデート時に上書きされる可能性があるため、実運用ではox_inventoryが対応しているアイテム追加専用の仕組み(バージョンによって異なる)を確認してから編集してください。

補足

本レッスンのフィールド名・コード例は公式ドキュメント(overextended.dev/docs/ox_inventory/Guides/creatingItems)で確認済みです。次のレッスン(Tier3-31)では、このアイテムをインベントリ画面から実際に「使用」できるようにする方法(usable item)を扱います。バージョンによって仕様が変わる場合があるため、公式ドキュメントも確認してください。
