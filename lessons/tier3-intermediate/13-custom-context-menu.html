🟠 中級 🖥️ UI表示(NUI)

独自のコンテキストメニューを自作する

結論

このレッスンを終えると、ox_libに頼らず、Lua側から選択肢のリストを渡して選ばせるコンテキストメニューを自作できるようになります。ox_lib(Tier3-08)の内部で何が行われているかの理解にもつながります。

こんな時に使う: ox_libを導入せずに軽量なメニューだけ実装したい、既存のNUIデザインに合わせた独自の見た目のメニューが欲しいとき。

説明

コンテキストメニューは、Tier3-01・Tier3-02で学んだNUIの基本パターン(SendNUIMessageで選択肢を渡し、RegisterNUICallbackで選ばれた項目を受け取る)をそのまま応用したものです。

コード例

client.lua: メニューを開く

local function openContextMenu(options)
    SetNuiFocus(true, true)
    SendNUIMessage({
        action = 'openMenu',
        options = options
    })
end

RegisterCommand('shopmenu', function()
    openContextMenu({
        { id = 'buy_water', label = '水を買う ($20)' },
        { id = 'buy_bread', label = 'パンを買う ($30)' },
        { id = 'close',     label = '閉じる' },
    })
end, false)

ui/script.js: 選択肢を描画し、選ばれたら通知する

window.addEventListener('message', (event) => {
  const data = event.data;
  if (data.action === 'openMenu') {
    const list = document.getElementById('menu-list');
    list.innerHTML = '';

    data.options.forEach((option) => {
      const item = document.createElement('button');
      item.textContent = option.label;
      item.addEventListener('click', () => selectOption(option.id));
      list.appendChild(item);
    });

    document.getElementById('app').style.display = 'block';
  }
});

function selectOption(optionId) {
  fetch(`https://${GetParentResourceName()}/menuSelect`, {
    method: 'POST',
    headers: { 'Content-Type': 'application/json; charset=UTF-8' },
    body: JSON.stringify({ id: optionId })
  });
  document.getElementById('app').style.display = 'none';
}

client.lua: 選択結果を受け取る

RegisterNUICallback('menuSelect', function(data, cb)
    SetNuiFocus(false, false)

    if data.id == 'buy_water' then
        TriggerServerEvent('shop:buyItem', 'water')
    elseif data.id == 'buy_bread' then
        TriggerServerEvent('shop:buyItem', 'bread')
    end

    cb('ok')
end)

注意点・よくあるミス

  • メニューの選択肢に含まれる「価格」等の表示用テキストは、あくまで表示のためだけに使ってください。実際の購入処理(Tier3-05)では、Lua側(server)で保持している正しい価格を使い、JS側から送られてきた表示用の値は信用しないでください。
  • 選択肢が多くなるメニューでは、Tier3-14「通知のキュー管理」と同様に、UIの表示状態(開いているか/閉じているか)をJS側で正しく管理しないと、複数回開いたときに表示が重なるバグが起きやすくなります。

補足

ox_lib(Tier3-08)のlib.registerContext/lib.showContextは、この自作パターンをより洗練させ、アイコン・アニメーション・ネストしたメニュー(サブメニュー)まで含めて提供してくれるものです。シンプルな用途では自作、複雑な用途ではox_libの利用も検討してください。
