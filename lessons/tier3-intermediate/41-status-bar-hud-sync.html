ステータスバー(体力/満腹度/喉の渇き等)の同期

結論

このレッスンを終えると、体力・満腹度・喉の渇きといった複数のステータス値をHUDのバー表示に同期することができるようになります。体力はFiveM標準nativeから、満腹度・喉の渇きのようなフレームワーク独自の値は汎用的な取得関数を経由する設計にすることで、ESX/QBCore/Qboxのどれでも同じHUDコードが使い回せます。

こんな時に使う: Tier3-39・Tier3-40で作ったHUDに、体力バーと満腹度・喉の渇きバーを追加したいとき。

説明

体力(GetEntityHealth)はFiveM標準のnativeで直接取得できますが、満腹度・喉の渇きはフレームワークごとにデータの持ち方が異なります(例: ESXはxPlayer.hunger、QBCoreはPlayerData.metadata.hungerなど)。この違いをHUD側のコードに直接書いてしまうと、フレームワークを変えるたびにHUDを書き直すことになります。そこで「満腹度を取得する」という汎用関数だけをHUD側が呼び、中身の実装はフレームワークごとに差し替えるという設計にします。

コード例

client.lua: 体力とステータス値をまとめてHUDに送る

-- getHungerValue/getThirstValueは、導入しているフレームワークに合わせて実装する想定の関数(Tier4-01参照)
-- ここでは概念を示すため、固定値を返すダミー実装にしている

local function getHungerValue()
    return 80 -- 実際にはESX/QBCore等のプレイヤーデータから取得する
end

local function getThirstValue()
    return 65
end

CreateThread(function()
    while true do
        Wait(1000) -- 体力ほど頻繁に変わらないため、更新間隔を長めにする

        local ped = PlayerPedId()
        SendNUIMessage({
            action = 'updateStatusBars',
            health = GetEntityHealth(ped) - 100, -- GetEntityHealthは最低値100を返すため補正する
            hunger = getHungerValue(),
            thirst = getThirstValue(),
        })
    end
end)

ui/script.js: バーの幅を割合で反映する

window.addEventListener('message', (event) => {
  const data = event.data;
  if (data.action !== 'updateStatusBars') return;

  document.getElementById('health-bar').style.width = `${Math.max(0, data.health)}%`;
  document.getElementById('hunger-bar').style.width = `${data.hunger}%`;
  document.getElementById('thirst-bar').style.width = `${data.thirst}%`;
});

注意点・よくあるミス

  • GetEntityHealthはGTA V内部の仕様上、最低値が100(死亡状態の少し手前)です。バーの割合として使う場合はGetEntityHealth(ped) - 100のように補正し、0〜100の範囲になるよう変換してください。
  • 満腹度・喉の渇きの取得処理をHUDのコードに直接ベタ書きすると、フレームワークを変更した際に修正箇所が分散します。上記コード例のように専用関数(getHungerValue等)にまとめておくと、差し替えが1箇所で済みます。
  • 更新間隔を体力・満腹度・喉の渇きで別々にする(体力は短く、満腹度・喉の渇きは長く)と、無駄なSendNUIMessage呼び出しを減らせます。

補足

ESX/QBCore/Qboxそれぞれの満腹度・喉の渇きの正確なデータ構造は、フレームワークのバージョンによって変わることがあります。実際に導入する際は、各フレームワークの公式ドキュメントで最新のプレイヤーデータ構造を確認してください。これでカスタムHUDの主要な3要素(常駐表示・スピードメーター/ミニマップ・ステータスバー)が揃いました。演習ex-14ではこれらを1つのHUDリソースに統合します。
