スピードメーター・ミニマップのカスタマイズ

結論

このレッスンを終えると、車両の速度を取得してHUDに表示するスピードメーターと、ミニマップの位置・サイズを自作HUDに合わせて調整することができるようになります。Tier3-39の常駐HUDの実践的な応用です。

こんな時に使う: Tier4-33で貸し出す配送車両にスピード表示を付けたい、自作HUDのレイアウトに合わせてミニマップの位置をずらしたいとき。

説明

速度の取得はGetEntitySpeedという1つのnativeで完結します(戻り値はm/sなので、km/h表示にするには3.6倍します)。ミニマップの位置調整はSetMinimapComponentPositionというnativeで、frontend.xmlで定義されている座標系を上書きする形で行います。どちらもTier3-39で作った常駐HUDのスレッド内で扱います。

コード例

client.lua: 乗車中の車両の速度をHUDに送る

CreateThread(function()
    while true do
        Wait(200)

        local ped = PlayerPedId()
        local vehicle = GetVehiclePedIsIn(ped, false)

        if vehicle ~= 0 then
            local speedMs = GetEntitySpeed(vehicle)
            local speedKmh = math.floor(speedMs * 3.6) -- m/s → km/hに変換

            SendNUIMessage({ action = 'updateSpeed', visible = true, speed = speedKmh })
        else
            SendNUIMessage({ action = 'updateSpeed', visible = false })
        end
    end
end)

ui/script.js: スピードメーターの表示切り替え

window.addEventListener('message', (event) => {
  const data = event.data;
  if (data.action !== 'updateSpeed') return;

  const speedo = document.getElementById('speedometer');
  speedo.style.display = data.visible ? 'block' : 'none';
  if (data.visible) {
    speedo.textContent = `${data.speed} km/h`;
  }
});

client.lua: ミニマップの位置・サイズを自作HUDに合わせて調整する

CreateThread(function()
    Wait(1000) -- HUDの初期化を待ってから適用する

    -- SetMinimapComponentPosition(name, alignX, alignY, posX, posY, sizeX, sizeY)
    -- alignX/alignYは "L"(左) "R"(右) "T"(上) "B"(下) を組み合わせて基準位置を指定する
    SetMinimapComponentPosition('minimap', 'L', 'B', 0.0, -0.047, 0.1638, 0.183)
    SetMinimapComponentPosition('minimap_mask', 'L', 'B', 0.020, 0.020, 0.128, 0.20)
    SetMinimapComponentPosition('minimap_blur', 'L', 'B', -0.008, 0.010, 0.170, 0.240)
end)

注意点・よくあるミス

  • GetEntitySpeedは徒歩中のped(プレイヤー自身)にも使えますが、車両のスピードメーターとしては必ずGetVehiclePedIsInで取得した車両ハンドルに対して呼び出してください。
  • SetMinimapComponentPositionの座標系は画面解像度に対する相対値(0.0〜1.0程度)です。数値を大きく変えるとミニマップが画面外にはみ出すので、少しずつ調整しながら確認してください。
  • ミニマップ位置の調整は、他のリソース(既存のHUDリソースなど)と競合すると意図しない位置に表示されることがあります。同じ機能を持つリソースを重複して導入しないよう注意してください。

補足

解像度やアスペクト比(ウルトラワイドモニター等)によってミニマップの見え方が変わることがあります。本番導入時は複数の解像度で見た目を確認することをおすすめします。次のレッスン(Tier3-41)では、体力・満腹度・喉の渇きといったステータスバーをHUDに追加します。
