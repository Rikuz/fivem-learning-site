オンラインプレイヤー一覧とスペクテイト/ノークリップ

結論

このレッスンを終えると、オンライン中のプレイヤー一覧をNUIに表示し、選択したプレイヤーをスペクテイト(観戦)することと、管理者自身がノークリップ(壁抜け飛行)で自由に移動することができるようになります。Tier3-42の権限レベルと組み合わせて、実用的な管理者ツールの中核機能を実装します。

こんな時に使う: 通報(Tier3-21)を受けた際に、対象プレイヤーの様子を離れた場所からこっそり確認したいとき。

説明

プレイヤー一覧はGetPlayers()(接続中の全プレイヤーIDを返す)から作れます。スペクテイトはNetworkSetInSpectatorModeで対象のpedにカメラを切り替える仕組みです。ノークリップは単一のnativeではなく、「衝突判定を無効化」「重力を無効化」「移動速度を上げる」という複数のnativeを組み合わせて自作するのが一般的です。

コード例

server.lua: 権限を確認してプレイヤー一覧を送る

RegisterNetEvent('adminpanel:requestPlayerList')
AddEventHandler('adminpanel:requestPlayerList', function()
    local playerId = source
    if not hasPermission(playerId, 'moderator') then return end -- Tier3-42参照

    local playerList = {}
    for _, targetId in ipairs(GetPlayers()) do
        table.insert(playerList, {
            id = tonumber(targetId),
            name = GetPlayerName(targetId),
        })
    end

    TriggerClientEvent('adminpanel:receivePlayerList', playerId, playerList)
end)

client.lua: 選択したプレイヤーをスペクテイトする

local isSpectating = false

RegisterNetEvent('adminpanel:spectatePlayer')
AddEventHandler('adminpanel:spectatePlayer', function(targetServerId)
    local targetPed = GetPlayerPed(GetPlayerFromServerId(targetServerId))
    if targetPed == 0 then return end

    NetworkSetInSpectatorMode(true, targetPed)
    isSpectating = true
end)

RegisterCommand('stopspectate', function()
    if not isSpectating then return end
    NetworkSetInSpectatorMode(false, PlayerPedId())
    isSpectating = false
end, false)

client.lua: ノークリップ(壁抜け飛行)を実装する

local noclipEnabled = false

RegisterCommand('togglenoclip', function()
    local ped = PlayerPedId()
    noclipEnabled = not noclipEnabled

    SetEntityCollision(ped, not noclipEnabled, not noclipEnabled)
    SetEntityInvincible(ped, noclipEnabled)
    SetEntityVisible(ped, not noclipEnabled, false)
end, false)

CreateThread(function()
    while true do
        Wait(0)
        if noclipEnabled then
            local ped = PlayerPedId()
            local coords = GetEntityCoords(ped)
            local forward = GetEntityForwardVector(ped)
            local speed = 0.5

            -- 前進キー(control 32)が押されている間、向いている方向に移動する
            if IsControlPressed(0, 32) then
                SetEntityCoords(ped, coords.x + forward.x * speed, coords.y + forward.y * speed, coords.z + forward.z * speed, false, false, false, false)
            end
        end
    end
end)

注意点・よくあるミス

  • プレイヤー一覧・スペクテイト機能は必ずTier3-42の権限チェックを通してください。誰でも他人をスペクテイトできると、プライバシー上の問題になります。
  • スペクテイトを終了する際は、必ずNetworkSetInSpectatorMode(false, PlayerPedId())を呼んでカメラを自分のpedに戻してください。呼び忘れると視点が対象プレイヤーに固定されたままになります。
  • ノークリップ終了時は、SetEntityCollision・SetEntityVisibleを元に戻すのを忘れないでください。衝突判定が無効なままだと、地面に埋まったり壁を抜けたままプレイを続けてしまう不具合になります。
  • 上記のノークリップ実装は概念を示す簡略版です。カメラの向きに応じた自由な移動(上下移動・視点連動)まで作り込む場合は、GetGameplayCamRotと組み合わせた発展が必要になります。

補足

スペクテイト・ノークリップは管理者ツールの中でも強い権限を伴う機能です。誰がいつ使用したかをTier3-22のDiscord Webhookログに記録しておくと、後から利用状況を追跡できます。これで管理者パネルの主要機能(権限レベル・プレイヤー一覧・スペクテイト・ノークリップ)が揃いました。演習ex-15ではこれらとTier4-07・Tier4-11・Tier3-21・Tier3-22を1つのパネルに統合します。
