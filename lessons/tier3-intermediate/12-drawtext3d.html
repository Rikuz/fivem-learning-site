🟠 中級 🖥️ UI表示(NUI)

頭上にフローティングテキストを表示する

結論

このレッスンを終えると、ワールド上の特定の座標(NPCの頭上など)に文字を表示する自作のDrawText3Dを実装できるようになります。

こんな時に使う: プレイヤーの名前タグを頭上に表示したい、NPCの上に「[E] 話す」のようなヒントを出したいとき(Tier4-03のokokTextUIとは別の、画面固定ではなくワールド追従型の表示方法です)。

説明

FiveMのnative関数には、3D座標を直接指定してテキストを描画する専用関数はありません。代わりにGetScreenCoordFromWorldCoordのような関数で3D座標を2Dの画面座標に変換し、通常のHUDテキスト描画関数(SetTextEntry系)でその位置に描画する、という2段階の処理を組み合わせます。

コード例

client.lua: DrawText3D関数を自作する

local function drawText3D(x, y, z, text)
    local onScreen, screenX, screenY = World3dToScreen2d(x, y, z)
    local playerCoords = GetGameplayCamCoord()
    local distance = #(playerCoords - vector3(x, y, z))

    local scale = (1.0 / distance) * 2.0
    local fov = (1.0 / GetGameplayCamFov()) * 100.0
    scale = scale * fov

    if onScreen then
        SetTextScale(0.0 * scale, 0.55 * scale)
        SetTextFont(4)
        SetTextProportional(1)
        SetTextColour(255, 255, 255, 215)
        SetTextDropshadow(0, 0, 0, 0, 255)
        SetTextEdge(2, 0, 0, 0, 150)
        SetTextDropShadow()
        SetTextOutline()
        SetTextEntry('STRING')
        SetTextCentre(1)
        AddTextComponentString(text)
        DrawText(screenX, screenY)
    end
end

使用例: NPCの頭上に名前を表示する

local npcCoords = vector3(100.0, 200.0, 31.0) -- 頭の高さ分z座標を足した値

CreateThread(function()
    while true do
        local playerCoords = GetEntityCoords(PlayerPedId())
        local distance = #(playerCoords - npcCoords)

        if distance < 10.0 then
            drawText3D(npcCoords.x, npcCoords.y, npcCoords.z, '雑貨屋の店員')
            Wait(0)
        else
            Wait(500)
        end
    end
end)

注意点・よくあるミス

  • Marker(Tier2-03)やScaleform(Tier3-11)と同様、毎フレーム呼び続けないと表示されません。表示したい間はループの中で呼び出し続けてください。
  • World3dToScreen2dは、指定した座標が画面外(カメラの後ろ側など)にある場合、1つ目の戻り値(onScreen)がfalseになります。必ずこの値を確認してから描画してください。確認しないと、カメラの後ろにあるテキストが画面に大きく引き伸ばされて表示されるバグになります。
  • 距離に応じた文字サイズ調整(scaleの計算)を省略すると、遠くのテキストも近くのテキストと同じ大きさで表示され、不自然に見えます。

補足

この仕組みはコミュニティで広く使われている定番パターンで、多くのフレームワークやスクリプトが同様の自作DrawText3D関数を持っています。Tier2-11で学んだ距離に応じたWait調整と組み合わせて、負荷を抑えるようにしましょう。
