NUIの基礎(画面UIを表示する)

結論

このレッスンを終えると、HTML/CSS/JSで作った画面をプレイヤーの画面上に表示し、Lua側からそのUIにデータを送ることができるようになります。これをNUI(FiveMの組み込みブラウザ機能。ゲーム画面の上に独自のHTML画面を重ねて表示できる)と呼びます。

説明

NUIの実体は、resource内に置いたHTML/CSS/JSファイル一式です。fxmanifest.luaでui_pageにエントリーポイントのHTMLを指定し、filesに関連ファイルを列挙します。

Lua側からSendNUIMessage(データ)を呼ぶと、JS側でwindow.addEventListener('message', ...)がそのデータを受け取れます。またマウス操作をUIに向けたい場合はSetNuiFocus(true, true)でフォーカスを移します(これを呼ばないと、UIが表示されていてもプレイヤーの操作はゲーム側に渡ったままになります)。

コード例

fxmanifest.lua

fx_version 'cerulean'
game 'gta5'

client_script 'client.lua'

ui_page 'ui/index.html'

files {
    'ui/index.html',
    'ui/style.css',
    'ui/script.js'
}

client.lua

RegisterCommand('opennui', function()
    SetNuiFocus(true, true) -- マウス操作をUI側に渡す

    SendNUIMessage({
        action = 'open',
        message = 'ようこそ!'
    })
end, false)

ui/index.html

<!doctype html>
<html>
<head>
  <meta charset="utf-8">
  <link rel="stylesheet" href="style.css">
</head>
<body>
  <div id="app" class="app">
    <p id="message">まだメッセージを受信していません</p>
  </div>
  <script src="script.js"></script>
</body>
</html>

ui/script.js

window.addEventListener('message', (event) => {
    const data = event.data;

    if (data.action === 'open') {
        document.getElementById('app').style.display = 'block';
        document.getElementById('message').textContent = data.message;
    }
});

実際に動かして確認できるサンプル一式を samples/nui-basics/index.html に用意しています。ブラウザで開き、画面左下の「デモ」ボタンを押すと、SendNUIMessageを受信した想定の動きを確認できます(FiveM実機では、このデモボタンの代わりに実際のLua側からのメッセージで表示されます)。

注意点・よくあるミス

  • filesに列挙し忘れたファイル(CSS/JS/画像など)は、実際のFiveM環境では404になり読み込まれません。ui_pageのHTMLだけでなく、そこから読み込む全てのファイルをfilesに含める必要があります。
  • SetNuiFocus(true, true)を呼ばないと、UIは表示されてもクリックやキー入力がゲーム側に渡ったままになり、ボタンが押せません。UIを閉じるときはSetNuiFocus(false, false)を忘れずに呼び戻してください。
  • NUIのHTMLはFiveMの組み込みブラウザ(CEF)で描画されます。通常のWebブラウザとほぼ同じですが、一部の最新Web APIが使えない場合があります。

補足

NUIの背景を透過させたい場合(HUDのように画面の一部だけに表示したい場合)は、CSSのbody { background: transparent; }を指定します(サンプルにも反映済みです)。次のレッスンでは、逆にJS側からLua側へデータを送る「NUIコールバック」を学びます。
