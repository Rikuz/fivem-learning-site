重要操作をDiscord Webhookでログ収集する

結論

このレッスンを終えると、お金の増減・BAN・管理者コマンドの実行など、重要な操作が起きたときにDiscordのチャンネルへ自動で通知を送ることができるようになります。

こんな時に使う: 「誰が・いつ・いくらお金を配ったか」を後から確認したい、不正操作の証跡を残したい、DBを直接見なくてもDiscordで運用状況を把握したいとき。

説明

DiscordのWebhook(Discordのチャンネルに外部からメッセージを送信できる、あらかじめ発行されたURL)にHTTPリクエストを送ることで、ゲーム内で起きた出来事をDiscordに転送できます。FiveMのLuaにはPerformHttpRequestというnative関数が用意されており、これでHTTP通信を行います。

コード例

server.lua: Webhookにログを送信する共通関数

local WEBHOOK_URL = 'https://discord.com/api/webhooks/xxxxx/yyyyy' -- 実際のWebhook URLに置き換える

local function sendDiscordLog(title, description)
    local payload = json.encode({
        embeds = {
            {
                title = title,
                description = description,
                color = 3066993 -- 緑系の色(10進数のRGB値)
            }
        }
    })

    PerformHttpRequest(WEBHOOK_URL, function(statusCode, responseText, headers) end, 'POST', payload, {
        ['Content-Type'] = 'application/json'
    })
end

使用例: 管理者のお金付与をログに残す

RegisterCommand('givemoney', function(source, args)
    if not IsPlayerAceAllowed(source, 'command.givemoney') then return end

    local targetId = tonumber(args[1])
    local amount = tonumber(args[2])

    -- 実際のお金付与処理はここに書く(省略)

    sendDiscordLog(
        '💰 お金付与',
        ('管理者 %s が %s に $%s を付与しました'):format(GetPlayerName(source), GetPlayerName(targetId), amount)
    )
end, false)

注意点・よくあるミス

  • Webhook URLは秘密情報です。コード中に直接書いた状態でGitHub等の公開リポジトリにコミットしないでください(Tier1-08で学んだ.gitignoreで除外するConfig.luaに分離する等の対策を取りましょう)。URLが漏れると誰でもそのチャンネルに投稿できてしまいます。
  • PerformHttpRequestは非同期です(Tier3-03のDB処理と同じ考え方)。送信結果を待たずに次の行が実行されるため、送信の成否を厳密に確認したい場合はコールバック内で処理してください。
  • ログを送りすぎるとDiscordのレート制限(短時間に大量のリクエストを送ると一時的に拒否される制限)に引っかかることがあります。本当に重要な操作だけに絞ってログを送るようにしましょう。

補足

Discordの「Embed」機能(色付きの枠で表示されるリッチな見た目のメッセージ)を使うことで、通常のテキストより見やすいログを作れます。BAN機能(Tier4-07)、通報システム(Tier3-21)など、多くの管理者向け機能と組み合わせて活用されます。
