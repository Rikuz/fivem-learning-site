スキル・経験値(XP)システム

結論

このレッスンを終えると、プレイヤーの行動に応じて経験値を加算し、一定量たまったらレベルアップさせ、DBに保存するスキルシステムの基本設計ができるようになります。

こんな時に使う: 釣りを繰り返すと釣りスキルが上がる、採掘を繰り返すと採掘スキルが上がる、といった熟練度による報酬アップを実装したいとき。

説明

XPシステムの核は「現在の経験値」と「レベルごとに必要な経験値」を比較し、超えたらレベルを上げる、というシンプルな計算です。DBには最終的な経験値の数値だけを保存し、レベルは都度計算する設計が一般的です。

コード例

server.lua: レベルと必要経験値の計算

-- レベルNに必要な累計経験値を計算する(単純な二次関数の例)
local function xpRequiredForLevel(level)
    return level * level * 100
end

local function calculateLevel(totalXp)
    local level = 1
    while totalXp >= xpRequiredForLevel(level + 1) do
        level = level + 1
    end
    return level
end

server.lua: 経験値を加算し、レベルアップを検知する

local playerFishingXp = {} -- playerId -> 経験値(メモリ上で管理し、定期的にDB保存する)

local function addFishingXp(playerId, amount)
    local currentXp = playerFishingXp[playerId] or 0
    local oldLevel = calculateLevel(currentXp)

    local newXp = currentXp + amount
    local newLevel = calculateLevel(newXp)

    playerFishingXp[playerId] = newXp

    if newLevel > oldLevel then
        TriggerClientEvent('myscript:notify', playerId, ('釣りスキルがレベル%dになりました!'):format(newLevel))
    end
end

RegisterNetEvent('fishing:catchFish')
AddEventHandler('fishing:catchFish', function()
    local playerId = source
    addFishingXp(playerId, 10)
    -- Tier3-24のアイテム付与処理もここで行う
end)

レベルに応じて成功率を上げる例

local function getRareFishBonus(playerId)
    local level = calculateLevel(playerFishingXp[playerId] or 0)
    return level * 2 -- レベルが上がるほど、レアな魚の重み(Tier3-24参照)にボーナスを加える
end

注意点・よくあるミス

  • 経験値をメモリ上のテーブル(playerFishingXp)だけで管理していると、サーバー再起動で失われます。Tier3-15「プレイヤーデータの自動保存設計」と組み合わせてDBに保存してください。
  • レベル計算の数式(xpRequiredForLevel)を後から変更すると、既存プレイヤーのレベルが急に変わってしまうことがあります。バランス調整は早い段階でしっかり検討しておくのがおすすめです。
  • 経験値の加算処理も、他の重要な数値変更と同様に必ずserver側で行い、client側から「経験値を加算して」と直接指示させないでください(Tier3-05のサーバー側バリデーションと同じ考え方)。

補足

複数のスキル(釣り、採掘、料理など)を管理したい場合は、playerFishingXpのような変数を種類ごとに複数持つのではなく、playerSkills[playerId][skillName]のようなネストしたテーブルにまとめると管理しやすくなります。
