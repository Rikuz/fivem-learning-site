死亡・蘇生(リバイブ)システムの基礎

結論

このレッスンを終えると、プレイヤーが致命傷を負ったことを検知して「ダウン状態」に遷移させ、他プレイヤーや救急隊コマンドで蘇生するという、RPサーバーの定番システムの土台を実装できるようになります。

こんな時に使う: 撃たれてもすぐにリスポーンさせず、しばらく動けない演出にしたい、救急隊の役割を作りたいとき。

説明

GTA Vの標準動作では、プレイヤーは死亡すると自動的にリスポーンしてしまいます。RPサーバーでは、これを乗っ取って「ダウン状態(意識を失っているが死んではいない)」を独自に表現し、他プレイヤーが助けに来るまで待つ、という流れがよく使われます。

コード例

client.lua: 致命傷を検知してダウン状態にする

local isDowned = false

CreateThread(function()
    while true do
        Wait(500)
        local ped = PlayerPedId()

        if IsEntityDead(ped) and not isDowned then
            isDowned = true
            enterDownedState()
        end
    end
end)

function enterDownedState()
    local ped = PlayerPedId()

    NetworkResurrectLocalPlayer(GetEntityCoords(ped), GetEntityHeading(ped), true, false)
    SetEntityHealth(ped, 100) -- 完全に死なせず、体力を最低限残す
    SetPedCanRagdoll(ped, false)

    -- 動けなくする(実際にはアニメーションでうつ伏せにする処理等を組み合わせる)
    FreezeEntityPosition(ped, true)

    TriggerServerEvent('myscript:notifyDowned')
end

server.lua: 救急隊が蘇生するコマンド

RegisterCommand('revive', function(source, args)
    local targetId = tonumber(args[1])
    if not targetId then return end

    -- 実運用ではTier4-02のJob確認(救急隊かどうか)や、
    -- Tier2-17のレイキャストで対象が近くにいるかの確認も組み合わせる
    TriggerClientEvent('myscript:revivePlayer', targetId)
end, false)

client.lua: 蘇生を受け取る

RegisterNetEvent('myscript:revivePlayer')
AddEventHandler('myscript:revivePlayer', function()
    local ped = PlayerPedId()

    FreezeEntityPosition(ped, false)
    SetEntityHealth(ped, 200)
    SetPedCanRagdoll(ped, true)
    isDowned = false

    TriggerEvent('myscript:notify', '蘇生しました')
end)

注意点・よくあるミス

  • SetEntityHealthを0や極端に低い値にしたままにすると、ちょっとした被弾で即座に「本当の死亡」判定に戻ってしまいます。ダウン中は一定の体力を保つよう管理してください。
  • ダウン状態から一定時間経っても誰も助けに来ない場合の救済措置(自動リスポーン、NPC救急隊の自動出動など)を用意しないと、プレイヤーが長時間動けなくなり離脱の原因になります。
  • 蘇生コマンドをTier3-05のサーバー側バリデーションなしで誰でも実行できるようにすると、ゲームバランスが崩れます。実運用ではJob確認(救急隊のみ)や道具の所持確認などを組み合わせてください。

補足

ダウン中の見た目(地面に横たわる等)は、Tier2-07で学んだアニメーション再生(TaskPlayAnimにループフラグを付けたもの)と組み合わせて実現します。
