釣り・採掘などのミニゲームループ

結論

このレッスンを終えると、プログレスバーと確率抽選を組み合わせて、釣り・採掘のような「繰り返し行うと時々報酬が得られる」アクションを実装できるようになります。

こんな時に使う: 釣りスポットで魚を釣らせたい、鉱山で鉱石を採掘させたい、繰り返しプレイできる収集系のコンテンツを作りたいとき。

説明

釣り・採掘のようなミニゲームは、内部的には「アニメーション再生+プログレスバー(Tier2-07、Tier3-08)」と「確率に応じたアイテム付与(Tier3-04)」の組み合わせでできています。math.randomで抽選を行い、結果に応じてアイテムを付与するかどうかを決めます。

コード例

Config.lua: 釣れる魚とその確率

Config.FishLoot = {
    { name = 'common_fish', weight = 70 },  -- weightが大きいほど当たりやすい
    { name = 'rare_fish',   weight = 25 },
    { name = 'legendary_fish', weight = 5 },
}

server.lua: 重み付き抽選を行う関数

local function weightedRandom(lootTable)
    local totalWeight = 0
    for _, entry in ipairs(lootTable) do
        totalWeight = totalWeight + entry.weight
    end

    local roll = math.random(1, totalWeight)
    local cumulative = 0

    for _, entry in ipairs(lootTable) do
        cumulative = cumulative + entry.weight
        if roll <= cumulative then
            return entry.name
        end
    end
end

RegisterNetEvent('fishing:catchFish')
AddEventHandler('fishing:catchFish', function()
    local playerId = source
    local caughtFish = weightedRandom(Config.FishLoot)

    exports.ox_inventory:AddItem(playerId, caughtFish, 1)
    TriggerClientEvent('myscript:notify', playerId, ('%sを釣り上げました!'):format(caughtFish))
end)

client.lua: 釣りのループ

RegisterCommand('fish', function()
    local ped = PlayerPedId()

    RequestAnimDict('amb@world_human_stand_fishing@idle_a')
    while not HasAnimDictLoaded('amb@world_human_stand_fishing@idle_a') do Wait(0) end
    TaskPlayAnim(ped, 'amb@world_human_stand_fishing@idle_a', 'idle_c', 8.0, 8.0, -1, 1, 0, false, false, false)

    if lib.progressBar({ duration = 8000, label = '釣りをしています...', canCancel = true }) then
        TriggerServerEvent('fishing:catchFish')
    end

    ClearPedTasks(ped)
end, false)

注意点・よくあるミス

  • 抽選(math.random)は必ずserver側で行ってください。client側で抽選すると、改ざんされたクライアントで常に最高レア度が出るよう固定される危険があります。
  • 連打だけで大量に稼げてしまうと経済バランスが崩れます。Tier5-04のレート制限の考え方で、一定間隔でしか釣れないようにする、あるいは1回ごとに餌等の消費アイテムを要求する設計も検討してください。
  • weightedRandomのような重み付き抽選は、単純なmath.random(1, 3)のような等確率抽選と違い、レアなアイテムの出現率を低く保つのに便利です。合計値(totalWeight)の計算を忘れないでください。

補足

採掘(mining)もほぼ同じ構造で実装でき、Config.FishLootをConfig.MiningLootのように置き換えるだけで応用できます。Tier3-23のクラフトシステムと組み合わせれば、「採取→クラフト」という一連の生産チェーンが作れます。
