DB連携の基礎(oxmysql)

結論

このレッスンを終えると、oxmysql(FiveMで広く使われるMySQL連携リソース)を導入し、データの取得(SELECT)と保存(INSERT)ができるようになります。

説明

FiveMのサーバーからMySQLデータベースを扱うには、oxmysqlというリソースを別途導入します。導入後はMySQL.Async.fetchAll(SELECTで複数行取得)やMySQL.Async.execute(INSERT/UPDATE/DELETEの実行)といった関数が使えるようになります。

これらは名前の通り非同期(処理の完了を待たずに次の行に進み、完了したらコールバック関数が呼ばれる)で動きます。DBへの問い合わせには数十ミリ秒〜数百ミリ秒かかることがあり、その間サーバーの他の処理を止めないための仕組みです。

コード例

導入(server.cfg)

ensure oxmysql
# server.cfgにMySQL接続情報を設定する
set mysql_connection_string "mysql://ユーザー名:パスワード@localhost/データベース名?charset=utf8mb4"

fxmanifest.luaでの依存指定

dependency 'oxmysql'

SELECT(複数行取得)

local function getPlayerData(identifier)
    MySQL.Async.fetchAll('SELECT * FROM users WHERE identifier = @identifier', {
        ['@identifier'] = identifier
    }, function(result)
        if result and result[1] then
            print('見つかったユーザー名: ' .. result[1].name)
        else
            print('該当するユーザーが見つかりませんでした')
        end
    end)
end

INSERT(保存)

local function createPlayerRecord(identifier, name)
    MySQL.Async.execute('INSERT INTO users (identifier, name, money) VALUES (@identifier, @name, @money)', {
        ['@identifier'] = identifier,
        ['@name'] = name,
        ['@money'] = 500
    }, function(rowsChanged)
        print(('%s件のレコードを追加しました'):format(rowsChanged))
    end)
end

注意点・よくあるミス

  • クエリに値を埋め込むとき、文字列連結(..)で直接組み立てるのは絶対にやめてください。SQLインジェクション(悪意のある文字列を混入させ、意図しないSQL文を実行させる攻撃)の危険があります。必ず上記のようにプレースホルダ(@identifierなど)とパラメータテーブルを使ってください。
  • 非同期処理なので、MySQL.Async.fetchAllを呼んだ直後の行では、まだ結果が返ってきていません。結果を使う処理は必ずコールバック関数の中に書いてください。
  • oxmysqlより先に自分のresourceが起動してしまうと接続前にクエリを投げてしまう可能性があります。fxmanifest.luaにdependency 'oxmysql'を書いて起動順序を保証してください。

補足

oxmysqlにはPromiseベースのexports.oxmysql:execute(...)のような新しい書き方もあります。本レッスンでは、他のmysql系リソースからの移行がしやすいMySQL.Async.*形式(互換レイヤー)を採用しています。

※oxmysqlはバージョンによって書き方の選択肢が増えることがあります。実際に導入しているoxmysqlのREADME・公式ドキュメントも必ず確認してください。
