マップ編集・カスタムプロップ配置(YMAP等)

結論

このレッスンを終えると、屋外のカスタムプロップ(装飾物)を、静的なYMAPファイルとして配置する方法と、Tier2-09で学んだ動的なCreateObjectで配置する方法を使い分けられるようになります。「ずっとそこにある装飾」と「プレイヤーの操作で出し入れする物」の違いを整理して理解します。

こんな時に使う: 街に固定の装飾(看板・柵・イベント用の飾り付け等)を追加したいが、Tier4-35の家具設置システムのようにプレイヤーごとに動的配置する必要はないとき。

説明

プロップ配置には大きく2つのアプローチがあります。①静的配置(YMAP)は、resource起動時に自動的に読み込まれ続ける固定の装飾に向いています(Tier3-44のMLOと同じ仕組み)。②動的配置(CreateObject)は、プレイヤーの操作やDBの内容に応じて配置場所や数が変わる場合に向いています(Tier4-35の家具設置がこれにあたります)。「常にそこにあるべきか」「条件によって変わるか」で使い分けるのが基本方針です。

コード例

fxmanifest.lua: 静的なプロップ配置(YMAP)を読み込む

fx_version 'cerulean'
game 'gta5'

author '自分の名前'
description '街の装飾プロップ配置'
version '1.0.0'

this_is_a_map 'yes'

files {
    'stream/decorations.ymap',
}

比較: 動的配置(Tier2-09の復習)

-- 条件によって出し入れする場合はCreateObjectを使う(Tier2-09・Tier4-35参照)
local function spawnEventDecoration(coords)
    local model = `prop_xmas_tree_int`

    RequestModel(model)
    while not HasModelLoaded(model) do Wait(0) end

    local obj = CreateObject(model, coords.x, coords.y, coords.z, false, false, false)
    FreezeEntityPosition(obj, true)
    SetModelAsNoLongerNeeded(model)

    return obj
end

-- 例: イベント期間中だけコマンドで装飾を出し入れする
local eventDecorations = {}

RegisterCommand('event_decorate_on', function()
    eventDecorations[#eventDecorations + 1] = spawnEventDecoration(vec3(200.0, 100.0, 30.0))
end, false)

RegisterCommand('event_decorate_off', function()
    for _, obj in ipairs(eventDecorations) do
        if DoesEntityExist(obj) then
            DeleteEntity(obj)
        end
    end
    eventDecorations = {}
end, false)

注意点・よくあるミス

  • 静的配置(YMAP)はresourceが起動している限り常に読み込まれ続けます。「季節限定の装飾だから期間外は消したい」という場合は、YMAPではなくTier2-09の動的配置(または期間外はresource自体を`stop`する運用)を選んでください。
  • 大量のプロップを動的配置(CreateObject)で置くと、Tier5-01で学ぶパフォーマンスに影響します。数十〜数百個規模の固定装飾は、素直にYMAPの静的配置にした方が軽量です。
  • YMAPで配置したプロップの座標を後から微調整したい場合、Lua側から動的に動かすことはできません(静的データのため)。座標を作り直してYMAPファイル自体を差し替える必要があります。

補足

実際のYMAPファイルの作成(座標を決めて配置する作業)には、コミュニティ製の「FiveM Map Editor」のようなin-game編集ツールがよく使われますが、そうしたツール自体の操作は本サイトのスコープ外(Luaスクリプト開発に特化しているため)です。ここで扱ったのは、既に作られたYMAPをresourceとして正しく読み込ませる方法と、動的配置との使い分けの考え方です。
