管理者メニューの基礎設計

結論

このレッスンを終えると、権限を持つ管理者だけが開けるメニューを作り、接続中プレイヤーの一覧を表示して操作ボタンを配置する基本設計ができるようになります。

こんな時に使う: テレポート・お金付与・キック等をコマンド入力なしでボタン操作でできるようにしたい、管理業務をまとめて1つの画面に集約したいとき。

説明

これまで学んできた「権限チェック付きコマンド(Tier2-04)」「NUI(Tier3-01・02)」「プレイヤー一覧取得」を組み合わせると、管理者メニューの基本形が作れます。コマンドを1つずつ覚える必要がなく、視覚的に操作できるのが利点です。

コード例

client.lua: 権限チェック付きでメニューを開く

RegisterCommand('adminmenu', function()
    TriggerServerEvent('admin:requestOpen')
end, false)

RegisterNetEvent('admin:openMenu')
AddEventHandler('admin:openMenu', function(players)
    SetNuiFocus(true, true)
    SendNUIMessage({ action = 'openAdminMenu', players = players })
end)

server.lua: 権限を確認し、プレイヤー一覧を渡す

RegisterNetEvent('admin:requestOpen')
AddEventHandler('admin:requestOpen', function()
    local source = source
    if not IsPlayerAceAllowed(source, 'command.adminmenu') then return end

    local players = {}
    for _, playerId in ipairs(GetPlayers()) do
        table.insert(players, {
            id = tonumber(playerId),
            name = GetPlayerName(playerId)
        })
    end

    TriggerClientEvent('admin:openMenu', source, players)
end)

server.lua: メニューからの操作を受け取る(NUIコールバック経由)

RegisterNetEvent('admin:teleportToPlayer')
AddEventHandler('admin:teleportToPlayer', function(targetId)
    local source = source
    if not IsPlayerAceAllowed(source, 'command.adminmenu') then return end -- 呼び出し側でも必ず再チェックする

    local targetPed = GetPlayerPed(targetId)
    if targetPed and targetPed ~= 0 then
        local coords = GetEntityCoords(targetPed)
        TriggerClientEvent('admin:doTeleport', source, coords)
    end
end)

注意点・よくあるミス

  • 「メニューを開けた=全ての操作を実行してよい」ではありません。メニュー内の個別のボタン操作(テレポート・BAN等)も、それぞれのイベントハンドラで改めて権限チェックしてください。メニューを開く権限チェックだけに頼ると、他のイベントを直接発火されて権限を回避される危険があります。
  • プレイヤー一覧はプレイヤーの入退室で変化します。メニューを開いている間に切断したプレイヤーへの操作がエラーにならないよう、対象が存在するか確認する処理(targetPed ~= 0等)を必ず入れてください。
  • 危険な操作(BAN、resource再起動等)には、誤操作防止の確認ダイアログをUI側に用意することを検討してください。
