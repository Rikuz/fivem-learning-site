ox_libで通知・プログレスバーを出す

結論

このレッスンを終えると、ox_lib(FiveMで広く使われる共通UI/ユーティリティライブラリ)で通知を表示し、プログレスバー付きのアクション(例: 「調べています...」の待機演出)を実装することができるようになります。

説明

Tier4-03で学んだokokNotifyのような通知は特定のスクリプトシリーズ専用でしたが、ox_libはより汎用的なUI部品(通知・プログレスバー・確認ダイアログ・コンテキストメニュー等)を提供するライブラリで、フレームワークを問わず多くのスクリプトの土台として使われています。

コード例

通知を表示する

lib.notify({
    title = '入手',
    description = 'アイテムを入手しました',
    type = 'success' -- 'inform' / 'error' / 'success' / 'warning'
})

プログレスバー付きのアクションを実装する

RegisterCommand('search', function()
    local success = lib.progressBar({
        duration = 3000,
        label = '調べています...',
        useWhileDead = false,
        canCancel = true,
        disable = { move = true, car = true }, -- 実行中は移動・車両操作を無効化する
    })

    if success then
        lib.notify({ description = '何かを見つけました', type = 'success' })
    else
        lib.notify({ description = 'キャンセルしました', type = 'error' })
    end
end, false)

アニメーション・持ち物付きのプログレスバー

lib.progressBar({
    duration = 2000,
    label = '水を飲んでいます',
    canCancel = true,
    anim = { dict = 'mp_player_intdrink', clip = 'loop_bottle' },
    prop = {
        model = `prop_ld_flow_bottle`,
        pos = vec3(0.03, 0.03, 0.02),
        rot = vec3(0.0, 0.0, -1.5)
    },
})

注意点・よくあるミス

  • lib.progressBarは戻り値がtrue(完了)/false(キャンセル)です。この戻り値を確認せずに後続処理を実行すると、キャンセルしたのに処理が実行されてしまいます。上記コード例のようにif success then ... else ... endで分岐してください。
  • disableで移動や車両操作を無効化しないと、プログレスバー実行中でも自由に歩き回れてしまい、不自然な体験になります。用途に応じてmove/car/combat等を適切に無効化しましょう。
  • ox_libを使うには、自分のresourceのfxmanifest.luaでox_libを読み込む設定(dependency 'ox_lib'や共有スクリプトとしての読み込み)が必要です。導入しているox_libのバージョンのセットアップ手順を確認してください。

補足

本レッスンの構文(lib.notify、lib.progressBar)はOverextended公式ドキュメント(overextended.dev/ox_lib)で確認済みです。ox_libには他にもlib.alertDialog(確認ダイアログ)やlib.registerContext/lib.showContext(コンテキストメニュー)などの機能があります。バージョンによって仕様が変わる場合があるため、公式ドキュメントも確認してください。
