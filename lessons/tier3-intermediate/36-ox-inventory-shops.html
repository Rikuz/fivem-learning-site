ox_inventory組み込みのショップ登録

結論

このレッスンを終えると、ox_inventoryが標準で持っているショップ機能(RegisterShop)を使い、商品リスト・座標・利用制限を一括登録することができるようになります。Tier3-26で作った自作ショップと同じことを、ox_inventory側の機能だけで数行で実現できます。

説明

Tier3-26では、購入イベントの受信・所持金チェック・アイテム付与を全て自分で実装しました。ox_inventoryを導入している場合、exports.ox_inventory:RegisterShopにショップ情報を渡すだけで、購入UI・所持金チェック・アイテム付与までox_inventory側がまとめて処理してくれます。

コード例

server.lua: ショップを登録する

exports.ox_inventory:RegisterShop('TestShop', {
    name = 'Test shop',
    inventory = {
        { name = 'burger', price = 10 },
        { name = 'water', price = 10 },
        { name = 'cola', price = 10 },
    },
    locations = {
        vec3(223.832962, -792.619751, 30.695190),
    },
    groups = { police = 0 }, -- この職業(job)のプレイヤーだけが利用できる(省略すると誰でも利用可)
})

複数座標に同じ店舗を展開する例

exports.ox_inventory:RegisterShop('GeneralStore', {
    name = '雑貨屋',
    inventory = {
        { name = 'water', price = 20 },
        { name = 'bread', price = 30 },
    },
    locations = {
        vec3(100.0, 200.0, 30.0),
        vec3(-50.0, -150.0, 40.0),
        vec3(300.0, 400.0, 30.0),
    },
    -- groupsを省略すると誰でも利用できる店舗になる
})

注意点・よくあるミス

  • 公式ドキュメントには「Blip・Marker・ゾーンは作られない」と明記されています。locationsに座標を指定しても、Tier2-03のBlipやTier3-07のox_targetは自動生成されません。プレイヤーに場所を知らせたい場合は、別途Blipの設置が必要です。
  • inventoryに指定するアイテム名('burger'等)は、Tier3-30で学んだdata/items.luaに実在するアイテムでなければ販売できません。先にアイテムを定義してから商品リストに加えてください。
  • groupsで職業制限をかけない限り、誰でも購入できる店舗になります。専用ショップを作りたい場合は必ず指定してください。

補足

本レッスンの構文は公式ドキュメント(overextended.dev/docs/ox_inventory/Guides/shops)で確認済みです。Tier3-26の自作ショップは「購入処理の流れを理解する」ための教材として、このレッスンのRegisterShopは「実運用で素早くショップを増やす」ための機能として、それぞれ使い分けてください。バージョンによって仕様が変わる場合があるため、公式ドキュメントも確認してください。
