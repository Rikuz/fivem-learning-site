Scaleform(GTA組み込みUI部品)を使う

結論

このレッスンを終えると、GTA V本編に標準で入っているUI部品(ミッション通知やインストラクショナルボタン等)を、自分のスクリプトから表示することができるようになります。

こんな時に使う: NUIを1から作るほどではない、GTA本編と統一感のあるシンプルな通知・案内を表示したいとき。

説明

Scaleformは、GTA Vのゲーム内UI(ミッション目標の表示、レーダー、クレジット表記等)を描画するためのFlashベースの仕組みです。Tier3のNUI(自作のHTML)とは異なり、あらかじめGTA V本体に組み込まれているUI部品を、native関数経由で呼び出して使います。

コード例

client.lua: ミッション目標風のテキストを表示する

local scaleform = nil

local function loadInstructionalScaleform()
    scaleform = RequestScaleformMovie('MIDSIZED_MESSAGE')

    while not HasScaleformMovieLoaded(scaleform) do
        Wait(0)
    end
end

local function showMissionText(title)
    if not scaleform then
        loadInstructionalScaleform()
    end

    BeginScaleformMovieMethod(scaleform, 'SHOW_MIDSIZED_MESSAGE')
    ScaleformMovieMethodAddParamPlayerNameString(title)
    ScaleformMovieMethodAddParamInt(100)
    EndScaleformMovieMethod()
end

RegisterCommand('missiontext', function()
    showMissionText('配達完了')
end, false)

client.lua: 毎フレーム描画し続ける(Scaleformは描画も自分で行う)

CreateThread(function()
    while true do
        Wait(0)
        if scaleform then
            DrawScaleformMovieFullscreen(scaleform, 255, 255, 255, 255, 0)
        end
    end
end)

注意点・よくあるミス

  • ScaleformもMarker(Tier2-03)やパーティクル(Tier2-11)と同様、毎フレーム描画し続けないと表示されません。DrawScaleformMovieFullscreen系の関数をループの中で呼び続ける必要があります。
  • Scaleformの種類ごとに、呼び出せるメソッド名・引数の型が異なります(ScaleformMovieMethodAddParamInt、...AddParamFloat、...AddParamPlayerNameString等)。ドキュメントやコミュニティの実例で正確な組み合わせを確認してください。
  • 不要になったScaleformはSetScaleformMovieAsNoLongerNeededで解放しないと、メモリに残り続けます。

補足

Scaleformは自由度が低い分、GTA本編と統一感のある見た目を簡単に出せるのが利点です。細かいデザインを自由に作りたい場合はTier3-01のNUIを、GTA標準の見た目で十分な場合はScaleformを、というように使い分けます。
