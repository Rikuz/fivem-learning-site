無線チャンネルシステムの基礎

結論

このレッスンを終えると、プレイヤーをチャンネル番号でグループ分けし、同じチャンネルのプレイヤー同士だけでテキスト通信できる無線システムの基本ロジックを実装できるようになります(音声そのものはTier3-27で触れたボイスチャットリソースとの連携が必要ですが、ここでは「誰に届けるか」というグループ管理の考え方を扱います)。

こんな時に使う: 警察無線、救急無線のように、同じ周波数(チャンネル)にいる人だけで会話できる仕組みを作りたいとき。

説明

無線チャンネルの管理は、実は難しい技術ではなく「プレイヤーIDとチャンネル番号を対応付けるテーブルを持ち、メッセージを送るときは同じチャンネルの人にだけTriggerClientEventする」というシンプルな仕組みです。

コード例

server.lua: チャンネルの参加・退出

local playerChannels = {} -- playerId -> チャンネル番号

RegisterNetEvent('radio:joinChannel')
AddEventHandler('radio:joinChannel', function(channel)
    local playerId = source
    playerChannels[playerId] = channel
    TriggerClientEvent('myscript:notify', playerId, ('チャンネル%dに接続しました'):format(channel))
end)

RegisterNetEvent('radio:leaveChannel')
AddEventHandler('radio:leaveChannel', function()
    local playerId = source
    playerChannels[playerId] = nil
end)

server.lua: 同じチャンネルの全員にメッセージを送る

RegisterNetEvent('radio:sendMessage')
AddEventHandler('radio:sendMessage', function(message)
    local senderId = source
    local channel = playerChannels[senderId]

    if not channel then
        TriggerClientEvent('myscript:notify', senderId, '無線に接続していません')
        return
    end

    for playerId, playerChannel in pairs(playerChannels) do
        if playerChannel == channel then
            TriggerClientEvent('radio:receiveMessage', playerId, GetPlayerName(senderId), message)
        end
    end
end)

切断時のクリーンアップ(Tier2-15参照)

AddEventHandler('playerDropped', function()
    playerChannels[source] = nil
end)

注意点・よくあるミス

  • 切断したプレイヤーのplayerChannelsエントリを消し忘れると、メモリ上にデータが残り続けます。上記コード例のようにplayerDroppedで必ずクリーンアップしてください(Tier2-15参照)。
  • チャンネル参加を誰でも自由にできるようにすると、警察無線に一般人が紛れ込む、といった不自然な状態になります。Tier4-02の職業(Job)確認と組み合わせ、特定のJobだけが特定のチャンネルに参加できるよう制限することを検討してください。
  • 実際の「声」を届けるには、Tier3-27で扱ったボイスチャットリソース側の「チャンネル」機能(MumbleSetSubChannel相当)と連携する必要があります。このレッスンのテキストベースの仕組みだけでは音声は届きません。

補足

Tier4-16「cd_dispatchで警察無線通知を送る」と組み合わせることで、「事件発生の通知」と「無線での会話」の両方を備えた警察無線システムに発展させられます。
