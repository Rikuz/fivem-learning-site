ox_inventoryで使用可能アイテムを作る

結論

このレッスンを終えると、インベントリ画面でアイテムをダブルクリック(使用)したときに、自分のスクリプトの処理を実行させることができるようになります。Tier3-30で追加したアイテムに「使うと効果が発動する」という機能を持たせる回です。

説明

ox_inventoryは、アイテムのclient.export(またはclient.event)フィールドの有無を見て、使用時にそのexport(またはイベント)を呼び出すかどうかを判定しています(ox_inventory本体のソースコードで確認済み)。呼び出す側は'リソース名.export名'という文字列で指定し、呼ばれる側は自分のresourceでexports('export名', function(data, slot) ... end)という形で処理を登録します。

コード例

data/items.lua: 使用時にexportを呼ぶよう指定する

['water_bottle'] = {
    label = 'Water Bottle',
    weight = 500,
    stack = true,
    close = true,
    client = {
        export = 'my-resource.drinkWater' -- 'リソース名.export名' の形式
    }
}

my-resource/client.lua: exportを登録する

-- 第1引数はexport名(items.luaのclient.exportで指定した名前と一致させる)
exports('drinkWater', function(data, slot)
    -- exports.ox_inventory:useItem(...) でサーバー側に使用を通知し、承認されてから効果を適用する
    exports.ox_inventory:useItem(data, function(data)
        if data then
            -- ここで実際の効果(空腹度/喉の渇きの回復など)を適用する
            lib.notify({ description = '水を飲んで喉が潤った' })
        end
    end)
end)

Tier3-30の「burger」アイテムを使用可能にする例

-- data/items.luaのburgerに client = { export = 'my-resource.eatBurger', ... } を追加した想定

exports('eatBurger', function(data, slot)
    exports.ox_inventory:useItem(data, function(data)
        if data then
            local playerPed = PlayerPedId()
            local maxHealth = GetEntityMaxHealth(playerPed)
            local health = GetEntityHealth(playerPed)
            SetEntityHealth(playerPed, math.min(maxHealth, health + 20))
            lib.notify({ description = 'バーガーを食べた', type = 'success' })
        end
    end)
end)

注意点・よくあるミス

  • items.lua側のclient.exportに指定した文字列('リソース名.export名')と、実際にexports('export名', ...)で登録した名前が完全に一致している必要があります。1文字でも違うと使用時に何も起こりません。
  • exports.ox_inventory:useItem(data, callback)を挟まずに、いきなり効果を適用してはいけません。この呼び出しがサーバー側で「本当にそのアイテムを持っていて、消費が成立したか」を確認する役割を持っています。これを省略すると、既にアイテムを使い切っているのに何度でも効果だけ発動できてしまう不正の温床になります。
  • close = trueを指定したアイテムは、使用と同時にインベントリ画面が閉じます。薬など「使ったらすぐ画面を閉じたい」アイテムにはtrue、道具など「使いながら画面を見ていたい」アイテムにはfalseを使い分けてください(Tier3-30参照)。

補足

本レッスンの構文(client.exportフィールド、exports.ox_inventory:useItem)は公式ドキュメント(overextended.dev/docs/ox_inventory/Guides/creatingItems)およびox_inventory本体のソースコード(modules/items/client.lua)で確認済みです。client.event(exportの代わりにイベントを発火させる方式)という選択肢もあります。バージョンによって仕様が変わる場合があるため、公式ドキュメントも確認してください。
