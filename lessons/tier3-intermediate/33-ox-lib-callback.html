ox_libでコールバックを使う(lib.callback)

結論

このレッスンを終えると、「serverに問い合わせて、その結果を受け取るまで待つ」という処理を、往復用の2つのイベントを自分で用意せずに1行で書けるようになります。Tier2-01で学んだTriggerServerEvent+TriggerClientEventの往復パターンを、ox_libのlib.callbackが簡略化してくれます。

説明

これまでのレッスンで「clientからserverに何かを依頼し、結果を受け取る」処理を書くたびに、依頼用のイベントと結果返却用のイベントの2つを用意してきました(例: Tier2-01のpickupItemとpickupResult)。lib.callbackを使うと、1つの名前で「呼ぶ側」と「答える側」を対応付けられ、コードが半分程度に減ります。

コード例

server.lua: コールバックを登録する(答える側)

lib.callback.register('myscript:getPlayerCash', function(source)
    local cash = getPlayerMoney(source) -- Tier4-01のフレームワーク連携で取得する想定
    return cash
end)

client.lua: 呼び出す(コールバック関数スタイル)

RegisterCommand('mycash', function()
    lib.callback('myscript:getPlayerCash', false, function(cash)
        print('所持金: ' .. cash)
    end)
end, false)

client.lua: 呼び出す(await/Promiseスタイル)

RegisterCommand('mycash2', function()
    local cash = lib.callback.await('myscript:getPlayerCash', false)
    print('所持金: ' .. cash)
end, false)

引数を渡す例

-- server.lua
lib.callback.register('myscript:canAfford', function(source, price)
    return getPlayerMoney(source) >= price
end)

-- client.lua
local canAfford = lib.callback.await('myscript:canAfford', false, 500)
if canAfford then
    print('購入可能です')
end

注意点・よくあるミス

  • 第2引数(上記コード例のfalse)はタイムアウト時間(ミリ秒)です。falseを渡すとタイムアウトせず、応答が来るまでいつまでも待ちます。ネットワーク遅延が心配な処理では数値(例: 5000)を指定し、タイムアウト時の挙動も考慮してください。
  • lib.callback.registerで登録した名前と、呼び出し側の名前(lib.callback/lib.callback.awaitの第1引数)が完全に一致している必要があります。
  • コールバックの中身(serverのlib.callback.registerで登録した処理)は、あくまで「値を返すだけ」の処理にしてください。お金の増減など副作用のある処理は、Tier3-05のサーバー側バリデーションを踏まえた別のイベントで行う方が設計として分かりやすくなります。

補足

本レッスンの構文は公式ドキュメント(overextended.dev/ox_lib/Modules/Callback)で確認済みです。lib.callback.registerはclient側からserverへ、あるいはserverからclientへの両方向で使える汎用的な仕組みです。既存のTier3-13(自作コンテキストメニュー)やTier3-20(管理者メニュー)のようなNUI通信も、このlib.callbackで置き換えるとコードを短縮できます。
