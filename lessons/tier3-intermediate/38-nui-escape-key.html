NUIをEscキーで閉じる標準パターン

結論

このレッスンを終えると、これまで作ってきたNUI(ショップ、コンテキストメニュー等)を、閉じるボタンだけでなくEscキーでも閉じられるようにすることができるようになります。多くの市販・OSSのNUIが採用している定番パターンです。

説明

Tier3-01で学んだ通り、SetNuiFocus(true, true)を呼ぶとマウス・キーボードの操作がNUI(ゲーム内ブラウザ)側に渡ります。この状態でのキー入力はLua側のnative(IsControlJustPressed等)では検知できません。NUIのHTML/JS側でキーイベントを監視し、Escapeが押されたらLua側に「閉じてほしい」と伝える、という設計になります。

コード例

ui/script.js: Escキーを監視する

window.addEventListener('keydown', (event) => {
  if (event.key === 'Escape') {
    closeMenu();
  }
});

function closeMenu() {
  document.getElementById('app').style.display = 'none';

  fetch(`https://${GetParentResourceName()}/closeMenu`, {
    method: 'POST',
    headers: { 'Content-Type': 'application/json; charset=UTF-8' },
    body: JSON.stringify({})
  });
}

// 既存の閉じるボタンからも同じ関数を呼ぶ
document.getElementById('close-btn').addEventListener('click', closeMenu);

client.lua: 通知を受け取ってフォーカスを戻す

RegisterNUICallback('closeMenu', function(data, cb)
    SetNuiFocus(false, false)
    cb('ok')
end)

共通化して既存のNUI(Tier3-13等)に組み込む例

// どの画面でも使い回せる共通関数として用意しておく
function setupEscapeToClose(closeCallbackName) {
  window.addEventListener('keydown', (event) => {
    if (event.key !== 'Escape') return;

    document.getElementById('app').style.display = 'none';
    fetch(`https://${GetParentResourceName()}/${closeCallbackName}`, {
      method: 'POST',
      headers: { 'Content-Type': 'application/json; charset=UTF-8' },
      body: JSON.stringify({})
    });
  });
}

setupEscapeToClose('closeMenu');

注意点・よくあるミス

  • Lua側のnative(IsControlJustPressed等)でEscapeキーを検知しようとしても、SetNuiFocus(true, true)で入力がNUI側に奪われている間は反応しません。必ずNUI(JS)側でキーイベントを監視してください。
  • keydownイベントは、フォーム内のテキスト入力欄にフォーカスがある状態でも発火します。入力中に意図せずEscapeで閉じてしまうのが困る場合は、入力欄にフォーカスがあるかを確認する処理を追加してください。
  • 閉じるボタンとEscキーの両方から同じcloseMenu関数を呼ぶようにし、処理を1箇所にまとめておくと、後で修正が必要になったときに漏れがなくなります。

補足

この仕組み自体はFiveM特有のAPIではなく、通常のWebブラウザのキーボードイベント(keydown)をそのまま使っています。NUIはFiveMの組み込みブラウザ(CEF)で描画されているため(Tier3-01参照)、一般的なWeb開発の知識がそのまま活かせる好例です。
