oxmysqlのモダンな書き方(MySQL.insert/update/scalar)

結論

このレッスンを終えると、oxmysqlが提供する用途別の関数(insert/update/scalar/single)と?プレースホルダを使い、Tier3-03よりも簡潔にDB操作を書けるようになります。Tier3-03で学んだMySQL.Async.fetchAllは他のDBリソースからの移行を想定した互換APIで、こちらがoxmysql本来のモダンな書き方です。

説明

oxmysqlは、クエリの種類ごとに専用の関数(MySQL.insert=挿入、MySQL.update=更新、MySQL.scalar=1行1列だけ取得、MySQL.single=1行まとめて取得、MySQL.query=複数行取得)を用意しています。それぞれ.awaitを付けるとPromise/コルーチンによる書き方(結果が返るまで待つ)に、付けなければコールバック関数で受け取れます。

コード例

INSERT

local id = MySQL.insert.await('INSERT INTO `users` (identifier, firstname, lastname) VALUES (?, ?, ?)', {
    identifier, firstName, lastName
})
print('新規登録したID: ' .. id)

UPDATE

local affectedRows = MySQL.update.await('UPDATE users SET firstname = ? WHERE identifier = ?', {
    newName, identifier
})
print(affectedRows .. '件更新しました')

SELECT(1行1列だけ)

local firstName = MySQL.scalar.await('SELECT `firstname` FROM `users` WHERE `identifier` = ? LIMIT 1', {
    identifier
})

SELECT(1行まとめて)

local row = MySQL.single.await('SELECT `firstname`, `lastname` FROM `users` WHERE `identifier` = ? LIMIT 1', {
    identifier
})
print(row.firstname, row.lastname)

.awaitを使わない(コールバックスタイル)

MySQL.insert('INSERT INTO `users` (identifier, firstname, lastname) VALUES (?, ?, ?)', {
    identifier, firstName, lastName
}, function(id)
    print('新規登録したID: ' .. id)
end)

注意点・よくあるミス

  • Tier3-03のMySQL.Async.fetchAllは@identifierのような名前付きプレースホルダでしたが、このモダンAPIは?という位置プレースホルダです。パラメータもテーブル(連想配列)ではなく、順番通りの配列{ }で渡します。2つの書き方を混同しないよう注意してください。
  • .awaitを使う関数は、呼び出し元がコルーチン的な文脈で実行されている必要があります(CreateThreadの中や、イベントハンドラの中は基本的に問題ありません)。純粋なグローバルスコープの先頭などで.awaitを使うとエラーになることがあります。
  • MySQL.scalarは「該当行がない」場合にnilを返します。使う前に必ずnilチェックをしてください。

補足

本レッスンの構文は公式ドキュメント(overextended.dev/docs/oxmysql/Functions)の各ページで確認済みです。どちらのAPI(Tier3-03の互換API、このレッスンのモダンAPI)を使うかはプロジェクト内で統一するのがおすすめです。バージョンによって仕様が変わる場合があるため、公式ドキュメントも確認してください。
