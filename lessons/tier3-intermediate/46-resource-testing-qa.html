自作リソースのテスト/QAの考え方

結論

このレッスンを終えると、「自分の環境で1回動いた」で終わらせず、restart耐性・複数人同時利用・エラーなしの起動を確認するための体系立ったチェック手順を持てるようになります。Tier1-05のデバッグの基本を、公開前の品質チェックという視点で発展させたレッスンです。

こんな時に使う: 作ったスクリプトを本番サーバーに導入する前、または他の人に配布する前に、最低限確認しておくべきことを知りたいとき。

説明

「動いた」には段階があります。①起動時にエラーが出ない、②1人で操作して期待通り動く、③resourceを再起動しても壊れない、④複数人が同時に使っても矛盾が起きないという順で確認範囲を広げていくと、抜け漏れに気づきやすくなります。特に③・④は1人での動作確認だけでは見つからない不具合の温床です。

コード例

F8コンソール/サーバーコンソールでのrestart耐性チェック

# サーバーコンソールから対象resourceだけを再起動する(全体再起動より高速に確認できる)
restart my-resource

# fxmanifest.luaの変更を反映しつつ再起動する場合
refresh
restart my-resource

server.lua: 起動直後に自己チェックする(セルフテストコマンド)

-- resource起動のたびに、重要な前提条件が揃っているかを自動でチェックする
local function runSelfCheck()
    local ok = true

    if GetResourceState('oxmysql') ~= 'started' then
        print('^1[my-resource] 警告: oxmysqlが起動していません^0') -- Tier1-05のprintデバッグの応用
        ok = false
    end

    if GetConvar('my_resource_api_key', '') == '' then
        print('^1[my-resource] 警告: my_resource_api_keyが未設定です^0')
        ok = false
    end

    if ok then
        print('^2[my-resource] 起動チェック: 問題ありません^0')
    end
end

AddEventHandler('onResourceStart', function(resourceName)
    if GetCurrentResourceName() ~= resourceName then return end
    runSelfCheck()
end)

pcallを使った安全な初期化(Tier1-07の応用)

local success, err = pcall(function()
    -- 外部リソースのexportsを呼ぶなど、失敗しうる初期化処理
    exports['some-dependency']:Initialize()
end)

if not success then
    print(('^1[my-resource] 初期化に失敗しました: %s^0'):format(err))
end

注意点・よくあるミス

  • 「起動時にエラーが出ない」ことと「正しく動く」ことは別です。 構文エラーがなくても、ロジックの誤りは実際に操作してみないと見つかりません。起動確認だけで安心せず、必ず実際の操作フローを一通り試してください。
  • 1人でのテストだけでは、Tier5-02の非同期処理やTier3-05のバリデーションで想定していた「同時に複数人が操作したときの競合」を見つけられません。可能であれば2つのクライアントで同時に操作して確認しましょう。
  • restartで状態がおかしくなる典型的な原因は、「resource停止時に生成物(NPC・Blip・オブジェクト等)を削除し忘れている」ことです。Tier2-02等で学んだonResourceStopでの後片付けを必ず確認してください。
  • 本番導入前に、意図的に不正な入力(存在しないアイテム名、範囲外の数値等)を送ってTier3-05のバリデーションが機能しているか確認するのも有効なテストです。

補足

チェックリストとしてまとめると、①ensure直後にエラーが出ないか、②主要な操作を一通り試したか、③restart後も壊れないか、④2人以上で同時に試したか、⑤不正な入力を送っても落ちないか、の5点です。全て自動化する必要はありませんが、公開・本番導入の前にこの順番で確認する習慣をつけると、トラブルの多くを未然に防げます。
