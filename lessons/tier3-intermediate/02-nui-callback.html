NUIコールバック(双方向通信)

結論

このレッスンを終えると、NUI画面(JS側)からLua側へデータを送り、Lua側で処理してJS側にレスポンスを返すという双方向のやり取りができるようになります。

説明

前レッスンのSendNUIMessageはLua→JSの一方向でした。JS→Luaへ送るときは、通常のWeb APIであるfetch()を使い、宛先をhttps://リソース名/コールバック名という特殊なURLに向けます。これをLua側でRegisterNUICallbackが受け取ります。

リソース名はGetParentResourceName()というJS側の組み込み関数(FiveMのNUI環境でのみ使える)で取得します。

コード例

ui/script.js(JS→Lua)

async function closeNui() {
    await fetch(`https://${GetParentResourceName()}/closeNui`, {
        method: 'POST',
        headers: { 'Content-Type': 'application/json; charset=UTF-8' },
        body: JSON.stringify({})
    });

    document.getElementById('app').style.display = 'none';
}

document.getElementById('close-btn').addEventListener('click', closeNui);

client.lua(コールバックを受け取る)

RegisterNUICallback('closeNui', function(data, cb)
    SetNuiFocus(false, false) -- UIへのフォーカスを解除し、操作をゲーム側に戻す

    -- cb()を必ず呼ぶこと。呼ばないとJS側のfetch()がいつまでも完了しない
    cb('ok')
end)

実際に動かせるサンプルを samples/nui-callback/index.html に用意しています。ブラウザで直接開いても(FiveM環境がないため通信自体は失敗しますが)、画面が閉じる動きは確認できます。FiveM実機に組み込むと、Lua側にも正しく通知が届きます。

注意点・よくあるミス

  • RegisterNUICallbackのコールバック関数内で必ずcb(...)を呼んでください。呼び忘れると、JS側のfetch()がレスポンスを受け取れずに待ち続け(タイムアウトするまで固まったように見え)ます。
  • fetchのURLはhttps://リソース名/コールバック名という決まった形式です。リソース名を直接文字列でハードコードすると、resourceフォルダ名を変更したときに動かなくなるため、必ずGetParentResourceName()で取得してください。
  • ブラウザ単体(file://)でこのサンプルを開いた場合、GetParentResourceNameという関数自体が存在せず、また通信先も実在しないためfetchは失敗します。これはサンプルの不具合ではなく、FiveMのNUI環境外では正常な挙動です。

補足

RegisterNUICallbackで受け取ったdataには、JS側のfetchのbodyに入れたJSON(JSON.parse済みのLuaテーブル)がそのまま渡ってきます。フォーム入力の値や選択したボタンの種類などを送るのに使えます。
