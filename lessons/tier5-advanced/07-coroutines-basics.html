コルーチンの基礎

結論

このレッスンを終えると、コルーチン(処理を好きなタイミングで一時停止・再開できる仕組み)の基本を理解し、CreateThreadとの違いを説明できるようになります。

こんな時に使う: 複数のステップからなる処理を、途中で一時停止しながら順番に進めたいとき。FiveMのフレームワーク内部の非同期処理の仕組みを理解したいとき。

説明

Tier2-05で学んだCreateThreadはFiveM独自の仕組みですが、コルーチン(coroutine)はLua言語自体が持つ標準機能です。coroutine.yieldで処理を一時停止し、coroutine.resumeで再開できます。FiveMの内部でも、非同期処理をシンプルに書くための土台としてコルーチンが使われることがあります。

コード例

コルーチンの基本

local co = coroutine.create(function()
    print('ステップ1')
    coroutine.yield() -- ここで一時停止する

    print('ステップ2')
    coroutine.yield()

    print('ステップ3')
end)

coroutine.resume(co) -- ステップ1 が出力される
coroutine.resume(co) -- ステップ2 が出力される
coroutine.resume(co) -- ステップ3 が出力される

値を渡しながら一時停止・再開する

local co = coroutine.create(function(startValue)
    print('開始値: ' .. startValue)

    local receivedValue = coroutine.yield('ステップ1完了')
    print('受け取った値: ' .. receivedValue)
end)

local ok, message = coroutine.resume(co, 100)
print(message) -- ステップ1完了

coroutine.resume(co, 'こんにちは')

非同期処理をコルーチンで直列に見せる(概念)

local function fetchDataSync(query)
    local co = coroutine.running()
    local result = nil

    MySQL.Async.fetchAll(query, {}, function(data)
        result = data
        coroutine.resume(co) -- DB結果が返ってきたタイミングで再開する
    end)

    coroutine.yield() -- 結果が来るまで一時停止しておく
    return result
end

CreateThread(function()
    -- コルーチンの仕組みのおかげで、コールバックを書かずに「同期処理っぽく」書ける
    local users = fetchDataSync('SELECT * FROM users')
    print(#users)
end)

注意点・よくあるミス

  • coroutine.yield()は、コルーチンの中からしか呼べません。通常の関数の中で直接呼ぶとエラーになります。
  • 停止したままのコルーチンを二度とresumeしないと、その中の処理は永遠に完了しません。多用しすぎると「どこで止まっているか」が把握しづらくなるため、複雑な非同期フローには慎重に使いましょう。
  • CreateThread(FiveM独自、Wait()で制御される)とcoroutine(Lua標準、yield/resumeで制御される)は別の仕組みです。CreateThreadの中身自体が実はコルーチンの応用として実装されている、という関係性ですが、通常のスクリプトを書く上では区別して使えれば十分です。

補足

コルーチンを直接扱う場面は多くありませんが、フレームワークやライブラリのソースコードを読んでいると「非同期処理を同期処理のように書くためのテクニック」として登場することがあります。仕組みを知っておくと、そうしたコードを読み解きやすくなります。
