cd_dispatchで警察無線通知を送る

結論

このレッスンを終えると、cd_dispatch(FiveMで使われるディスパッチ通知スクリプト)を使い、事件発生時に警察官の画面へ通知とミニマップ上のブリップを表示することができるようになります。

こんな時に使う: 強盗事件が発生したら警察に自動で通報を送りたい、110番通報のような演出を作りたいとき。

説明

cd_dispatchはcd_dispatch:AddNotificationという共通のserverイベントに、事件のタイトル・座標・対象job等をまとめたテーブルを送ることで、対象のJob(例: 警察)を持つ全プレイヤーに通知とBlip(Tier2-03参照)を表示してくれます。

コード例

client.lua: 事件を通報する

local function reportRobbery()
    local data = exports['cd_dispatch']:GetPlayerInfo() -- 現在地・性別・通り名などを取得できる

    TriggerServerEvent('cd_dispatch:AddNotification', {
        job_table = { 'police' },
        coords = data.coords,
        title = '10-15 - 強盗事件',
        message = ('%sが%sで強盗をしています'):format(data.sex, data.street),
        flash = 0,
        unique_id = data.unique_id,
        sound = 1,
        blip = {
            sprite = 431,
            scale = 1.2,
            colour = 3,
            flashes = false,
            text = '911 - 強盗事件',
            time = 5, -- ブリップの表示時間(分)
            radius = 0,
        }
    })
end

RegisterCommand('triggerrobbery', reportRobbery, false)

ショップの防犯アラーム(Tier3-26)と組み合わせる例

RegisterNetEvent('shop:robbed')
AddEventHandler('shop:robbed', function()
    local playerId = source
    local ped = GetPlayerPed(playerId)
    local coords = GetEntityCoords(ped)

    TriggerClientEvent('cd_dispatch:AddNotification', -1, {
        job_table = { 'police' },
        coords = coords,
        title = '10-15 - 店舗強盗',
        message = '店舗で強盗が発生しました',
        sound = 1,
        blip = { sprite = 431, scale = 1.2, colour = 3, text = '911 - 店舗強盗', time = 5, radius = 0 }
    })
end)

注意点・よくあるミス

  • job_tableに指定したJob名('police'等)は、実際にフレームワーク側で登録されているJob名(Tier4-01参照)と完全に一致している必要があります。
  • 通報を誰でも自由に発火できる状態にすると、いたずらで通報を連発される危険があります。実際のゲームイベント(強盗の実行成功など)に紐付けて発火させ、コマンド単体で誰でも呼べないようにしてください。
  • cd_dispatchは有償スクリプトであり、バージョンによってAddNotificationのテーブル構造(特にunique_idのようなフィールド)が変わる場合があります。導入しているバージョンの公式ドキュメント(docs.codesign.pro)を確認してください。

補足

Tier3-28で学んだ無線チャンネルシステムと組み合わせることで、「通知を受け取った警察官同士が同じ無線チャンネルで連携する」という、より実践的なディスパッチシステムに発展させられます。
