lb-phoneアプリのスターターテンプレート

結論

このレッスンを終えると、lb-phoneアプリを作るときに毎回ゼロから書く必要がある「型」を理解し、コピーしてすぐ次のアプリ開発に取り掛かれるようになります。これまでのTier4-04・Tier4-05で学んだ知識を、実際に動く最小構成のアプリとして初めてひとまとめに提示します。

こんな時に使う: 新しいlb-phoneアプリを作り始めるたびに、この構成をコピーして中身を書き換えていく出発点として使います。

説明

lb-phoneアプリは、①`Config.CustomApps`へのアプリ登録(Tier4-04)、②アプリを開いたときにデータを送るLua側の処理、③データを受け取って画面を描画するJS側の処理、という3点セットで成り立っています。この型さえ押さえれば、あとは中身(表示するデータ・操作)を差し替えるだけで次々に新しいアプリを作れます。

コード例

ディレクトリ構成

my-phone-app/
├── fxmanifest.lua
├── client.lua
└── ui/
    ├── index.html
    ├── style.css
    └── script.js

fxmanifest.lua

fx_version 'cerulean'
game 'gta5'

client_script 'client.lua'

ui_page 'ui/index.html'
files {
    'ui/index.html',
    'ui/style.css',
    'ui/script.js'
}

lb-phone/config/config.lua への追記(Tier4-04参照)

Config.CustomApps = {
    ["my_phone_app"] = {
        name = "マイアプリ",
        description = "自作の連携アプリです",
        developer = "自分の名前",
        defaultApp = true,
        ui = "my-phone-app/ui/index.html",
    },
}

client.lua: アプリを開いたらデータを送る

RegisterNetEvent('myPhoneApp:open')
AddEventHandler('myPhoneApp:open', function()
    exports['lb-phone']:SendCustomAppMessage('my_phone_app', {
        action = 'open',
        title = 'マイアプリ',
        items = { '1件目のデータ', '2件目のデータ', '3件目のデータ' }
    })
end)

ui/index.html

<!doctype html>
<html>
<head>
  <meta charset="utf-8">
  <link rel="stylesheet" href="style.css">
</head>
<body>
  <div id="app" class="app">
    <header class="app-header">
      <h1 id="app-title">マイアプリ</h1>
    </header>
    <main id="app-body" class="app-body">
      <p id="placeholder">まだデータを受信していません</p>
    </main>
  </div>
  <script src="script.js"></script>
</body>
</html>

ui/script.js: データを受け取って描画する

function handleAppMessage(data) {
  if (data.action !== 'open') return;

  document.getElementById('app').style.display = 'flex';
  document.getElementById('app-title').textContent = data.title || 'マイアプリ';

  const body = document.getElementById('app-body');
  body.innerHTML = '';

  data.items.forEach((item) => {
    const el = document.createElement('p');
    el.textContent = item;
    body.appendChild(el);
  });
}

window.addEventListener('message', (event) => {
  handleAppMessage(event.data);
});

実際に動かして確認できるサンプル一式を samples/lb-phone-starter/ui/index.html に用意しています。ブラウザで開き、画面左下の「デモ」ボタンを押すと、SendCustomAppMessageを受信した想定の画面を確認できます。

注意点・よくあるミス

  • Config.CustomAppsのキー("my_phone_app")、SendCustomAppMessageの第1引数、uiのパスの3箇所は全て一致している必要があります(Tier4-04/Tier4-05の注意点の再確認です)。
  • lb-phoneアプリの画面はスマホの限られたサイズの中に描画されます。CSSは320×560程度の縦長サイズを前提に、はみ出さないレイアウトを組んでください(このサンプルのstyle.cssを参照)。
  • このテンプレートは「開いたら即座にデータを送る」設計です。Tier4-05で学んだ通り、実際のアプリではonOpen直後にUIがまだ読み込み中の場合があるため、より丁寧に作る場合はUI側からの「準備完了」通知を待ってからデータを送る設計にしてください。

補足

この型を土台に、次のレッスン(Tier4-22)で複数画面への遷移、Tier4-23で新着通知バッジを追加していきます。演習ex-08・ex-09では、この型を使って実際に1本のアプリを完成させます。
