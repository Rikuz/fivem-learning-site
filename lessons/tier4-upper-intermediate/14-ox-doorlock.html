ox_doorlockでドアを施錠する

結論

このレッスンを終えると、ox_doorlock(FiveMで広く使われるドア管理リソース)でドアの施錠・解錠を制御することができるようになります。

こんな時に使う: 自宅・店舗のドアに鍵をかけたい、権限のある人だけがドアを開けられるようにしたいとき。

説明

ox_doorlockは、GTA Vのマップ上にある扉(ドア)をゲーム内コマンドで登録し、施錠状態をDBで管理してくれるリソースです。ドア自体の登録はゲーム内の/doorlockコマンドでその場に立って行い(Luaファイルに座標を直接書く方式ではありません)、以後はdoorIdという番号でそのドアを操作します。

コード例

ドアを施錠・解錠する

-- state: trueまたは1で施錠、falseまたは0で解錠
exports.ox_doorlock:setDoorState(doorId, true)  -- 施錠
exports.ox_doorlock:setDoorState(doorId, false) -- 解錠

ドアの情報を取得する

local door = exports.ox_doorlock:getDoor(doorId)
local doorByName = exports.ox_doorlock:getDoorFromName('my_house_door')

if door then
    print('施錠状態: ' .. tostring(door.state))
end

ox_targetと組み合わせて、鍵を持っている人だけ操作できるようにする例

RegisterNetEvent('myscript:toggleHouseDoor')
AddEventHandler('myscript:toggleHouseDoor', function(doorId)
    local playerId = source
    local hasKey = playerHasHouseKey(playerId) -- 自作の鍵所持チェック関数(Tier3-04のインベントリ確認等)

    if not hasKey then
        TriggerClientEvent('myscript:notify', playerId, '鍵を持っていません')
        return
    end

    local door = exports.ox_doorlock:getDoor(doorId)
    exports.ox_doorlock:setDoorState(doorId, not door.state)
end)

設定を編集する

exports.ox_doorlock:editDoor(doorId, { distance = 3.0 }) -- 操作可能な距離を変更する例

注意点・よくあるミス

  • ドアの登録自体はLua設定ファイルではなくゲーム内コマンドで行う点に注意してください。「Config.luaにドアの座標を書けばいい」と勘違いしないようにしましょう。
  • 鍵の所持判定(誰が開けられるか)は、ox_doorlock自体の機能ではなく自分のスクリプト側で実装する必要があります。上記コード例のように、自作のチェックとsetDoorStateを組み合わせてください。
  • 施錠・解錠の判定は必ずserver側で行い、client側から直接setDoorStateを呼び放題にしないでください(Tier3-05のサーバー側バリデーションと同じ考え方)。

補足

本レッスンのexport構文(setDoorState、getDoor、getDoorFromName、editDoor)はOverextended公式ドキュメント(overextended.dev/docs/ox_doorlock)で確認済みです。ドアの登録手順(/doorlockコマンドの詳しい使い方)は、導入しているバージョンのREADMEも確認してください。
