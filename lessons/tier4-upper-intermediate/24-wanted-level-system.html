指名手配度(Wanted Level)システム

結論

このレッスンを終えると、犯罪行為を行うたびにプレイヤーの指名手配度が上がり、その情報を警察側(Tier4-28のMDT)から確認できる仕組みを自作できるようになります。ここから始まる犯罪script系レッスンの土台となる、最も基本的なシステムです。

こんな時に使う: 強盗・薬物取引など「見つかったらまずい行為」をしたプレイヤーに、ゲーム内でのペナルティ・警察の追跡対象という状態を持たせたいとき。

説明

指名手配度は「プレイヤーIDに紐付いた数値」というシンプルなデータですが、①犯罪行為で加算する、②時間経過で自然に減少させる、③警察側から一覧で確認できるようにする、という3つの動きを組み合わせて設計します。GTA Vのゲーム内の星マーク(SetPlayerWantedLevel)とは別に、RPサーバー独自の「スコア」として管理するのが一般的です。

コード例

server.lua: 指名手配度を管理する

local wantedLevels = {} -- playerId -> 数値(0〜100等)

local function addWantedLevel(playerId, amount, reason)
    local current = wantedLevels[playerId] or 0
    wantedLevels[playerId] = math.min(100, current + amount)

    print(('プレイヤー%sの指名手配度が%sになりました(理由: %s)'):format(playerId, wantedLevels[playerId], reason))
    TriggerClientEvent('myscript:notify', playerId, '指名手配度が上昇しました', 'warning')
end

local function getWantedLevel(playerId)
    return wantedLevels[playerId] or 0
end

exports('AddWantedLevel', addWantedLevel)
exports('GetWantedLevel', getWantedLevel)

server.lua: 時間経過で自然に減少させる

CreateThread(function()
    while true do
        Wait(60 * 1000) -- 1分ごと

        for playerId, level in pairs(wantedLevels) do
            if level > 0 then
                wantedLevels[playerId] = math.max(0, level - 5)
            end
        end
    end
end)

使用例: 薬物取引を行うと指名手配度が上がる

RegisterNetEvent('drugs:sellToNpc')
AddEventHandler('drugs:sellToNpc', function()
    local playerId = source
    -- 実際の販売処理(Tier4-25参照)

    exports['my-wanted-system']:AddWantedLevel(playerId, 15, '薬物取引')
end)

警察側から一覧を取得する(Tier4-28 MDTで使用)

local function getAllWantedPlayers()
    local result = {}
    for playerId, level in pairs(wantedLevels) do
        if level > 0 and GetPlayerName(playerId) then -- オンライン中のプレイヤーのみ
            table.insert(result, { id = playerId, name = GetPlayerName(playerId), level = level })
        end
    end
    return result
end

exports('GetAllWantedPlayers', getAllWantedPlayers)

注意点・よくあるミス

  • 指名手配度の加算は、必ずTier3-05のサーバー側バリデーションを経た正当な犯罪行為の結果としてのみ行ってください。clientから直接「指名手配度を上げて」と送らせる設計は、逆にチートで指名手配度を消される危険があります。
  • 時間経過での減少処理を入れないと、一度犯罪を犯したプレイヤーが永久に指名手配され続けてしまいます。ゲームバランスとして減少速度を調整してください。
  • 切断したプレイヤーのエントリ(wantedLevels[playerId])を放置すると、再接続時に別のプレイヤーIDへ再割り当てされたときに古いデータが誤って引き継がれる可能性があります。Tier2-15のplayerDroppedと組み合わせ、切断時にDBへ保存してからメモリを片付ける設計が安全です(再接続時は識別子ベースで復元する)。

補足

GTA V本編のSetPlayerWantedLevel(画面上の星マーク)と、このレッスンで作った独自の指名手配度は別物です。両方を連動させたい場合(星の数に応じてNPC警官が追ってくる等)は、このスコアの値に応じてSetPlayerWantedLevelを呼ぶ処理を追加で組み合わせてください。
