アプリ内の画面遷移と戻る操作

結論

このレッスンを終えると、1つのアプリの中で「一覧画面→詳細画面」のように複数の画面を切り替え、戻るボタンで前の画面に戻ることができるようになります。Tier4-21のスターターテンプレートは1画面だけでしたが、実際のアプリの多くは複数画面で構成されています。

こんな時に使う: メッセージ一覧から1件をタップすると詳細が開く、商品一覧から詳細ページに遷移する、といった構成のアプリを作りたいとき。

説明

lb-phoneアプリのHTMLはページ遷移(別のHTMLファイルへの移動)をしません。1つのHTML内で、画面ごとの要素を用意し、JSでそれらのCSS表示/非表示を切り替えるという、SPA(Single Page Application。1つのHTMLの中でJSが画面内容を書き換えていく作り方)的な手法を使います。どの画面が今開いているかを表す「画面スタック(履歴)」をJS側の配列で管理すると、戻るボタンの実装も自然に書けます。

コード例

ui/index.html: 画面ごとにdivを用意する

<div id="app" class="app">
  <header class="app-header">
    <button id="back-btn" class="back-btn" style="display:none">← 戻る</button>
    <h1 id="app-title">一覧</h1>
  </header>

  <div id="screen-list" class="screen">
    <!-- 一覧画面の中身(JSで動的に追加) -->
  </div>

  <div id="screen-detail" class="screen" style="display:none">
    <!-- 詳細画面の中身(JSで動的に追加) -->
  </div>
</div>

ui/script.js: 画面スタックで管理する

const screenStack = ['screen-list']; // 現在開いている画面の履歴(末尾が現在の画面)

function showScreen(screenId) {
  // 全ての画面を一旦隠す
  document.querySelectorAll('.screen').forEach((el) => {
    el.style.display = 'none';
  });

  document.getElementById(screenId).style.display = 'block';

  // 一覧画面(履歴の一番最初)以外なら戻るボタンを表示する
  document.getElementById('back-btn').style.display =
    screenStack.length > 1 ? 'inline-block' : 'none';
}

function navigateTo(screenId) {
  screenStack.push(screenId);
  showScreen(screenId);
}

function goBack() {
  if (screenStack.length <= 1) return; // これ以上戻れない(一覧画面が最初)
  screenStack.pop();
  showScreen(screenStack[screenStack.length - 1]);
}

document.getElementById('back-btn').addEventListener('click', goBack);

一覧のアイテムをクリックしたら詳細画面に遷移する例

function renderList(items) {
  const container = document.getElementById('screen-list');
  container.innerHTML = '';

  items.forEach((item, index) => {
    const el = document.createElement('p');
    el.textContent = item.title;
    el.addEventListener('click', () => {
      renderDetail(item);
      navigateTo('screen-detail');
    });
    container.appendChild(el);
  });
}

function renderDetail(item) {
  document.getElementById('screen-detail').innerHTML = `
${item.body}
`;
}

注意点・よくあるミス

  • 戻るボタンの表示・非表示は、画面スタックの長さを見て判断してください。単純に「詳細画面かどうか」で分岐すると、画面数が増えたときに対応できなくなります。
  • screenStackに画面IDをpushするだけでpopし忘れると、戻るボタンを何度押しても同じ画面に留まり続けるバグになります。navigateToとgoBackを必ずセットで使ってください。
  • アプリを閉じて再度開いたときに、前回の画面(詳細画面)が残ったままにならないよう、開くたびにscreenStackを初期状態にリセットする処理を入れてください。

補足

この「戻る」の仕組みは、通常のNUI(Tier3-38で学んだEscキーでの全体クローズ)とは役割が異なります。Escキーは「アプリ全体を閉じる」、この戻るボタンは「アプリ内の1つ前の画面に戻る」という違いを意識してください。両方を組み合わせ、「詳細画面ではEscで一覧に戻り、一覧画面でEscでアプリを閉じる」という多段階の挙動にすることもできます。
