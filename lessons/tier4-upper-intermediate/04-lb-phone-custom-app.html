lb-phoneにカスタムアプリを追加する

結論

このレッスンを終えると、lb-phone(FiveMで広く使われるスマートフォンリソース)に自作のアプリを登録し、動的に追加・削除することができるようになります。

説明

lb-phoneのカスタムアプリは、lb-phone/config/config.luaのConfig.CustomAppsにアプリ情報を登録することで追加できます。加えて、条件によってアプリを持たせたり取り上げたりしたい場合(例: 警察官だけが持つ専用アプリ)は、AddCustomApp/RemoveCustomAppというexportをスクリプトから呼び出します。

コード例

lb-phone/config/config.lua: アプリの登録

Config.CustomApps = {
    ["my_custom_app"] = { -- アプリの識別子(ユーザーには表示されない)
        name = "マイアプリ",                 -- ユーザーに表示されるアプリ名
        description = "自作の連携アプリです",  -- 説明文
        developer = "自分の名前",             -- 任意
        defaultApp = true,                   -- trueならダウンロード不要で最初から入っている
        ui = "my-resource/ui/index.html",    -- カスタムUIを使う場合のパス
    },
}

Lua側エクスポート: アプリの動的な追加・削除

-- アプリを追加する
exports['lb-phone']:AddCustomApp('my_custom_app')

-- アプリを削除する
exports['lb-phone']:RemoveCustomApp('my_custom_app')

実例: 警察官のときだけ専用アプリを持たせる

RegisterNetEvent('myscript:updateJob')
AddEventHandler('myscript:updateJob', function(jobName)
    if jobName == 'police' then
        exports['lb-phone']:AddCustomApp('police_app')
    else
        exports['lb-phone']:RemoveCustomApp('police_app')
    end
end)

注意点・よくあるミス

  • Config.CustomAppsのキー("my_custom_app")と、AddCustomApp/RemoveCustomAppに渡す文字列は完全に一致している必要があります。1文字でも違うとアプリが認識されません。
  • defaultApp = trueにすると、条件に関わらず全プレイヤーに最初からアプリが入った状態になります。「特定のJobの人だけ」のように条件付きで持たせたい場合はdefaultApp = falseにし、上記のようにAddCustomAppを条件分岐で呼び出してください。
  • uiに指定するパスの起点はlb-phone側の解決ルールに従います(resource名を含めた相対パス)。実際に導入しているlb-phoneのバージョンのドキュメント内の記法に合わせてください。
