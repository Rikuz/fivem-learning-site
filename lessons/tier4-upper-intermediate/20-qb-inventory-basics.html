qb-inventoryの基本

結論

このレッスンを終えると、QBCore環境で標準的に使われるqb-inventoryのアイテム操作・使用可能アイテム登録ができるようになります。これまでのTier3-04・Tier3-30・Tier3-31で学んだox_inventoryとは別系統のインベントリで、導入しているサーバーに応じて使い分けます。

説明

ox_inventoryとqb-inventoryは、どちらも「アイテムを増減させる」という役割は同じですが、exportの名前・引数の並び、アイテムを使用可能にする仕組みが異なります。QBCoreサーバーの多くはqb-inventoryを標準採用しているため、Tier4-01でQBCoreを検知した場合はこちらを使うことになります。

コード例

アイテムを追加・削除する

-- AddItem(source, itemName, amount, info, reason)
exports['qb-inventory']:AddItem(source, 'phone', 1)

-- metadata(耐久値・弾数・シリアル番号等)付きで追加する
exports['qb-inventory']:AddItem(source, 'weapon_pistol', 1, false, {
    durability = 100,
    ammo = 12,
    serial = 'ABC123XYZ'
})

-- RemoveItem(source, itemName, amount, slot, reason)
exports['qb-inventory']:RemoveItem(source, 'phone', 1)

-- 特定のスロットからピンポイントで削除する
exports['qb-inventory']:RemoveItem(source, 'phone', 1, 5)

使用可能アイテムを登録する

-- QBCore本体の機能。ox_inventoryのitems.lua(client.export)とは異なる方式
QBCore.Functions.CreateUseableItem('lockpick', function(source, item)
    local Player = QBCore.Functions.GetPlayer(source)

    if Player.Functions.GetItemByName('lockpick') then
        TriggerClientEvent('lockpick:client:use', source)
    end
end)

フレームワークを検知して切り替える例(Tier4-01の応用)

local function addItemToPlayer(source, itemName, amount)
    if GetResourceState('ox_inventory') == 'started' then
        exports.ox_inventory:AddItem(source, itemName, amount)
    elseif GetResourceState('qb-inventory') == 'started' then
        exports['qb-inventory']:AddItem(source, itemName, amount)
    end
end

注意点・よくあるミス

  • ox_inventoryのAddItem(source, item, count, metadata, slot)とqb-inventoryのAddItem(source, itemName, amount, info, reason)は引数の役割が似ていても順序・意味が異なります。片方の書き方をもう片方にそのまま流用しないでください。
  • 使用可能アイテムの仕組みも異なります。ox_inventoryはitems.luaのclient.exportフィールドでどのexportを呼ぶか事前に紐付けるのに対し、qb-inventoryはQBCore.Functions.CreateUseableItemを(通常はresourceの初期化時に)呼んで登録します。
  • ox_inventoryとqb-inventoryを同時に導入するのは避けてください。プレイヤーの所持アイテムが2つのシステムに分散し、整合性が取れなくなります。

補足

本レッスンの構文は公式ドキュメント(docs.qbcore.org)およびGitHub公式リポジトリ(github.com/qbcore-framework/qb-inventory, qb-core)で確認済みです。導入しているサーバーがQBCore+qb-inventoryなのか、QBCore+ox_inventoryなのか(近年はQBCoreサーバーでもox_inventoryを併用するケースが増えています)は、実際にインストールされているresourceを確認してから実装してください。バージョンによって仕様が変わる場合があるため、公式ドキュメントも確認してください。
