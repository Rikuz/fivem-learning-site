アプリの新着通知バッジ

結論

このレッスンを終えると、プレイヤーがアプリを開いていなくても、ホーム画面のアプリアイコンに未読件数のバッジを表示することができるようになります。メッセージアプリやデリバリー依頼アプリで「新着があるかどうか一目でわかる」体験を作れます。

こんな時に使う: 演習ex-08のメッセージアプリで新着メッセージがあることを知らせたい、演習ex-09のデリバリーアプリで新しい依頼を知らせたいとき。

説明

Tier4-05で学んだSendCustomAppMessageは、アプリを開いているときの画面更新に使ってきましたが、実はアプリを開いていない状態でも呼び出せます。lb-phone本体がアイコンにバッジ数を表示する専用のメッセージ形式を用意しているため、それに従ってデータを送るだけでバッジが更新されます。

コード例

server.lua: 新着があったらバッジ数を送る

local unreadCounts = {} -- playerId -> 未読件数(メモリ管理。実運用ではDBと同期させる)

local function notifyNewMessage(targetPlayerId)
    unreadCounts[targetPlayerId] = (unreadCounts[targetPlayerId] or 0) + 1

    TriggerClientEvent('myscript:updateBadge', targetPlayerId, unreadCounts[targetPlayerId])
end

client.lua: バッジ更新をlb-phoneに伝える

RegisterNetEvent('myscript:updateBadge')
AddEventHandler('myscript:updateBadge', function(count)
    exports['lb-phone']:SendCustomAppMessage('my_phone_app', {
        action = 'updateBadge',
        count = count
    })
end)

アプリを開いたら未読を既読にする

RegisterNetEvent('myPhoneApp:open')
AddEventHandler('myPhoneApp:open', function()
    local playerId = source
    unreadCounts[playerId] = 0

    -- バッジを0にリセットする通知も送る
    TriggerClientEvent('myscript:updateBadge', playerId, 0)

    exports['lb-phone']:SendCustomAppMessage('my_phone_app', {
        action = 'open',
        -- ...一覧データ等
    })
end)

ui/script.js側: action分岐にバッジ更新を追加する(Tier4-21の型を拡張)

window.addEventListener('message', (event) => {
  const data = event.data;

  if (data.action === 'open') {
    handleAppMessage(data);
  } else if (data.action === 'updateBadge') {
    // lb-phone側がこのメッセージを見てアイコンのバッジを更新する
    // (アプリ画面自体には特別な描画は不要な場合が多い)
  }
});

注意点・よくあるミス

  • バッジ用のメッセージ(SendCustomAppMessage)は、Tier4-21のような画面更新用メッセージと同じアプリ識別子('my_phone_app')に送る必要があります。アプリ識別子が食い違うと、そもそも対象のアプリが見つからずバッジが更新されません。
  • 未読数をメモリ上のテーブルだけで管理していると、サーバー再起動で消えてしまいます。実運用ではTier3-15の自動保存パターンや、ex-08のDB設計と組み合わせて未読状態を永続化してください。
  • アプリを開いた瞬間に必ずバッジを0にリセットする処理を忘れると、既読にしたはずなのにバッジが残り続けるバグになります。

補足

バッジ機能自体の詳細なメッセージ形式(action名や必須フィールド)は、導入しているlb-phoneのバージョンによって呼び方が異なる場合があります。本レッスンは「開いていないアプリにも通知を送れる」という考え方の紹介であり、実装時は導入しているlb-phoneのドキュメントで正確な形式を確認してください。
