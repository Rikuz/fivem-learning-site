家具設置システム(プロップの設置・削除・保存)

結論

このレッスンを終えると、家具(プロップ)を仮配置してから座標を確定し、DBに保存してresource再起動後も復元される家具設置システムを作れるようになります。Tier2-09のオブジェクト生成を「配置モード」という形に発展させます。

こんな時に使う: Tier4-34で購入できるようにした物件の内部に、プレイヤー自身が家具を配置できるようにしたいとき。

説明

家具設置は「①プレビュー用のオブジェクトをプレイヤーの少し前方に仮生成する」「②キー操作で位置・向きを微調整する」「③確定キーで座標をDBに保存し、プレビューを本設置に切り替える」という3ステップで作ります。設置した家具はresource起動時にDBから読み込んで再生成することで、サーバー再起動後も家具が消えないようにします。

コード例

SQL: 家具配置テーブル

CREATE TABLE IF NOT EXISTS `property_furniture` (
  `id` INT AUTO_INCREMENT PRIMARY KEY,
  `property_id` VARCHAR(50) NOT NULL,
  `model` VARCHAR(50) NOT NULL,
  `x` FLOAT NOT NULL,
  `y` FLOAT NOT NULL,
  `z` FLOAT NOT NULL,
  `heading` FLOAT NOT NULL
);

client.lua: プレビューを生成し、キーで位置を微調整する

local previewObject = nil

local function startPlacement(model)
    RequestModel(model)
    while not HasModelLoaded(model) do Wait(0) end

    local ped = PlayerPedId()
    local coords = GetEntityCoords(ped)

    previewObject = CreateObject(model, coords.x, coords.y, coords.z, false, false, false)
    SetEntityAlpha(previewObject, 150, false) -- 半透明にしてプレビューだと分かるようにする
    SetEntityCollision(previewObject, false, false)
    FreezeEntityPosition(previewObject, true)
    SetModelAsNoLongerNeeded(model)
end

CreateThread(function()
    while true do
        Wait(0)
        if previewObject then
            local coords = GetEntityCoords(previewObject)
            local heading = GetEntityHeading(previewObject)

            -- 上下矢印キー(control 172/173)で前後移動、左右矢印キー(control 174/175)で回転する
            if IsControlJustPressed(0, 172) then SetEntityCoords(previewObject, coords.x, coords.y + 0.1, coords.z, false, false, false, false) end
            if IsControlJustPressed(0, 173) then SetEntityCoords(previewObject, coords.x, coords.y - 0.1, coords.z, false, false, false, false) end
            if IsControlJustPressed(0, 174) then SetEntityHeading(previewObject, heading - 5.0) end
            if IsControlJustPressed(0, 175) then SetEntityHeading(previewObject, heading + 5.0) end
        end
    end
end)

client.lua / server.lua: 設置を確定してDBに保存する

-- client.lua: Enterキー(control 191)で確定する
RegisterCommand('confirm_placement', function()
    if not previewObject then return end

    local coords = GetEntityCoords(previewObject)
    local heading = GetEntityHeading(previewObject)
    local model = GetEntityModel(previewObject)

    SetEntityAlpha(previewObject, 255, false)
    SetEntityCollision(previewObject, true, true)
    previewObject = nil -- プレビュー管理から外す(実体は残す)

    TriggerServerEvent('housing:saveFurniture', GetCurrentPropertyId(), model, coords.x, coords.y, coords.z, heading)
end, false)
RegisterKeyMapping('confirm_placement', '家具の設置を確定する', 'keyboard', 'RETURN')
-- server.lua: 所有者本人であることを確認してから保存する
RegisterNetEvent('housing:saveFurniture')
AddEventHandler('housing:saveFurniture', function(propertyId, model, x, y, z, heading)
    local playerId = source
    local identifier = GetPlayerIdentifierByType(playerId, 'license')

    local owner = MySQL.scalar.await('SELECT owner_identifier FROM property_owners WHERE property_id = ?', { propertyId })
    if owner ~= identifier then return end -- Tier4-34の所有権確認と同じパターン

    MySQL.insert('INSERT INTO property_furniture (property_id, model, x, y, z, heading) VALUES (?, ?, ?, ?, ?, ?)', {
        propertyId, model, x, y, z, heading
    })
end)

client.lua: 物件に入る際、保存済みの家具を復元する

RegisterNetEvent('housing:loadFurniture')
AddEventHandler('housing:loadFurniture', function(furnitureList)
    for _, item in ipairs(furnitureList) do
        RequestModel(item.model)
        while not HasModelLoaded(item.model) do Wait(0) end

        local obj = CreateObject(item.model, item.x, item.y, item.z, false, false, false)
        SetEntityHeading(obj, item.heading)
        FreezeEntityPosition(obj, true)
        SetModelAsNoLongerNeeded(item.model)
    end
end)

注意点・よくあるミス

  • 設置確定の保存処理は必ずserver側で所有権を確認してください。他人の物件に無断で家具を設置されることを防げます(Tier4-34と同じ考え方)。
  • プレビュー用のオブジェクト(previewObject)は半透明・当たり判定なしにしておき、確定後の実体と見分けがつくようにしましょう。
  • 家具を大量に設置できてしまうとパフォーマンスに影響します。1物件あたりの設置上限数をserver側でチェックする処理を追加することをおすすめします。
  • 物件から退出する際、復元した家具オブジェクトをDeleteEntityで確実に削除してください。放置するとクライアントのメモリを圧迫します。

補足

上記コード例は方向キーでの簡易的な微調整ですが、発展させる場合はカメラの向きに応じた移動(GetGameplayCamRotとの組み合わせ)や、マウスホイールでの回転など、より直感的な操作方法も検討できます。次のレッスン(Tier4-36)では、この物件に収納・施錠の機能を追加します。
