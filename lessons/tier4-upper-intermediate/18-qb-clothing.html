qb-clothingで服屋システムを使う

結論

このレッスンを終えると、qb-clothing(QBCore向けの服屋・ワードローブスクリプト)で服屋メニューと保存済みアウトフィット一覧を開くことができるようになります。

こんな時に使う: 服屋で服を試着・購入できるようにしたい、自宅のクローゼットで保存した服装(アウトフィット)に着替えられるようにしたいとき。

説明

qb-clothingは、Tier2-13で学んだSetPedComponentVariation等の低レベルな服装操作をUI付きでラップしてくれるリソースです。店舗では服屋メニュー、自宅などではワードローブ(保存済みの服装セット一覧)という、用途に応じた2種類の画面を開けます。

コード例

服屋メニューを開く(Tier3-07のox_targetと組み合わせる例)

exports.ox_target:addBoxZone({
    coords = vec3(72.32, -1399.1, 29.38),
    size = vec3(2.0, 2.0, 3.0),
    options = {
        {
            name = 'open_clothing_store',
            icon = 'fas fa-shirt',
            label = '服屋を利用する',
            onSelect = function()
                TriggerEvent('qb-clothing:client:openMenu')
            end,
        }
    }
})

保存済みのワードローブを開く

exports.ox_target:addBoxZone({
    coords = vec3(-1039.7, -2745.9, 20.17), -- 自宅のクローゼット等を想定
    size = vec3(1.0, 1.0, 2.0),
    options = {
        {
            name = 'open_wardrobe',
            icon = 'fas fa-door-open',
            label = 'クローゼットを開く',
            onSelect = function()
                TriggerEvent('qb-clothing:client:openOutfitMenu')
            end,
        }
    }
})

注意点・よくあるミス

  • qb-clothing:client:openMenu(服屋・見た目編集全般)とqb-clothing:client:openOutfitMenu(保存済みアウトフィット一覧)は役割が異なります。「服を購入・カスタムする店舗」には前者、「保存した服装に着替えるだけのクローゼット」には後者を使うのが自然です。
  • qb-clothingはQBCore(またはQBCore互換のQbox)を前提に設計されています。ESXベースのサーバーでは、別のクロージングスクリプト(illenium-appearanceの一部機能等)を検討してください。
  • どちらのイベントも引数なしで呼び出すだけのシンプルなものですが、店舗の場所ごとに販売する服の種類を制限したい場合は、qb-clothing側の設定ファイル(Config.Stores)側での調整が必要です。

補足

本レッスンのイベント名(qb-clothing:client:openMenu、qb-clothing:client:openOutfitMenu)は、公式GitHubリポジトリ(github.com/qbcore-framework/qb-clothing)のソースコードで実際に定義されていることを確認済みです。バージョンによって仕様が変わる場合があるため、公式ドキュメント(docs.qbcore.org)も確認してください。
