試乗(テストドライブ)システム

結論

このレッスンを終えると、ディーラーの車両を制限時間付きで無料貸し出しし、時間切れやエリア外逸脱時に自動回収する試乗システムを作れるようになります。Tier4-12の中古車販売店に、実際のディーラー体験に欠かせない試乗機能を追加します。

こんな時に使う: Tier4-12で作った販売店に、「購入前に乗り心地を確認できる」機能を追加したいとき。

説明

試乗は「①試乗車をスポーンする」「②制限時間のタイマーを開始する」「③時間切れ、またはディーラーエリアから離れすぎたら車両を回収する」という流れです。Tier4-30の投獄システムで使った「エリア外に出たら強制的に戻す」考え方と、Tier4-33のジョブ専用車両の貸出/回収の考え方を組み合わせるだけで実装できます。

コード例

client.lua: 試乗を開始する

local DEALERSHIP_COORDS = vec3(-56.0, -1096.0, 26.0)
local TEST_DRIVE_DURATION_MS = 3 * 60 * 1000 -- 3分間

local testDriveVehicle = nil
local testDriveEndsAt = nil

RegisterNetEvent('dealership:startTestDrive')
AddEventHandler('dealership:startTestDrive', function(model)
    RequestModel(model)
    while not HasModelLoaded(model) do Wait(0) end

    testDriveVehicle = CreateVehicle(model, DEALERSHIP_COORDS.x, DEALERSHIP_COORDS.y, DEALERSHIP_COORDS.z, 0.0, true, false)
    SetVehicleOnGroundProperly(testDriveVehicle)
    SetModelAsNoLongerNeeded(model)

    local ped = PlayerPedId()
    TaskWarpPedIntoVehicle(ped, testDriveVehicle, -1)

    testDriveEndsAt = GetGameTimer() + TEST_DRIVE_DURATION_MS
    TriggerEvent('myscript:notify', '試乗開始(3分間)', 'success')
end)

client.lua: 時間切れ・エリア外逸脱で回収する

local function endTestDrive(reason)
    if not testDriveVehicle or not DoesEntityExist(testDriveVehicle) then return end

    local ped = PlayerPedId()
    if IsPedInVehicle(ped, testDriveVehicle, false) then
        TaskLeaveVehicle(ped, testDriveVehicle, 0)
    end

    SetEntityAsMissionEntity(testDriveVehicle, true, true)
    DeleteEntity(testDriveVehicle)
    testDriveVehicle = nil
    testDriveEndsAt = nil

    TriggerEvent('myscript:notify', ('試乗を終了しました(%s)'):format(reason), 'warning')
end

CreateThread(function()
    while true do
        Wait(1000)

        if testDriveEndsAt then
            if GetGameTimer() >= testDriveEndsAt then
                endTestDrive('時間切れ')
            elseif testDriveVehicle and DoesEntityExist(testDriveVehicle) then
                local distance = #(GetEntityCoords(testDriveVehicle) - DEALERSHIP_COORDS)
                if distance > 500.0 then -- 販売店から離れすぎたら強制終了する
                    endTestDrive('エリア外')
                end
            end
        end
    end
end)

注意点・よくあるミス

  • 試乗車は売却不可・改造不可にする必要があります。試乗中に別のショップで転売されたり改造されたりしないよう、既存のショップ・改造系イベント側で「試乗車かどうか」を確認する処理を追加することを検討してください。
  • 試乗車が事故で破損した場合の扱い(修理費を請求する、単に回収するだけにする等)を事前に決めておきましょう。
  • 時間切れの判定を長い間隔(上記コード例は1秒)で行っているため、正確に3分ちょうどで切れるわけではありません。誤差を許容できる範囲で間隔を調整してください。
