フレームワークで職業(Job)システムを使う

結論

このレッスンを終えると、プレイヤーの職業(Job)を確認し、職業専用のエリア・NPCへのアクセスを制限し、一定時間ごとに給料を支払う仕組みが作れるようになります。

説明

ESX・QBCore・Qboxでは「Job(職業)」という概念でプレイヤーの所属(警察官・救急隊員など)と階級(grade)を管理します。ox_coreでは考え方が近い概念として「group(グループ)」が使われます。これらを条件分岐に使うことで、「警察官だけが入れる部屋」「タクシー運転手だけが使える車両」といった制御ができます。

コード例

ESX: Jobの確認

local ESX = exports['es_extended']:getSharedObject()

RegisterNetEvent('myscript:enterPoliceRoom')
AddEventHandler('myscript:enterPoliceRoom', function()
    local xPlayer = ESX.GetPlayerFromId(source)

    if xPlayer.job.name ~= 'police' then
        TriggerClientEvent('myscript:notify', source, '警察官専用エリアです')
        return
    end

    TriggerClientEvent('myscript:teleportToPoliceRoom', source)
end)

QBCore / Qbox: Jobの確認

local QBCore = exports['qb-core']:GetCoreObject()

RegisterNetEvent('myscript:enterPoliceRoom')
AddEventHandler('myscript:enterPoliceRoom', function()
    local Player = QBCore.Functions.GetPlayer(source)

    if Player.PlayerData.job.name ~= 'police' then
        TriggerClientEvent('myscript:notify', source, '警察官専用エリアです')
        return
    end

    TriggerClientEvent('myscript:teleportToPoliceRoom', source)
end)

給料処理の実装例(QBCore)

-- 30分ごとに、勤務中の全プレイヤーへJobの給料を支払う
CreateThread(function()
    while true do
        Wait(30 * 60 * 1000) -- 30分

        for _, playerId in ipairs(QBCore.Functions.GetPlayers()) do
            local Player = QBCore.Functions.GetPlayer(playerId)
            if Player and Player.PlayerData.job.onduty then
                local salary = Player.PlayerData.job.payment
                Player.Functions.AddMoney('bank', salary, 'job-salary')
                TriggerClientEvent('myscript:notify', playerId, ('給料 $%s を受け取りました'):format(salary))
            end
        end
    end
end)

Job専用NPCの表示制御(client.lua)

-- サーバー側からclientへ現在のJobを通知しておき、clientはそれに応じてNPC等の表示を切り替える
local myJob = nil

RegisterNetEvent('myscript:updateJob')
AddEventHandler('myscript:updateJob', function(jobName)
    myJob = jobName
end)

CreateThread(function()
    while true do
        Wait(1000)
        if myJob == 'police' then
            -- 警察専用の武器庫NPCなどをここで表示する処理を書く
        end
    end
end)

注意点・よくあるミス

  • Job名の文字列('police'など)は、実際にフレームワーク側で登録されているJob名と完全に一致している必要があります。タイプミスがあると常に「専用エリアです」と判定されてしまいます。
  • 給料処理をclient側で判定・送金してしまうと、チートでオンデューティ状態を偽装され放題になります。給料の支払い判定・実行は必ずserver側で行ってください。
  • QBCoreのonduty(勤務中かどうか)を確認せずに給料を配ると、オフデューティ中のプレイヤーにも支払われてしまいます。

補足

ox_coreの場合はgroupという概念でアクセス制御を行う設計になっています(例: player.getGroup('police')のようなアクセサで所属や階級を確認する想定)。

⚠️ ox_coreのgroup関連の具体的なメソッド名は、前レッスン同様に本セッションでは一字一句の裏取りができていません。実際に導入するバージョンの公式ドキュメントを確認してください。
