okokBankingV2と連携する

結論

このレッスンを終えると、okokBankingV2(FiveMで広く使われる銀行システムスクリプト)の口座残高を取得し、入出金を行い、取引履歴を記録・取得することができるようになります。

説明

okokBankingV2は、個人口座・ビジネス口座・貯金(savings)・ローンなどをまとめて管理する銀行システムです。自作スクリプトからは、exports経由でokokBankingV2が公開している関数(server側)を呼び出して連携します。

口座はsocietyという識別子で区別されます。個人口座であればプレイヤーのcitizenidなど、ビジネス口座であれば組織名などがsocietyとして使われます(実際にどの値を使うかは導入しているフレームワーク・設定に依存します)。

コード例

口座情報・残高を取得する

local account = exports['okokBanking']:GetAccount(society)

if account then
    print('口座の取得に成功しました')
end

入金する / 出金する

-- 入金する
exports['okokBanking']:AddMoney(society, 500)

-- 出金する(所持金が足りるかは事前にGetAccount等で確認しておく)
exports['okokBanking']:RemoveMoney(society, 200)

取引履歴を記録する

-- citizenid: プレイヤーの識別子(citizenid、Job名、口座識別子など)
-- transactionData: 送金元・送金先・金額・種別・理由などをまとめたテーブル
-- source: 省略可。Discord Webhook通知等に使われるサーバー側のプレイヤーID
exports['okokBanking']:AddTransaction(citizenid, {
    value = 500,
    type = 'deposit', -- deposit(入金) / withdraw(出金) / transfer(送金) /
                       -- savings_deposit / savings_withdraw / savings_transfer / loan_create
    reason = '給料の入金',
}, source)

取引履歴を取得する

-- limitを省略すると全件、0以下を指定すると空テーブルが返る
local allTransactions = exports['okokBanking']:GetPlayerTransactions(citizenid)
local recentTransactions = exports['okokBanking']:GetPlayerTransactions(citizenid, 10)

for _, tx in ipairs(recentTransactions) do
    print(tx.type, tx.value)
end

実例: 自作スクリプトの報酬をプレイヤーの口座に振り込む

RegisterNetEvent('myscript:completeDelivery')
AddEventHandler('myscript:completeDelivery', function()
    local playerId = source
    local citizenid = getCitizenId(playerId) -- 自作スクリプト側でプレイヤーの識別子を取得する処理(Tier4-01参照)
    local reward = 300

    exports['okokBanking']:AddMoney(citizenid, reward)
    exports['okokBanking']:AddTransaction(citizenid, {
        value = reward,
        type = 'deposit',
        reason = '配達報酬',
    }, playerId)

    TriggerClientEvent('myscript:notify', playerId, ('配達報酬 $%s が振り込まれました'):format(reward))
end)

注意点・よくあるミス

  • exportのリソース名は'okokBanking'です(V2でも変わりません)。'okokBankingV2'のようにバージョン名を含めて書くとexportの呼び出しに失敗します。
  • AddMoney/RemoveMoneyを呼ぶだけでは取引履歴には残りません。プレイヤーに見える取引明細やDiscord Webhook通知も出したい場合は、AddTransactionもあわせて呼び出してください。
  • お金の増減処理は必ずserver側で、かつ金額はサーバー側の定義・計算結果のみを使ってください(Tier3「サーバー側バリデーション」・Tier5「セキュリティ強化」と同じ考え方です)。clientから送られてきた金額をそのままAddMoneyに渡してはいけません。

補足

※本レッスンのexport構文(GetAccount, AddMoney, RemoveMoney, AddTransaction, GetPlayerTransactions)は公式ドキュメント(docs.okokscripts.io/scripts/okokbankingv2/exports)で確認済みです。ただしtransactionDataテーブルの詳細なキー構成(sender/receiverの正確なフィールド名など)は公式ドキュメントにも一部しか記載がありませんでした。実際に導入しているバージョンのドキュメント・config.luaも必ず確認してください。バージョンによって仕様が変わる場合があります。
