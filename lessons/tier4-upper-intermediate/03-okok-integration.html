okokシリーズと連携する

結論

このレッスンを終えると、okokNotifyで通知を表示し、okokTextUIで画面下部などにテキストUIを表示することができるようになります。okokシリーズは多くのFiveM RPサーバーで導入されている有償/コミュニティ製スクリプト群です。

説明

okokNotify・okokTextUIは、自分のスクリプトからexports(他のresourceが公開している関数を呼び出す仕組み)経由で呼び出します。通知やテキストUIそのものの見た目・アニメーションはokok側が管理しているため、自分で1からNUIを作らなくても、決まった書き方で呼び出すだけで利用できます。

コード例

okokNotify: 通知を表示する(client側から)

exports['okokNotify']:Alert('タイトル', 'メッセージ', 5000, 'success', true)
-- 第3引数: 表示時間(ミリ秒, 例 5000 = 5秒)
-- 第4引数: タイプ(success=緑 / info=青 / warning=黄 / error=赤 / neutral=灰)
-- 第5引数: 効果音を鳴らすか(true/false)

okokNotify: サーバー側から特定プレイヤーに通知を送る

TriggerClientEvent('okokNotify:Alert', source, 'タイトル', 'メッセージ', 5000, 'success', true)

okokTextUI: テキストUIの表示・非表示

-- 表示
exports['okokTextUI']:Open('[E] 拾う', 'lightblue', 'right')
-- 第2引数: 色(例: lightblue, darkblue など)
-- 第3引数: 位置(left / right)

-- 非表示
exports['okokTextUI']:Close()

組み合わせた実例: アイテムに近づいたらテキストUI、拾ったら通知

local itemLocation = vector3(100.0, 200.0, 30.0)
local isShowingUI = false

CreateThread(function()
    while true do
        local playerCoords = GetEntityCoords(PlayerPedId())
        local distance = #(playerCoords - itemLocation)

        if distance < 2.0 and not isShowingUI then
            exports['okokTextUI']:Open('[E] 拾う', 'lightblue', 'right')
            isShowingUI = true
        elseif distance >= 2.0 and isShowingUI then
            exports['okokTextUI']:Close()
            isShowingUI = false
        end

        if distance < 2.0 and IsControlJustPressed(0, 38) then -- 38 = Eキー
            TriggerServerEvent('myscript:pickupItem')
        end

        Wait(0)
    end
end)

RegisterNetEvent('myscript:itemPickedUp')
AddEventHandler('myscript:itemPickedUp', function()
    exports['okokNotify']:Alert('入手', 'アイテムを拾いました', 5000, 'success', true)
end)

注意点・よくあるミス

  • okokNotify/okokTextUIがensureされていない、または起動順序が自分のresourceより後だと、exportの呼び出しでエラーになります。fxmanifest.luaにdependency 'okokNotify'のように指定して起動順序を保証してください。
  • okokTextUIはOpenを呼びっぱなしにすると表示され続けます。プレイヤーが離れた・条件を満たさなくなったタイミングで確実にClose()を呼んでください(上記コード例のように状態フラグで二重に呼ばないよう管理するのがおすすめです)。
  • これらのexportはclient側のnative関数と組み合わせて使うことが多いですが、通知の元になった判定(アイテムを本当に拾えたか等)はサーバー側で行い、通知はその結果を受けて表示するだけにしましょう(Tier3「サーバー側バリデーション」参照)。

補足

※okokシリーズはサーバーごとに購入・導入するスクリプトであり、バージョンによって引数が増減する場合があります。導入しているokokNotify/okokTextUIのconfig.luaやREADME.mdも必ず確認してください。
