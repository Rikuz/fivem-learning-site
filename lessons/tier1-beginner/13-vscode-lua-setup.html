VS CodeでFiveM開発環境を整える

結論

このレッスンを終えると、VS Codeで変数の補完・関数の引数ヒント・タイプミスの警告が効くように、Lua用の拡張機能とFiveMのnative定義を設定することができるようになります。Tier1-01で軽く触れた内容を、実際に手を動かして設定します。

説明

標準のVS CodeはLuaの構文を理解しません。言語サーバー(コードを解析して補完・エラー検出などの支援を行う裏側のプログラム)を提供する拡張機能を入れることで、変数の型を推測した補完や、存在しない関数を呼んだ際の警告が得られるようになります。

コード例

ここではコードではなく、設定手順を示します。

1. Lua言語サーバー拡張機能を入れる

VS Codeの拡張機能タブで「Lua」と検索し、sumneko.lua(Lua Language Serverという名前で表示されることもあります)をインストールします。

2. workspace設定でグローバル関数の警告を抑える

プロジェクト直下に.vscode/settings.jsonを作成します。

{
  "Lua.diagnostics.globals": [
    "RegisterCommand", "RegisterNetEvent", "AddEventHandler",
    "TriggerEvent", "TriggerServerEvent", "TriggerClientEvent",
    "Citizen", "exports", "source"
  ],
  "Lua.runtime.version": "Lua 5.4"
}

これにより、FiveM独自のグローバル関数・変数(source等)を「未定義」として警告されるのを防げます。

3. FiveM native関数の型定義を追加する(補完を効かせる)

コミュニティが公開しているFiveM native定義ファイル(.lua形式の型定義集。VS Code拡張機能として配布されているものもあります)を導入すると、CreatePedやGetEntityCoordsのような数百種類のnative関数について、引数のヒントと補完が効くようになります。拡張機能タブで「FiveM」「Cfx」等のキーワードで検索し、更新が活発なものを選んでください。

注意点・よくあるミス

  • 拡張機能を入れた直後は解析に時間がかかることがあります。少し待ってから補完を確認してください。
  • .vscode/settings.jsonはプロジェクトごとの設定です。別のプロジェクトフォルダを開いた際は反映されないので、必要なら都度作成してください。
  • 補完が効かない・警告が消えない場合、VS Codeのコマンドパレットから「Lua: Reload」のような再起動系コマンドを試すと解決することがあります(拡張機能により名称は異なります)。
  • native定義ファイルはコミュニティ製のため、最新のFiveMアップデートに追従していない場合があります。存在するはずの関数が補完に出てこないときは、公式ドキュメント(Tier1-10参照)で実在を確認してください。

補足

補完・警告はあくまで開発を助けるツールであり、実際に動くかどうかは最終的にF8コンソール(Tier1-05)で確認する必要があります。「エディタでエラーが出ていないから大丈夫」と過信しないようにしましょう。
