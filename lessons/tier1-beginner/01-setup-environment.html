🟢 入門 ⚙️ 環境構築

開発環境を整える

結論

このレッスンを終えると、自分のPC上でFiveMサーバーを起動し、スクリプトを置く場所(resourcesフォルダ)を理解し、VS Codeでコードを編集できる状態になります。

説明

FiveM(GTA Vのマルチプレイヤー拡張フレームワーク)のスクリプトは、実際のプレイヤーがいる本番サーバーで直接試すものではありません。まず自分のPC上にローカルサーバー(自分だけがアクセスできる練習用サーバー)を立てて、そこで動作確認しながら開発します。

ローカルサーバーの起動にはtxAdmin(FiveMサーバーに標準で付属する管理ツール。サーバーの起動・設定・再起動をブラウザ画面から操作できる)を使うのが最も簡単です。

スクリプトはresource(リソース)という単位で管理されます。1つの機能(例: NPC配置スクリプト、UI表示スクリプトなど)が1つのresourceフォルダに対応し、サーバーの`resources`フォルダの中に置きます。

コード例

まだLuaコードは書きませんが、この時点で用意する手順をコマンド・設定として示します。

1. FiveMサーバーアーティファクトの入手・配置

mkdir C:\fxserver
cd C:\fxserver
# https://runtime.fivem.net/artifacts/fivem/build_server_windows/master/ から
# 最新のfx.tar.gz(または.zip)をダウンロードして展開する

2. resourcesフォルダの構成を確認する

C:\fxserver\
├── FXServer.exe
├── server.cfg           # サーバー設定ファイル
└── resources\
    ├── [local]\          # 自作スクリプトはこの中に置く運用が一般的
    │   └── my-first-script\
    └── [system]\         # txAdminなどシステムリソース

3. server.cfgの最低限の設定

endpoint_add_tcp "0.0.0.0:30120"
endpoint_add_udp "0.0.0.0:30120"

set sv_hostname "My Local Dev Server"
set sv_maxclients 4

# ライセンスキーは https://keymaster.fivem.net/ で無料発行できる
sv_licenseKey "ここに自分のキーを入れる"

4. サーバーを起動する

cd C:\fxserver
FXServer.exe +exec server.cfg

起動後にコンソールへ表示されるURL(通常 http://localhost:30120/)からtxAdminの初回セットアップ画面を開けます。

5. VS Codeの拡張機能

VS Codeで 「Lua」(sumneko.lua など)拡張機能を入れておくと、補完やシンタックスチェックが効いて開発しやすくなります。

注意点・よくあるミス

  • サーバーのポート(既定30120)がファイアウォールでブロックされていると、自分のPCからも接続できないことがあります。ローカルで動作確認するだけなら外部公開の設定(ポート開放)は不要です。
  • sv_licenseKeyは個人ごとに発行される無料のキーです。他人のキーを流用しない・公開リポジトリにコミットしないよう注意してください。
  • resourcesフォルダの命名にスペースや日本語を含めると、パス関連のエラーが起きることがあります。英数字とハイフン・アンダースコアのみを使いましょう。

補足

txAdminのWeb UIからは、リソースの有効化・無効化、再起動、コンソールログの確認などをブラウザから行えます。次のレッスンからはLuaの基礎文法を学び、その後実際にresourceを1つ作成します。
