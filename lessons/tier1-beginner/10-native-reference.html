ネイティブ関数リファレンスの読み方

結論

このレッスンを終えると、docs.fivem.netのネイティブ関数リファレンスを自分で読み、知らない関数の使い方を調べられるようになります。このサイトのレッスンに載っていない関数を使いたくなったときに役立つ、一生使えるスキルです。

こんな時に使う: このサイトで扱っていないnative関数を使いたいとき、「この引数は何を意味しているんだろう」と迷ったとき。

説明

ネイティブ関数(native関数)は、これまでのレッスンで何度も登場したCreatePedやGetEntityCoordsのような、FiveMがゲームエンジンを直接操作するために提供している組み込み関数です。全てのnative関数はdocs.fivem.net/natives/で検索・閲覧できます。

コード例

コードそのものではなく、ドキュメントページの読み方を説明します。例としてCREATE_VEHICLE(LuaではCreateVehicle)のページを見てみましょう。

1. 関数名の対応関係

ドキュメント上はCREATE_VEHICLEのようにC言語風の大文字スネークケースで書かれていますが、Luaから呼ぶときはCreateVehicleのようにキャメルケースに変換されます。この変換ルールはどのnative関数でも共通です。

2. 引数(Parameters)の読み方

-- ドキュメントの表記例(実際はページ内に表形式で記載されている):
-- Hash modelHash, float x, float y, float z, float heading, BOOL isNetwork, BOOL netMissionEntity

CreateVehicle(model, x, y, z, heading, isNetwork, netMissionEntity)

型(Hash, float, BOOL等)と引数名が並んでいます。HashはGetHashKeyやバッククォート記法(次のレッスンで扱います)でハッシュ化した値を渡すという意味です。BOOLはtrue/falseを渡します。

3. client/server対応の見分け方

ページ上部に「Client」「Server」といったタグや実行環境の表記があります。両方に対応している関数もあれば、client専用(画面表示・入力系)、server専用(プレイヤー管理系)の関数もあります。

4. 戻り値(Return value)の確認

ページ下部に戻り値の型が書かれています。CreateVehicleであればVehicle型(生成した車両のハンドル、つまり操作用のID)が返ってきます。

注意点・よくあるミス

  • ドキュメントの説明文だけでは動作イメージが掴みにくいnative関数もあります。関数名で検索し、コミュニティのフォーラム(forum.cfx.re)やGitHub上の実例コードを参考にするのも有効です。
  • 一部のnative関数は非推奨(deprecated)になっていたり、GTA Online専用で意図通りに動かないものもあります。ページ上部の注記を確認してください。
  • ハッシュ値を渡す引数に文字列をそのまま渡すとエラーになります。GetHashKey('文字列')または` 文字列 `(バッククォート記法)で変換してから渡してください(次のレッスンで詳しく扱います)。

補足

VS Codeに「FiveM Natives」のような補完拡張機能を入れておくと、コードを書きながら引数のヒントが表示され、ドキュメントを開く回数を減らせます。ネイティブ関数は数百種類以上あるため、全てを覚える必要はなく、「調べれば使える」状態を目指しましょう。
