GetHashKeyとハッシュ文字列

結論

このレッスンを終えると、GetHashKeyとバッククォート記法(` `)の意味を理解し、モデル名などの文字列をnative関数が要求するハッシュ値に正しく変換できるようになります。

こんな時に使う: Tier2-02で書いた` a_m_m_business_01 `のような記法の意味を知りたいとき、モデル名をハッシュに変換する処理を自分で書きたいとき。

説明

GTA Vのゲームエンジン内部では、ペドモデル名や武器名などの多くの文字列が、実際にはハッシュ値(文字列を一定の計算で変換した固定長の数値。同じ文字列からは必ず同じ数値が得られる)として扱われています。GetHashKey('文字列')という関数で、任意の文字列をこのハッシュ値に変換できます。

コード例

GetHashKeyで明示的に変換する

local modelHash = GetHashKey('a_m_m_business_01')
print(modelHash) -- 数値(例: -1656750862)が出力される

local ped = CreatePed(4, modelHash, 100.0, 200.0, 30.0, 90.0, false, false)

バッククォート記法(糖衣構文)

-- 以下2行は完全に同じ意味
local modelHash1 = GetHashKey('a_m_m_business_01')
local modelHash2 = `a_m_m_business_01`

print(modelHash1 == modelHash2) -- true

FiveMのLua処理系には、バッククォートで囲んだ文字列をコンパイル時に自動でハッシュ値へ変換するという拡張機能があります。これまでのレッスンで使ってきた` a_m_m_business_01 `のような記法は、この糖衣構文(syntax sugar。書きやすくするための簡略記法)です。

weapon名などでも同様に使える

local weaponHash = `WEAPON_PISTOL`
GiveWeaponToPed(PlayerPedId(), weaponHash, 100, false, true)

注意点・よくあるミス

  • ハッシュ変換は不可逆です。ハッシュ値から元の文字列を復元することはできません(数値だけを見ても、何のモデルだったか分かりません)。デバッグ時は元の文字列をコメントで残しておくと分かりやすくなります。
  • 大文字・小文字が異なると、別のハッシュ値になります。` WEAPON_PISTOL `と` weapon_pistol `は別の値として扱われるため、公式のモデル名・アイテム名の表記に正確に合わせる必要があります。
  • GetHashKeyは実行時に計算されるのに対し、バッククォート記法はコンパイル時に変換されるため、わずかに実行が速い場合があります。基本的にはどちらを使っても構いません(このサイトでは主にバッククォート記法を使っています)。

補足

変数に入った文字列をハッシュ化したい場合(コンパイル時に値が確定しない場合)は、バッククォート記法が使えないためGetHashKey(変数)を使う必要があります。
