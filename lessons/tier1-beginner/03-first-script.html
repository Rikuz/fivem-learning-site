最初のスクリプトを作る

結論

このレッスンを終えると、自分のresource(スクリプト単位のフォルダ)を1から作成し、サーバーに読み込ませて、F8コンソールに文字を表示させるところまでできるようになります。

説明

FiveMのスクリプトはresourcesフォルダの中に1つのフォルダとして配置します。このフォルダには最低限、fxmanifest.lua(そのresourceの設定ファイル。どのLuaファイルをclient/serverどちらで実行するかなどを書く)と、実際の処理を書くLuaファイルが必要です。

作成したresourceはserver.cfgにensure リソース名という1行を追加することで、サーバー起動時に自動的に読み込まれます。

コード例

1. resourceフォルダを作成する

cd C:\fxserver\resources\[local]
mkdir my-first-script
cd my-first-script

2. fxmanifest.luaを作成する

fx_version 'cerulean'
game 'gta5'

author 'あなたの名前'
description 'はじめてのFiveMスクリプト'
version '1.0.0'

client_script 'client.lua'
server_script 'server.lua'

3. client.luaを作成する

-- client.lua: プレイヤーの画面(クライアント側)で動く処理
RegisterCommand('hello', function()
    print('こんにちは!クライアント側のスクリプトが動いています。')
end, false)

4. server.luaを作成する

-- server.lua: サーバー側で動く処理。resource起動時に一度だけ実行される
print('my-first-script がサーバー側で起動しました')

5. server.cfgに追加する

ensure my-first-script

6. サーバーを起動して確認する

サーバーを起動すると、サーバーコンソールに my-first-script がサーバー側で起動しました と表示されます。

ゲーム内でF8キーを押してクライアントコンソールを開き、helloと入力してEnterを押すと、こんにちは!クライアント側のスクリプトが動いています。と表示されます。

注意点・よくあるミス

  • ensureの後のリソース名はフォルダ名と完全に一致している必要があります。1文字でも違うと「見つかりません」というエラーになります。
  • client_scriptとserver_scriptを逆に書いてしまうと、コマンドがF8コンソールに反応しなかったり、意図しない側で処理が実行されたりします。「画面やプレイヤー操作に関わるものはclient」「データ管理やサーバー全体に関わるものはserver」と覚えておくと迷いにくいです。
  • ファイルを保存しただけではサーバーに反映されません。サーバーコンソールでrestart my-first-scriptと入力するか、サーバーを再起動してください。
