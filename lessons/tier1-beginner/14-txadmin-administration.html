txAdminの本格的な使い方(権限管理・バックアップ・リソース監視)

結論

このレッスンを終えると、txAdmin(FXServerに標準同梱されているWeb管理パネル)で、管理者権限の割り当て・自動バックアップ・スケジュール再起動・リソースの負荷監視を行えるようになります。Tier1-01ではローカルサーバーの起動だけを扱いましたが、ここでは実際にサーバーを運用する上で欠かせない管理機能を扱います。

こんな時に使う: サーバーを複数人で管理したい、定期的にデータをバックアップしたい、「どのリソースが重いのか」を調べたいとき。

説明

txAdminはFXServerに標準で同梱されており、デフォルトではhttp://localhost:40120(または設定したポート)でWebパネルにアクセスできます。管理者権限・バックアップ・リソース監視は、いずれもこのWebパネルの各タブから操作します。設定ファイルを直接手で編集するのではなく、txAdmin自体のUIから操作するのが公式に推奨されている方法です。

コード例

管理者権限(admins.json)の主なパーミッションノード

管理者ごとの権限はtxData/admins.jsonに保存され、txAdminの「Admin Manager」画面から付与・剥奪します。代表的なパーミッションノードは以下の通りです。

// admins.json内の permissions 配列の抜粋イメージ(直接手編集はせず、Admin Manager画面から設定する)
{
  "moderator_taro": {
    "permissions": [
      "players.kick",
      "players.warn",
      "players.spectate",
      "console.view"
    ]
  },
  "admin_hanako": {
    "permissions": [
      "all_permissions"
    ]
  }
}

代表的なパーミッションノード一覧

ノードできること
all_permissions全権限(他の権限指定は無視される)
manage.admins他の管理者アカウントの作成・編集・削除
control.serverサーバーの起動・停止・再起動
console.view / console.writeコンソールの閲覧 / コマンド実行
server.cfg.editortxAdmin上でのserver.cfg編集
players.kick / players.ban / players.warnプレイヤーのキック・BAN・警告
players.spectate / players.teleportプレイヤーの観戦・テレポート

server.cfgでの権限確認との違い

# これはTier3-42で学んだACE権限(自作スクリプト向け)
# txAdminの管理者権限とは別の仕組みなので混同しないこと
add_ace group.admin command.heal allow

注意点・よくあるミス

  • txAdminの管理者権限と、Tier3-42で学んだACE権限(自作スクリプト向け)は別物です。 txAdminのAdmin Managerで権限を与えても、自作スクリプトのIsPlayerAceAllowedによる判定には反映されません。それぞれ独立して設定する必要があります。
  • admins.jsonは基本的に手で直接編集するファイルではありません。Admin Manager画面から操作し、直接編集する場合はtxAdminを再起動するまで反映されないことがあります。
  • 自動バックアップは「バックアップを取ること」自体は自動化できますが、バックアップ先のディスク容量を定期的に確認する運用は別途必要です。ローカル保存のみだと、サーバー自体に障害が起きた場合にバックアップも失われます。
  • スケジュール再起動を設定する際は、プレイヤーへの事前アナウンス(カウントダウン通知)を有効にしておくと、再起動によるプレイ中断への不満を減らせます。

補足

txAdminには他にも、①「Backups」タブでの手動/自動バックアップ(server-dataフォルダ全体のスナップショット)、②「Settings → Scheduled Restarts」でのメモリクリア目的の定期再起動設定(6時間・12時間おき等が一般的)、③ダッシュボードに統合されたリソースモニター(各リソースのCPU tick時間を、コンソールにコマンドを打たずに視覚的に確認できる)といった機能があります。いずれもWebパネルから直感的に操作できるので、実際にログインして各タブを一通り触ってみることをおすすめします。

txAdminはバージョンによってUIのタブ構成やパーミッションノードの名称が変わることがあります。本レッスンの内容はCfxの公式ドキュメント(docs.fivem.net)で確認済みですが、導入しているバージョンのドキュメントも併せて確認してください。
