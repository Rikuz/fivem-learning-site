文字列・テーブル操作の応用

結論

このレッスンを終えると、文字列を整形・検索したり、テーブルに要素を追加/削除したりする、実務でよく使う操作ができるようになります。

説明

Tier1-02で学んだテーブル・文字列の基本操作に加え、実際のスクリプトでは「プレイヤー名を整形して表示する」「配列に要素を追加/削除する」といった操作が頻繁に登場します。Luaの標準ライブラリstring・tableにまとまっている関数を使います。

コード例

string.format: 変数を埋め込んだ文字列を作る

local name = "Alice"
local money = 1500

local message = string.format('%sさんの所持金は$%dです', name, money)
print(message)
-- 出力: Aliceさんの所持金は$1500です

-- ("..."):format(...) という書き方も同じ意味でよく使われる
local message2 = ('%sさんの所持金は$%dです'):format(name, money)

string.upper / string.lower / string.find

print(string.upper('hello'))  -- HELLO
print(string.lower('HELLO'))  -- hello

local found = string.find('my-first-script', 'script')
print(found) -- 見つかった開始位置(数値)。見つからない場合はnil

if string.find('my-first-script', 'admin') then
    print('adminという文字列を含む')
else
    print('adminという文字列を含まない')
end

table.insert / table.remove

local items = { 'apple', 'banana' }

table.insert(items, 'orange')       -- 末尾に追加 → { 'apple', 'banana', 'orange' }
table.insert(items, 1, 'grape')     -- 先頭(1番目)に追加 → { 'grape', 'apple', 'banana', 'orange' }

table.remove(items, 1)              -- 1番目を削除 → { 'apple', 'banana', 'orange' }
local last = table.remove(items)    -- 引数省略で末尾を削除し、削除した値を返す

pairsとipairsの違い

local mixedTable = { 'apple', 'banana', name = 'Alice', level = 12 }

-- ipairs: 1から始まる連番のキー(配列部分)だけを順番通りに回す
for i, value in ipairs(mixedTable) do
    print(i, value)
end
-- 出力: 1 apple / 2 banana (name, levelは無視される)

-- pairs: 配列部分・連想配列部分の両方を(順序不定で)全て回す
for key, value in pairs(mixedTable) do
    print(key, value)
end
-- 出力: 1 apple / 2 banana / name Alice / level 12 (順序は保証されない)

注意点・よくあるミス

  • ipairsは連番のキー(配列部分)が途中で途切れると、そこで止まります。例えば{[1]='a', [3]='c'}のように2番目が抜けていると、ipairsは1番目しか回りません。
  • pairsで回す順序は保証されません。「必ず1番目から順番に処理したい」場合はipairsを使うか、キーの一覧を別途ソートしてから処理してください。
  • table.remove(items, 1)のように途中の要素を削除すると、後ろの要素の添字が1つずつ詰められます。ループ中にtable.removeで削除すると、ループの添字とずれてバグになりやすいので注意してください。

補足

これらの関数はLuaの標準ライブラリなので、FiveM特有の機能ではなく、どのLua環境でも同じように使えます。string.formatはチャットメッセージや通知テキストの組み立てで特によく使うので、書き方に慣れておくと以降のレッスンがスムーズになります。
