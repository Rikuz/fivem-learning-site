Lua基礎文法

結論

このレッスンを終えると、変数・テーブル・関数・条件分岐・ループというLuaの基本要素を読み書きできるようになります。FiveMのスクリプトはすべてこの基礎の組み合わせでできています。

説明

LuaはFiveMのスクリプトを書くための言語(スクリプト言語。他に軽量で組み込みやすいという特徴がある)です。変数の型を事前に宣言する必要がなく、比較的シンプルな文法なので、プログラミング初心者でも学びやすい言語です。

FiveMではデータをまとめて扱うときにテーブル(Luaにおける配列・連想配列を兼ねるデータ構造)を多用します。プレイヤー情報やアイテム情報など、ほぼ全てがテーブルで表現されます。

コード例

変数とデータ型

local playerName = "Alice"   -- 文字列
local playerLevel = 12        -- 数値
local isOnline = true         -- 真偽値(true/false)

print(playerName, playerLevel, isOnline)
-- 出力: Alice   12   true

テーブル(配列として)

local fruits = { "apple", "banana", "orange" }

print(fruits[1])  -- Luaの配列は1から始まる(0からではない)
-- 出力: apple

for i = 1, #fruits do
    print(i, fruits[i])
end

テーブル(連想配列として)

local player = {
    name = "Alice",
    level = 12,
    money = 500
}

print(player.name)   -- ドット記法
print(player["money"]) -- ブラケット記法(どちらでも同じ意味)

関数

local function addMoney(current, amount)
    return current + amount
end

local newMoney = addMoney(player.money, 100)
print(newMoney) -- 600

if文

if player.level >= 10 then
    print("ベテランプレイヤーです")
elseif player.level >= 5 then
    print("中級者です")
else
    print("初心者です")
end

for / whileループ

-- forループ(1から5まで1ずつ増やす)
for i = 1, 5 do
    print("カウント: " .. i)  -- ".."は文字列連結演算子
end

-- whileループ
local hp = 100
while hp > 0 do
    hp = hp - 25
    print("残りHP: " .. hp)
end

注意点・よくあるミス

  • Luaの配列(テーブル)は添字が1から始まります。他言語(JavaScriptなど)の0始まりに慣れていると`fruits[0]`にアクセスしてバグになりがちです。
  • 文字列の連結は+ではなく..を使います。"a" + "b"はエラーになります。
  • localを付け忘れるとグローバル変数になり、他のスクリプトファイルの同名変数と衝突する危険があります。基本的に変数は必ずlocalで宣言してください。
