fxmanifest.luaを理解する

結論

このレッスンを終えると、fxmanifest.luaの主要な項目(fx_version, game, client_script, server_script, shared_script, dependency)の意味を理解し、自分のresourceの構成に合わせて書けるようになります。

説明

fxmanifest.luaは、そのresourceがどんなファイルで構成されているか、どの環境(client/server)でどのファイルを実行するかをFiveMに伝える設定ファイルです。resourceフォルダの直下に必ず1つ必要です。

コード例

fx_version 'cerulean'   -- fxmanifestの記法バージョン。現在はほぼ固定でこの値
game 'gta5'              -- 対象ゲーム('gta5'または'common'などを指定)

author 'あなたの名前'
description 'このresourceの説明'
version '1.0.0'

-- クライアント側(プレイヤーの画面)で実行するファイル
client_script 'client.lua'

-- サーバー側で実行するファイル
server_script 'server.lua'

-- client/server両方から読み込みたい共通ファイル(定数・設定など)
shared_script 'shared/config.lua'

-- このresourceが動くために必要な別のresource
dependency 'oxmysql'

複数ファイルを指定する場合

client_scripts {
    'client/main.lua',
    'client/ui.lua'
}

server_scripts {
    'server/main.lua',
    'server/database.lua'
}

注意点・よくあるミス

  • shared_scriptで読み込んだファイルは、client側でもserver側でもそれぞれ独立して実行されます。「1回だけ実行される共有メモリ」ではないため、client側の変更がserver側に自動で反映されるわけではありません。
  • dependencyに指定したresourceが実際にサーバーに導入されていない、または起動順序が逆だと、エラーで自分のresourceが起動しません。依存先は先にensureされている必要があります。
  • ファイルパスの区切りはスラッシュ(/)を使います(Windows環境でもバックスラッシュではなく/)。

補足

他にもui_page(NUIで使うHTMLファイルの指定。Tier3で扱います)やfiles(NUI用のCSS/JS/画像などを明示的に含める)といった項目があります。使う機能が増えるごとに少しずつ追加していく形で問題ありません。

※fxmanifestの項目はFiveMのアップデートで追加・変更されることがあります。詳細は公式ドキュメント(docs.fivem.net)の「fxmanifest.lua」ページも確認してください。
