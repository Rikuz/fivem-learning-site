サウンドを再生する

結論

このレッスンを終えると、UIの操作音のような画面全体で鳴る効果音と、特定の座標から聞こえる位置付きのサウンドの両方を再生することができるようになります。

こんな時に使う: ボタンを押したときにクリック音を鳴らしたい、ATMの近くで操作音を鳴らしたい、通知音でプレイヤーに気づかせたいとき。

説明

GTA Vには元から多数のサウンドセット(効果音の集まり)が組み込まれており、PlaySoundFrontend(画面全体・方向に依存しない音)とPlaySoundFromCoord(特定の座標から聞こえる、距離減衰のある音)の2種類のnative関数で再生できます。

コード例

UI操作音を鳴らす(PlaySoundFrontend)

local function playClickSound()
    -- PlaySoundFrontend(soundId, soundName, soundSet, isBlocking)
    -- soundIdは-1でよい(古いAPIとの互換用の引数)
    PlaySoundFrontend(-1, 'SELECT', 'HUD_FRONTEND_DEFAULT_SOUNDSET', true)
end

RegisterCommand('clicksound', playClickSound, false)

座標付きのサウンドを鳴らす(PlaySoundFromCoord)

local function playAtmBeep(coords)
    -- PlaySoundFromCoord(soundId, soundName, x, y, z, soundSet, isBlocking, range, unknown)
    PlaySoundFromCoord(-1, 'Menu_Accept', coords.x, coords.y, coords.z, 'HUD_FRONTEND_DEFAULT_SOUNDSET', false, 0, false)
end

RegisterCommand('atmbeep', function()
    playAtmBeep(GetEntityCoords(PlayerPedId()))
end, false)

注意点・よくあるミス

  • soundNameとsoundSetの組み合わせは決まったものしか鳴りません。存在しない組み合わせを指定しても、エラーは出ずに単に無音になります。コミュニティの「GTA5 sound list」等で確認してください。
  • PlaySoundFrontendを通知のたびに何度も呼ぶと耳障りになりがちです。連続して鳴らさないよう、クールダウン(Tier5-04で学んだレート制限と同じ考え方)を入れることを検討してください。
  • 座標付きサウンドはプレイヤーとの距離が離れるほど小さくなります。近づいたときだけ意味のある演出(ATM操作音など)に向いています。

補足

okokNotify(Tier4-03)のような通知スクリプトは、内部でこのようなサウンド再生を組み合わせて「効果音付きの通知」を実現しています。独自のNUIに効果音を追加したい場合は、この仕組みをclient.lua側から呼び出す形で連携できます。
