🟡 初級 🧍 NPC・エンティティ操作

NPCを配置する

結論

このレッスンを終えると、指定した座標にNPC(ノンプレイヤーキャラクター)を出現させ、その場に固定し、不要になったら削除することができるようになります。

説明

NPCの配置はclient側で行います(NPCは各プレイヤーの画面上に描画されるものであり、client側のnative関数で生成します)。生成にはペッドモデル(キャラクターの見た目データ)を先に読み込んでおく必要があります。

座標(x, y, z)はゲーム内のワールド座標です。座標を調べるには、ゲーム内でF8コンソールを開きGetEntityCoords(PlayerPedId())を実行して自分の現在地を確認するのが手軽です。

コード例

client.lua: NPCを生成して固定する

local spawnedPed = nil

local function spawnShopkeeper()
    -- `a_m_m_business_01` はFiveMのハッシュ文字列リテラル(バッククォート)。
    -- ペッドモデル名からハッシュ値に変換してくれる記法
    local model = `a_m_m_business_01`

    RequestModel(model)
    while not HasModelLoaded(model) do
        Wait(0) -- モデルの読み込みが終わるまで毎フレーム待つ
    end

    local x, y, z = 100.0, 200.0, 30.0
    local heading = 90.0

    -- CreatePed(pedType, model, x, y, z, heading, isNetwork, bScriptHostPed)
    spawnedPed = CreatePed(4, model, x, y, z, heading, false, false)

    FreezeEntityPosition(spawnedPed, true)   -- その場から動かなくする
    SetEntityInvincible(spawnedPed, true)    -- 攻撃されても死なないようにする
    SetBlockingOfNonTemporaryEvents(spawnedPed, true) -- 周囲の出来事に反応して勝手に動くのを防ぐ

    SetModelAsNoLongerNeeded(model) -- 読み込んだモデルデータをメモリから解放してよいと伝える
end

RegisterCommand('spawnnpc', spawnShopkeeper, false)

client.lua: NPCを削除する

local function removeShopkeeper()
    if spawnedPed and DoesEntityExist(spawnedPed) then
        SetEntityAsMissionEntity(spawnedPed, true, true)
        DeletePed(spawnedPed)
        spawnedPed = nil
    end
end

RegisterCommand('removenpc', removeShopkeeper, false)

座標を取得する

RegisterCommand('mycoords', function()
    local coords = GetEntityCoords(PlayerPedId())
    print(('x=%.2f, y=%.2f, z=%.2f'):format(coords.x, coords.y, coords.z))
end, false)

注意点・よくあるミス

  • RequestModel直後にモデルの読み込みが終わっているとは限りません。HasModelLoadedで確認するwhileループを必ず挟んでください。
  • resource停止時にNPCを消し忘れると、画面上にNPCが残り続けたり、次に同じコマンドを実行した際にNPCが重複して生成されたりします。AddEventHandler('onResourceStop', ...)で自分のresourceが止まるタイミングを検知し、削除処理を呼ぶようにしましょう。
  • NPCの数が増えすぎるとクライアントの負荷が上がります。不要になったNPCはこまめにDeletePedしてください。
