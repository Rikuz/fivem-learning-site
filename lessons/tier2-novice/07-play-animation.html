アニメーションを再生する

結論

このレッスンを終えると、プレイヤーやNPCに座る・手を振るといったアニメーション(モーション)を再生させることができるようになります。

説明

GTA V/FiveMのアニメーションは、アニメ辞書(関連するアニメーションをまとめたデータの集まり)ごとに分類されています。再生する前に該当のアニメ辞書を読み込み(RequestAnimDict)、読み込みが終わってからTaskPlayAnimで実際に再生します。

コード例

client.lua: アニメーションを再生する

local function playSitAnimation()
    local dict = 'anim@amb@nightclub@mini@stand_dance@dance_solo@male@var_a@'
    local anim = 'high_center'

    RequestAnimDict(dict)
    while not HasAnimDictLoaded(dict) do
        Wait(0)
    end

    local ped = PlayerPedId()

    -- TaskPlayAnim(ped, dict, anim, blendInSpeed, blendOutSpeed, duration, flag, playbackRate, lockX, lockY, lockZ)
    TaskPlayAnim(ped, dict, anim, 8.0, 8.0, -1, 1, 0, false, false, false)
    -- duration=-1: 明示的に止めるまでループ再生し続ける
    -- flag=1: ループ再生を有効にする

    RemoveAnimDict(dict) -- 読み込んだアニメ辞書をメモリから解放してよいと伝える(再生自体は続く)
end

RegisterCommand('dance', playSitAnimation, false)

client.lua: アニメーションを止める

local function stopAnimation()
    local ped = PlayerPedId()
    ClearPedTasks(ped)
end

RegisterCommand('stopanim', stopAnimation, false)

注意点・よくあるミス

  • RequestAnimDict直後はまだ読み込みが終わっていません。HasAnimDictLoadedで確認するwhileループを必ず挟んでください(モデルの読み込みと同じパターンです)。
  • アニメ辞書名・アニメーション名は1文字でも間違えると何も再生されません(エラーにもならず静かに失敗することが多いです)。コミュニティの「GTA5 Animations list」等で正確な名前を確認してから使ってください。
  • duration=-1かつflagにループを指定した場合、自分で止めない限りアニメーションが再生され続けます。プレイヤーが移動したりコマンドを実行したりしたタイミングでClearPedTasksを呼ぶ設計にしてください。

補足

小物(プロップ)を同時に持たせたい場合(例: 座って本を読むアニメーションに本のモデルを持たせる)は、CreateObjectで小物のオブジェクトを生成し、AttachEntityToEntityでペドの手のボーンに位置合わせして固定する、という組み合わせがよく使われます。
