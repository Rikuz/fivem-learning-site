コマンドを登録する

結論

このレッスンを終えると、チャット欄から/コマンド名で実行できる独自コマンドを作り、管理者などの限られた人だけ使える権限チェックを付けることができるようになります。

説明

RegisterCommandはclient側でもserver側でも使え、チャット欄(または該当側のコンソール)から/コマンド名 引数の形で実行されたときに呼び出されます。

誰でも使えると困るコマンド(例: 全員にお金を配る等)は、ACE権限(FiveMのアクセス制御の仕組み。server.cfgでadd_aceを使ってプレイヤーやグループに権限を付与する)とIsPlayerAceAllowedを組み合わせてチェックします。

コード例

server.lua: 誰でも使えるコマンド

-- source: 実行したプレイヤーのID, args: スペース区切りの引数の配列, rawCommand: 入力全体の文字列
RegisterCommand('hello', function(source, args, rawCommand)
    local playerName = GetPlayerName(source)
    TriggerClientEvent('chat:addMessage', source, {
        args = { ('%sさん、こんにちは!'):format(playerName) }
    })
end, false) -- 第3引数false: 誰でも実行できる(権限制限なし)

server.lua: 権限が必要なコマンド

RegisterCommand('heal', function(source, args, rawCommand)
    if not IsPlayerAceAllowed(source, 'command.heal') then
        TriggerClientEvent('chat:addMessage', source, {
            args = { '権限がありません' }
        })
        return
    end

    local targetId = tonumber(args[1])
    if not targetId then
        TriggerClientEvent('chat:addMessage', source, {
            args = { '使い方: /heal [プレイヤーID]' }
        })
        return
    end

    TriggerClientEvent('myscript:healPlayer', targetId)
end, false)

server.cfg: 権限をプレイヤーに付与する

# identifierはプレイヤーのSteam/license識別子に置き換える
add_ace identifier.steam:110000112345678 command.heal allow
# もしくはグループ単位で付与する
add_principal identifier.steam:110000112345678 group.admin
add_ace group.admin command.heal allow

注意点・よくあるミス

  • RegisterCommandの第3引数をfalseにすると「誰でも実行可能」になります。権限が必要なコマンドのつもりでこの引数を書き忘れると、誰でも実行できてしまいます。
  • 権限チェックは必ずserver側で行ってください。client側だけでチェックしても、チートツールで直接イベントを発火されると回避されてしまいます。
  • ACE権限名(command.healなど)は自分で決める文字列です。スクリプトごとに名前が重複しないよう、resource名を含めた命名(例: myscript.heal)にすると安全です。

補足

上記のchat:addMessageはFiveM標準のchatリソースが提供するイベントです。導入しているチャットシステムによって使い方が異なる場合があるため、実際の環境のチャットリソースのドキュメントも確認してください。
