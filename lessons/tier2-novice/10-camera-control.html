カメラを演出する

結論

このレッスンを終えると、通常のプレイヤー視点とは別に独自のカメラを作成し、簡易的な演出(カットシーン風の視点切り替え)を実装することができるようになります。

こんな時に使う: キャラクター作成画面で顔を回転して見せたい、施設のオープニング演出をしたい、防犯カメラのような固定視点を作りたいとき。

説明

FiveM/GTA Vでは、スクリプトカメラ(nativeで生成・操作できる仮想カメラ)を作成し、RenderScriptCamsで「今どのカメラを描画するか」を通常視点からスクリプトカメラに切り替えられます。

コード例

client.lua: カメラを作成して切り替える

local cam = nil

local function startCameraView()
    local coords = GetEntityCoords(PlayerPedId())

    -- CreateCamWithParams(camType, x, y, z, rotX, rotY, rotZ, fov, ...)
    cam = CreateCamWithParams('DEFAULT_SCRIPTED_CAMERA',
        coords.x, coords.y, coords.z + 2.0,
        0.0, 0.0, 0.0,
        50.0, -- 画角(FOV)
        false, 0)

    PointCamAtCoord(cam, coords.x + 5.0, coords.y, coords.z) -- 見る方向を指定する

    RenderScriptCams(true, true, 1000, true, false) -- 1000msかけて滑らかに切り替える
end

RegisterCommand('camview', startCameraView, false)

client.lua: カメラを元に戻す

local function stopCameraView()
    if cam then
        RenderScriptCams(false, true, 1000, true, false) -- 通常視点に戻す
        DestroyCam(cam, false)
        cam = nil
    end
end

RegisterCommand('camstop', stopCameraView, false)

注意点・よくあるミス

  • RenderScriptCams(true, ...)で切り替えたカメラは、自分でRenderScriptCams(false, ...)を呼んで戻さない限り視点が固定されたままになります。UIを閉じるタイミングなどで必ず戻す処理を書いてください。
  • DestroyCamを呼ばずにカメラを作り続けると、使われていないカメラがメモリに残り続けます。使い終わったカメラは必ず破棄しましょう。
  • カメラ演出中はプレイヤーが自由に動けてしまうと不自然な見た目になります。必要に応じてFreezeEntityPosition(Tier2-02参照)でプレイヤーの動きを止めることも検討してください。

補足

複数のカメラを用意してSetCamActiveWithInterpで滑らかに切り替えると、より映画的な演出ができます。キャラクリエイト画面(Tier4-17「illenium-appearanceでキャラクリエイトする」)の裏側でも、この仕組みが使われています。
