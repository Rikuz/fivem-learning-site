🟡 初級 🚗 車両操作

車両を生成・操作する

結論

このレッスンを終えると、指定した座標に車両を生成し、プレイヤーを乗せ、不要になったら削除することができるようになります。

説明

車両の生成はNPCの生成(Tier2-02)とよく似た手順です。車両モデル(ハッシュ)を読み込み、CreateVehicleで生成し、SetPedIntoVehicleでプレイヤーを乗せます。

コード例

client.lua: 車両を生成してプレイヤーを乗せる

local spawnedVehicle = nil

local function spawnMyCar()
    local model = `adder`

    RequestModel(model)
    while not HasModelLoaded(model) do
        Wait(0)
    end

    local playerPed = PlayerPedId()
    local coords = GetEntityCoords(playerPed)
    local heading = GetEntityHeading(playerPed)

    -- CreateVehicle(model, x, y, z, heading, isNetwork, bScriptHostVeh)
    spawnedVehicle = CreateVehicle(model, coords.x + 3.0, coords.y, coords.z, heading, true, false)

    SetVehicleNumberPlateText(spawnedVehicle, 'MYCAR01')
    SetPedIntoVehicle(playerPed, spawnedVehicle, -1) -- -1 = 運転席

    SetModelAsNoLongerNeeded(model)
end

RegisterCommand('mycar', spawnMyCar, false)

client.lua: 車両を削除する

local function deleteMyCar()
    if spawnedVehicle and DoesEntityExist(spawnedVehicle) then
        SetEntityAsMissionEntity(spawnedVehicle, true, true)
        DeleteVehicle(spawnedVehicle)
        spawnedVehicle = nil
    end
end

RegisterCommand('deletecar', deleteMyCar, false)

注意点・よくあるミス

  • NPC生成(Tier2-02)と同様に、RequestModel直後はまだモデルの読み込みが終わっていません。必ずHasModelLoadedで確認するwhileループを挟んでください。
  • CreateVehicleの第6引数isNetworkをtrueにしないと、他のプレイヤーからその車両が見えません(自分の画面にしか存在しないローカルなエンティティになります)。マルチプレイで共有したい場合は必ずtrueにしてください。
  • プレイヤーの真上や壁の中に近い座標を指定すると、車両がめり込んで生成されてしまうことがあります。座標に少し余裕を持たせる(上記コード例では+3.0)、または生成後にSetVehicleOnGroundProperlyを呼ぶと安定します。

補足

車両を残したまま次々に生成すると、サーバーの負荷が上がり続けます。resource停止時のクリーンアップ(NPCの回で学んだonResourceStop)や、既に自分の車両があれば先に削除してから生成する、といった管理も実運用では重要になります。
