車両の修理・ダメージ管理

結論

このレッスンを終えると、車両を修理して見た目・性能を元に戻し、現在のダメージ状態(エンジン・車体の状態)を確認することができるようになります。

こんな時に使う: 整備工場・修理コマンドを作りたい、ダメージ具合に応じてNPCの反応を変えたい、燃料システム(Tier4-15)と組み合わせて車両の状態を管理したいとき。

説明

GTA Vの車両は、エンジン・車体それぞれに独立した「体力」を持っており、事故やバトルでダメージを受けると数値が下がります。SetVehicleFixedで全ての損傷を修復でき、GetVehicleEngineHealth等で現在の状態を数値として取得できます。

コード例

車両を修理する

local function repairVehicle(vehicle)
    SetVehicleFixed(vehicle)              -- 見た目・エンジン状態を完全に修復する
    SetVehicleDeformationFixed(vehicle)   -- 車体のへこみを元に戻す
    SetVehicleDirtLevel(vehicle, 0.0)     -- 汚れをリセットする(0.0〜15.0)
end

RegisterCommand('repaircar', function()
    local vehicle = GetVehiclePedIsIn(PlayerPedId(), false)
    if vehicle ~= 0 then
        repairVehicle(vehicle)
    end
end, false)

ダメージ状態を確認する

RegisterCommand('carstatus', function()
    local vehicle = GetVehiclePedIsIn(PlayerPedId(), false)
    if vehicle == 0 then return end

    local engineHealth = GetVehicleEngineHealth(vehicle) -- 0.0〜1000.0
    local bodyHealth = GetVehicleBodyHealth(vehicle)     -- 0.0〜1000.0

    print(('エンジン: %.0f / 車体: %.0f'):format(engineHealth, bodyHealth))
end, false)

ダメージ度合いを段階的に判定する

local function getDamageLevel(vehicle)
    local engineHealth = GetVehicleEngineHealth(vehicle)

    if engineHealth > 800.0 then
        return '良好'
    elseif engineHealth > 400.0 then
        return '軽度の損傷'
    else
        return '重度の損傷'
    end
end

注意点・よくあるミス

  • 修理処理はclient側のnativeですが、誰でも自由に呼べる状態にすると「壊れた車両を見せかけだけ使う」チートの温床になります。整備工場などの機能として提供する場合は、Tier3-05で学んだサーバー側バリデーション(近くにいるか・お金を持っているか等)を組み合わせてください。
  • GetVehicleEngineHealthの値は最大1000.0ですが、0.0を下回ると炎上・エンジン停止といった状態になります。マイナス値になり得る点に注意してください。
  • 燃料システム(Tier4-15「ox_fuelで燃料システムを連携する」)とは別の仕組みです。「修理」と「給油」は独立した概念として扱ってください。

補足

実運用のガレージ・整備システムでは、ダメージ状態をDBに保存し、次回車両を出したときに前回のダメージが引き継がれる設計にすることもあります(Tier3-18「ガレージシステムの基礎設計」で扱います)。
