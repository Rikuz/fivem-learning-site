🟡 初級 🧍 NPC・エンティティ操作

オブジェクト(プロップ)を生成・設置する

結論

このレッスンを終えると、看板・コーン・ダンボール箱のような小物(プロップ)をワールドに設置し、不要になったら削除することができるようになります。

こんな時に使う: イベント会場に装飾を置きたい、露店の商品台を設置したい、道路工事のコーンを配置したいとき。

説明

NPC(Ped)・車両(Vehicle)と並ぶ3つ目のエンティティ種別がオブジェクト(Object)です。動かない小物や装飾品はほとんどがこのオブジェクトとして生成されます。生成手順はNPC・車両と同じく「モデルを読み込む→生成する→不要な設定を無効化する」という流れです。

コード例

client.lua: プロップを設置する

local spawnedObject = nil

local function placeSignboard()
    local model = `prop_sign_advert_01a`

    RequestModel(model)
    while not HasModelLoaded(model) do
        Wait(0)
    end

    local coords = GetEntityCoords(PlayerPedId())

    -- CreateObject(model, x, y, z, isNetwork, netMissionEntity, doorFlag)
    spawnedObject = CreateObject(model, coords.x + 2.0, coords.y, coords.z, true, true, false)

    PlaceObjectOnGroundProperly(spawnedObject) -- 地面に自然に接地させる
    FreezeEntityPosition(spawnedObject, true)  -- その場に固定する

    SetModelAsNoLongerNeeded(model)
end

RegisterCommand('placesign', placeSignboard, false)

client.lua: プロップを削除する

local function removeSignboard()
    if spawnedObject and DoesEntityExist(spawnedObject) then
        SetEntityAsMissionEntity(spawnedObject, true, true)
        DeleteObject(spawnedObject)
        spawnedObject = nil
    end
end

RegisterCommand('removesign', removeSignboard, false)

注意点・よくあるミス

  • PlaceObjectOnGroundProperlyを呼ばないと、地面に半分めり込んだ状態や浮いた状態で設置されることがあります。地面に置きたい小物では必ず呼びましょう。
  • NPC・車両と同様、isNetworkをtrueにしないと他プレイヤーから見えません。複数人で共有したい装飾には必須です。
  • プロップを大量に設置するとクライアントの負荷が上がります。イベント終了後は必ず削除する運用にしましょう(resource停止時の自動削除もTier2-02と同様に検討してください)。

補足

プロップのモデル名は非常に数が多く、コミュニティの「GTA5 Props list」等のサイトで用途別に検索できます。Tier2-07で学んだアニメーションと組み合わせて、プレイヤーに小物を持たせる(AttachEntityToEntityでボーンに固定する)演出もよく使われます。
