エリア判定を自作する

結論

このレッスンを終えると、プレイヤーが特定のエリア(円形・四角形の範囲)に入った/出たことを検知する自作のゾーンシステムを作れるようになります。

こんな時に使う: 「病院エリアに入ったら回復する」「工場エリアの外ではNPCを表示しない」のような、範囲に応じた処理を作りたいとき。

説明

最もシンプルなエリア判定は「2点間の距離」で行う円形ゾーンです。より複雑な形(建物の輪郭に沿った多角形など)にしたい場合は、点が多角形の内側にあるかどうかを判定するアルゴリズムを使います。

コード例

円形ゾーン: 距離での判定

local hospitalZone = { coords = vector3(300.0, -600.0, 40.0), radius = 30.0 }
local wasInside = false

CreateThread(function()
    while true do
        local playerCoords = GetEntityCoords(PlayerPedId())
        local distance = #(playerCoords - hospitalZone.coords)
        local isInside = distance <= hospitalZone.radius

        if isInside and not wasInside then
            print('病院エリアに入りました')
        elseif not isInside and wasInside then
            print('病院エリアから出ました')
        end

        wasInside = isInside
        Wait(500)
    end
end)

多角形ゾーン: Point-in-Polygon判定

-- 多角形の頂点座標を反時計回り or 時計回りで並べたもの
local factoryPolygon = {
    vector2(100.0, 100.0),
    vector2(150.0, 100.0),
    vector2(150.0, 150.0),
    vector2(100.0, 150.0),
}

-- レイキャスティング法による判定(点が多角形の内側にあるか)
local function isPointInPolygon(point, polygon)
    local inside = false
    local j = #polygon

    for i = 1, #polygon do
        local pi, pj = polygon[i], polygon[j]
        if ((pi.y > point.y) ~= (pj.y > point.y)) and
           (point.x < (pj.x - pi.x) * (point.y - pi.y) / (pj.y - pi.y) + pi.x) then
            inside = not inside
        end
        j = i
    end

    return inside
end

CreateThread(function()
    while true do
        local coords = GetEntityCoords(PlayerPedId())
        local point = vector2(coords.x, coords.y)

        if isPointInPolygon(point, factoryPolygon) then
            print('工場エリア内にいます')
        end

        Wait(1000)
    end
end)

注意点・よくあるミス

  • 円形ゾームの判定はxy平面だけでなくz座標(高さ)も含めた3次元距離になっている点に注意してください。ビルの2階と1階を区別したい場合は、別途z座標の範囲チェックを追加する必要があります。
  • 「入った/出た」を毎回printし続けないよう、上記コード例のようにwasInsideのような状態フラグで「変化があったときだけ」処理するのが基本パターンです(Tier2-03のBlip表示制御と同じ考え方)。
  • 多角形判定は円形判定より計算コストが高いため、Tier5-01の考え方に基づき判定頻度(Waitの値)を調整してください。

補足

本格的なゾーン管理が必要な場合は、コミュニティ製のPolyZoneライブラリ(CircleZone/BoxZone/PolyZone等をまとめて扱えるもの)を導入することも多いです。ox_target(Tier3-07)のaddBoxZoneも、内部的にはこれと似た考え方で範囲を判定しています。
