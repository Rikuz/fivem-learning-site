照準先のエンティティを取得する

結論

このレッスンを終えると、プレイヤーが画面の中心(カメラの正面)で見ている先に何があるかを判定することができるようになります。ox_target(Tier3-07)のようなライブラリの内部で使われている基礎技術です。

こんな時に使う: 「見ている車両のナンバーを表示したい」「照準を合わせたNPCの名前を表示したい」など、自分でシンプルなターゲティング機能を作りたいとき。

説明

カメラの位置から視線方向に向かって「見えない光線」を飛ばし、最初に当たったものを調べる処理をレイキャスト(3D空間に仮想的な光線を飛ばして衝突判定する手法)と呼びます。FiveMではStartShapeTestRay系のnative関数でこれを行います。

コード例

client.lua: 画面中心の照準先を取得する

local function getAimTarget()
    local playerPed = PlayerPedId()
    local camCoords = GetGameplayCamCoord()
    local camRotation = GetGameplayCamRot(2)

    -- カメラの向きから、少し先の座標を計算する
    local direction = RotationToDirection(camRotation)
    local destination = camCoords + direction * 10.0 -- 10メートル先まで判定する

    -- StartShapeTestRay(x1, y1, z1, x2, y2, z2, flags, ignoreEntity, p8)
    local rayHandle = StartShapeTestRay(
        camCoords.x, camCoords.y, camCoords.z,
        destination.x, destination.y, destination.z,
        -1, playerPed, 0
    )

    local _, hit, endCoords, _, hitEntity = GetShapeTestResult(rayHandle)

    return hit, hitEntity, endCoords
end

function RotationToDirection(rotation)
    local z = math.rad(rotation.z)
    local x = math.rad(rotation.x)
    local num = math.abs(math.cos(x))
    return vector3(-math.sin(z) * num, math.cos(z) * num, math.sin(x))
end

使用例: 照準先のエンティティ情報を表示する

CreateThread(function()
    while true do
        Wait(0)
        local hit, entity = getAimTarget()

        if hit == 1 and DoesEntityExist(entity) then
            if IsEntityAVehicle(entity) then
                print('車両を見ています: ' .. GetVehicleNumberPlateText(entity))
            elseif IsEntityAPed(entity) then
                print('ペドを見ています')
            end
        end
    end
end)

注意点・よくあるミス

  • ignoreEntity(上記コードのplayerPed)を指定しないと、自分自身に光線が当たってしまい、常に自分を「照準先」として検知してしまいます。
  • この処理をWait(0)で毎フレーム実行すると負荷がかかります(Tier5-01「パフォーマンス計測と最適化」参照)。UIを表示している間だけ実行する等、必要なときだけ動かす設計にしましょう。
  • flags引数(上記の-1)によって、どの種類のエンティティに光線が当たり判定を持つかが変わります。用途に応じて調整が必要です。

補足

実運用では、この仕組みを自分で組み立てるより、Tier3-07「ox_targetでインタラクションを作る」やTier3-29「qb-targetでインタラクションを作る」のような、既に最適化・調整済みのライブラリを使う方が安定します。ただし内部で何が起きているかを理解しておくと、これらのライブラリの挙動を理解しやすくなります。
