ペドの服装・見た目を変更する

結論

このレッスンを終えると、プレイヤーやNPCの服装パーツ・帽子などの装飾品を切り替えることができるようになります。

こんな時に使う: 制服を着せたい(警察官・救急隊員など)、変装システムを作りたい、NPCの見た目にバリエーションを持たせたいとき。

説明

ペドの見た目は、体の部位ごとに分かれたコンポーネント(髪型・上半身・下半身・靴など、部位ごとの着せ替えパーツ)と、帽子・アクセサリなどのプロップで構成されています。それぞれ番号(drawableId)とバリエーション番号(textureId)の組み合わせで指定します。

コード例

服装パーツを変更する

local function equipPoliceUniform()
    local ped = PlayerPedId()

    -- SetPedComponentVariation(ped, componentId, drawableId, textureId, paletteId)
    SetPedComponentVariation(ped, 11, 55, 0, 0) -- 11 = 上半身(トップス)
    SetPedComponentVariation(ped, 4, 35, 0, 0)  -- 4  = 下半身(パンツ)
    SetPedComponentVariation(ped, 6, 25, 0, 0)  -- 6  = 靴
end

RegisterCommand('equippolice', equipPoliceUniform, false)

帽子(プロップ)を装着する

local function equipHat()
    local ped = PlayerPedId()

    -- SetPedPropIndex(ped, componentId, drawableId, textureId, attach)
    SetPedPropIndex(ped, 0, 5, 0, true) -- 0 = 帽子

    -- 外すときは ClearPedProp(ped, 0)
end

元の見た目に戻す

local function resetAppearance()
    local ped = PlayerPedId()
    local model = GetEntityModel(ped)

    SetPedDefaultComponentVariation(ped) -- モデル本来の初期状態に戻す
end

注意点・よくあるミス

  • componentId(部位番号)は0〜11の固定値で、モデルによって使えるdrawableId/textureIdの範囲が異なります。存在しない番号を指定すると、その部位が非表示になったり、見た目が崩れたりします。
  • フレームワーク(ESX/QBCore)の服装システムを既に導入している場合、この関数を直接呼ぶとフレームワーク側の管理と競合することがあります。実運用では、Tier4-18で扱うqb-clothingのような専用スクリプトの仕組みに従って変更するのが安全です。
  • 変更はそのプレイヤーの画面にしか反映されません(client側のnativeのため)。他プレイヤーにも見せたい場合は、変更内容をイベントやStateBags(Tier5-03)で共有する必要があります。

補足

コンポーネント番号・プロップ番号の一覧は、コミュニティの「GTA5 Ped Component IDs」等のサイトで確認できます。本格的なキャラクリエイト機能を作りたい場合は、Tier4-17「illenium-appearanceでキャラクリエイトする」で扱う専用スクリプトの利用も検討してください。
